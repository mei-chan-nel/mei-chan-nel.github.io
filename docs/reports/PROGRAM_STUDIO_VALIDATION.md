## 継続して検証している仕様

- 1行ずつ実行すると実行中の行が緑になり、その結果が変数・出力に反映。解説・変数・出力の枠は実行中に伸縮しない。
- 外部入力は問題ごとの種類・範囲・個数をUIとWorkerで検証。範囲外・未代入・0除算などは該当行で停止。
- 範囲1～10の整数乱数、0以上1未満の実数乱数、リセットでの再現、乱数の単一評価を検証。
- 自動実行、一時停止、最初から、0.5秒から0.01秒・0.001秒への変更を検証。
- 作成途中の空白行・空のブロックは保存・共有でき、未完成のブロックは実行前にその行を示して止める。
- 旧ファイル・旧共有URL、AIが生成した完成済みのsource-onlyファイルを読み込み、行編集へ変換できる。不正なevalなどのファイルは既存プログラムを保持して拒否。
- AI向けMarkdown・JSON SchemaはHTML headから発見できる。通常は「ファイルの仕様」を閉じておき、読みたい人には日本語の規則と完全な仕様へのリンクを表示する。
- 保存容量不足、壊れたURL、サイズ上限、圧縮済みURLを読めない場合は理由とファイルによる代替を表示。非圧縮v2は圧縮APIがなくても生成・復元できる。共有URLを外部へ送らずに検証。
- 共通ヘッダー・フッター・広告、入口の3区分、代表15問と閉じた動画解説問題を維持。
