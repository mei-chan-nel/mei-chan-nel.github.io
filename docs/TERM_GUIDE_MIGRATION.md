## Study Atlas側で行った構造変更

- noteの「確認問題」は、各ページの `例題` カードへ移しました。
- noteの「アプリで類題を解く」、手動のchallenge ID・URL、案内文は移行せず、`term-challenge.js` によるタグ一致・最大5問・例題除外の共通UIへ置き換えました。
- note本文にあった空の区切り見出し・空段落は、読みやすさに影響しない装飾用マークアップとして除きました。
- ソートアルゴリズム記事の数式表示用文字列は、静的HTMLでも読めるように `$${...}$$` 表記を通常の数式表記へ整え、`N2N^2` は意図された `N²` として表示しています。内容の計算結果は変更していません。
- CPUページには既存の編集上の訂正として、noteの「と区別になります」を「と区別できます」としている箇所があります。
- 16進数記事の図はnoteの画像URLを参照しています。画像ファイル自体は新規コピーしていません。

## 生成の正本

用語ページのリンク判定はslug一覧を手書きせず、各 `terms/*/index.html` の次のメタデータを読み取ります。

```html
<meta name="study-atlas-term-tag" content="用語タグ" />
<meta name="study-atlas-term-summary" content="タグ検索に表示する短い説明" />
```

`python scripts/generate_term_guides.py` を実行すると、標準の `基礎資料\タグ一覧.xlsx` を読み込み、`assets/term-guides.js` と `terms/index.html` を同じページメタデータから生成します。Excelにないタグの用語ページは生成時にエラーにします。別の正本を使う場合だけ `--tag-list` を指定できます。
