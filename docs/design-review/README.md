# 表示改修の確認記録

ポータルと学習アプリを同一オリジンの本番と同じパス構成で検証した。対象はポータル b3e1429 とアプリ 0fb86d0 を基準とする。改修したファイルは両ドラフトPRの Files changed に掲載する。

| 領域 | 主な変更 |
| --- | --- |
| トップ | 円形の学習地図を狭い画面にも表示。主要教材3件、サブ教材、案内の順で入口を整理 |
| 共通UI・解説動画・書籍・案内 | 色・余白の基準、ヘッダー、現在地、フォーカス、本文と一覧の文字サイズを共通化 |
| 用語一覧・用語記事 | 検索入力、表示条件、記事見出しを統一。お気に入り・既読・ハイライトの各状態を維持 |
| 講義ノート | 独自ヘッダー・フッターを共通CSSへ移行。白地の表題、章の余白、用語への導線を整理 |
| 学習アプリ・問題検索 | 設定と開始操作、回答・結果、検索フォームとタグ選択を白と青を中心に整理 |
| 実戦演習 | 受験モード・絞り込み・試験一覧の境界と文字を整理。問題冊子とPDFはそのまま使用 |
| Interactive Lab | 分野内リンク、教材の説明、共通ヘルプ・見出し・ボタンを整理。可視化は各教材が管理 |
| トレース・Studio | 実行画面と一覧の文字・背景に共通色を適用。実行状態・コード色は専用CSSに維持 |

## CSSの棚卸し

[ページ一覧と読み込み順](pages.csv) と [外部CSS一覧と利用元](styles.csv) は両リポジトリを調査した結果。公開配信用HTMLは318件。配信用に加えて原稿・テンプレート等を含めたHTML/HTMは430件。外部CSSは48から51ファイルになった。追加は共通トークン、共通外枠、トップ専用の3ファイル。用語記事4件の同じ見出し用style要素を1ルールにし、Labのインライン色指定を6件取り除いた。公開HTMLのstyle要素は128から124、style属性は4,517から4,511になった。

- 共通層にヘッダー・フッターと横スクロールの手がかりを移し、講義側の重複を削除した。
- 検索入力とラジオボタンの重複、動画分野カードの重複、旧ホーム専用のモバイル上書きを整理した。
- 模試紙面のstyle要素124件は文書デザインとして扱った。Studioの生成物と模試原稿の完全一致するCSSは生成・配布関係を維持するため残した。
- 問題・解説、学習記録やlocalStorage、採点、プログラム実行エンジンは既存のものを使う。アプリの保護ハッシュはスタイルシート1件のみ更新した。

## 検証

| 検証内容 | 結果 |
| --- | --- |
| 18経路 × 375・768・1280px | 54通りをChromiumで測定。ページ全体の横あふれ、ローカル資材の取得エラーは0件 |
| 学習アプリと問題検索 | 分野・問題数の選択、回答・採点、学習履歴復元、キーワード・複数タグAND検索を確認 |
| 用語・講義 | お気に入りのキーボード操作と再読込、講義の開閉・穴埋め・ブックマーク・章リンクを確認 |
| 実戦演習 | 回答、中断、再開、採点、PDFの取得を確認 |
| Lab・トレース | 進数変換、トレースの前進・後退と編集ダイアログを確認 |
| アクセシビリティ | 1280pxの主要9画面をaxeで検査。対象のWCAG A・AA自動検査で検出0件。改修前のトレース一覧では行番号など101要素にコントラスト不足 |
| コードと生成物 | 統合検証、模試の採点・PDF・原稿検証、Studioの型チェック・ビルド・テストに合格 |

ブラウザによる検証では外部への送信を遮断し、集計APIにはテスト応答を使用した。実サービスの統計への書き込み、外部投稿、実機のSafari、全ページの手動操作や支援技術での読み上げは検証範囲外。
