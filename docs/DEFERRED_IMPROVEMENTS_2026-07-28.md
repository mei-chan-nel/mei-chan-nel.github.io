# Study Atlas 保留改善の調査メモ

調査日: 2026-07-28

この文書は、今回の安全な改善と混在させなかった変更の現状、実施条件、検証条件をまとめたものです。ここに挙げたファイルの削除、問題 JSON の分割、公開 URL の変更は実施していません。

## 1. 互換用ファイルと公開 URL

ポータル 164 ファイル、学習アプリ 142 ファイルの追跡対象を SHA-256 で比較しました。500 bytes を超える完全同一ファイルの組は見つかりませんでした。ページ番号付き HTML は別の問題範囲を掲載するページであり、単純な複製ではありません。旧タグ URL は物理ファイルの複製ではなく、タグ別一覧に埋め込んだ別名対応で維持されています。

したがって、現時点で安全に一括削除できる「同一ファイル群」は特定できませんでした。名前や構造が似ているという理由だけでページを統合すると、相対 URL、直接アクセス、履歴、キャッシュ、404 処理、canonical、サイトマップ、既存の公開 URL を壊す可能性があります。

別案件で整理する場合は、次の順序を推奨します。

1. 公開サーバの 60～90 日分のアクセスログから候補 URL の直接流入と参照元を確認する。
2. 旧 URL、正規 URL、内部相対リンク、canonical、サイトマップの対応表を作る。
3. クライアント側の meta refresh ではなく、ホスティング層で恒久リダイレクトを設定できるか確認する。
4. ブラウザ履歴、キャッシュ済み HTML、404 ページ、検索エンジン、共有済み URL をステージングで確認する。
5. 旧タグ URL と全内部リンクを含む統合検証を通した後、候補を一つずつ移行する。

## 2. GIF フォールバック

5 個の GIF は合計 2,855,135 bytes です。対応する WebM、MP4、静止画ポスターはすでにあり、動画ソースは表示領域へ近づくまで `data-src` のまま遅延読込みされます。GIF は `<video>` 要素内のフォールバック内容として残っています。

| 図 | GIF | WebM | MP4 | ポスター |
|---|---:|---:|---:|---:|
| DNS 名前解決 | 489,216 | 74,456 | 107,642 | 117,124 |
| パケットルーティング | 1,120,959 | 158,554 | 203,991 | 188,652 |
| 公開鍵暗号 | 529,093 | 111,889 | 245,114 | 93,471 |
| 共通鍵暗号 | 389,296 | 91,979 | 111,540 | 78,163 |
| TCP/IP カプセル化 | 326,571 | 57,949 | 85,088 | 86,215 |

現在の対象ブラウザ方針が明文化されていないため、削除は見送りました。HTML の `<video>` を理解しないブラウザでは内部の GIF が代替内容になります。一方、動画要素には対応するが WebM/MP4 のデコードに失敗する環境で、内部 GIF が必ず表示されるとは限りません。

削除判断には、最低対応ブラウザと OS の決定、WebM/MP4 の実機確認、コーデック不成立時の挙動確認が必要です。削除後は、ポスター画像と同等の代替テキストを常に利用できる明示的なエラー表示へ置き換え、Safari/iOS、Chrome/Android、主要デスクトップブラウザ、低速回線、`prefers-reduced-motion` を確認してください。

## 3. 問題 JSON の分割

`completed_questions.json` は 3,212,148 bytes、gzip 422,418 bytes です。Node.js で 25 回解析した参考値は中央値 9.461 ms、95 パーセンタイル 10.205 ms でした。今回、学習アプリと不備報告が同じ取得・JSON 解析 Promise を共有するようにしたため、同一画面での重複取得と重複解析は解消しています。

現時点では分割しません。分野別の遅延読込みは初期転送を減らせる一方、全分野抽選、共有挑戦 URL、問題 ID の解決、問題一覧との整合、エラー時の再試行を複雑にします。

別案件で検討する場合は、実利用環境の RUM で転送時間と JSON 解析時間を計測し、低速端末で問題が確認された場合に限り、軽量 manifest と分野別 shard の試作を比較してください。1,000 問、問題 ID、選択肢 ID、正答対応、抽選結果の非重複、共有 URL、不備報告を同じ統合テストで確認することが導入条件です。

## 4. 大容量タグ HTML

`questions/tags.html` は 2,408,075 bytes、gzip 312,433 bytes です。JavaScript 無効時にも 1,000 問を閲覧できる要件と、静的なタグ別問題カードを維持するため、今回は縮小していません。

将来変更する場合も、JavaScript 無効時の全文閲覧を失うクライアント描画への置換は避けます。静的ページ分割やサーバ側生成を候補とし、旧タグ URL、単独タグ検索、複数タグ OR 検索、検索欄、10 問ずつの追加表示、canonical、サイトマップを同時に検証してください。
