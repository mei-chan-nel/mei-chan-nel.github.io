# Study Atlas デザインガイド

## 色と文字

本文を載せる紙面は白、周囲はごく薄いグレー、見出しは深い緑灰色にする。リンクやフォーカスには青緑を使う。トップのキャッチコピーは公開版の改行と赤茶を使う。教材へのカードは白地に揃え、縁の一部に深緑を使う。

| 用途 | CSS変数 | 値 |
| --- | --- | --- |
| ページ背景 | --atlas-bg | #F7F8F8 |
| 紙面・フォーム背景 | --atlas-surface | #FFFFFF |
| 補足背景 | --atlas-soft | #EDF2E9 |
| 見出し・本文 | --atlas-ink | #263E35 |
| 補助文 | --atlas-muted | #526354 |
| 開始・再開・再挑戦 | --atlas-action | #306653 |
| 次へ・採点などの操作 | --atlas-control | #526456 |
| リンク・フォーカス | --atlas-accent | #356459 |
| キャッチコピーの強調 | --atlas-terracotta | #B94732 |
| 境界線 | --atlas-line | #D9DED1 |

本文は日本語のゴシック体を使い、16px相当を基本とする。読み物は行高1.7〜1.9を目安にする。トップ・記事タイトルの明朝体には、共通の見出し用フォントを利用できる。章見出しは画面幅に応じて拡縮し、説明文や操作ラベルよりはっきり大きくする。正答・誤答、実行行、グラフの系列や図の色には、それぞれの凡例と意味を優先する。

## 読み込みと共通部品

1. 通常ページは assets/site.css を読み込む。ここから atlas-tokens.css、atlas-shell.css の順に読み込み、サイト共通のヘッダー、現在地、キーボードフォーカス、フッターを適用する。
2. ページに固有のスタイルを、その後に読み込む。ホームは assets/home.css、用語は assets/term-page.css、Labは lab/lab.css と各教材CSS、実戦演習は mock-exams/app.css を使う。
3. 講義本文は LectureNote/lecture-note.css を入口とし、同じトークンと外枠だけを読み込む。教材の図表・穴埋め・拡大表示・印刷は講義側が管理する。
4. 学習アプリ・問題検索は隣接リポジトリの app/styles.css と assets/question-search.css が担当する。共通CSSの取得が遅れた場合にも読めるよう、主要な変数には既定色がある。

通常の遷移はリンク、状態変更はボタンを使う。主要なリンク型ボタンには既存の button と button-primary クラス、補助操作には button と button-ghost を組み合わせる。ナビゲーションでは aria-current、押下状態では aria-pressed、開閉には details と summary を使う。状態は文字・記号・形でも判別できるようにする。フォームにはラベルを付け、入力文字は原則1rem、押しやすい高さは44pxを目安とする。

画面左右は --atlas-gutter、カードや入力欄は --atlas-radius（10px）、境界は基本1px。カード間はおおむね12〜20px、セクション間は内容に応じて32〜64pxを使う。本文の区切りは細い罫線と見出しを基本とし、影を使う場合は --atlas-shadow を選ぶ。

## 新しい教材を加えるとき

既存の近いページを起点にする。共通ヘッダー、既存のJavaScriptが使うID・クラス・data属性、非表示・印刷・キーボード操作の契約を確認する。教材固有CSSは教材ルートのクラスに範囲を絞る。図表、コード、PDF、ゲーム盤面、採点色は教材側で定義する。StudioのCSSは projects/program-trace-studio/public/studio.css を編集してビルドする。Lab一覧は lab/tools/build-pages.mjs の生成元も更新する。

375・768・1280pxで操作、選択時の表示、横あふれ、フォーカスを確認する。コードや大きな表はコンテナ内でスクロールできるようにする。既存データでの採点・保存・再読込を、両リポジトリをつないだプレビューで確かめる。統合検証のコマンドはREADMEを参照。
