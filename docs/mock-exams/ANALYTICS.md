# 模試のGA4計測

本番の`mock-exams/index.html`だけに共通GA4タグ（`G-JEG0V1ZZF2`）を1回設置する。問題・解説のiframe、原稿、接続診断ページには設置しない。本人専用Sitesのプレビュー生成時はタグを除く。

| イベント | 記録する操作 |
|---|---|
| `mock_exam_start` | 新しい受験を開始したとき。再開・再読み込みは含めない |
| `mock_exam_grade` | 採点を実行したとき。`grading_type`: `final`（終了）、`interim`（途中採点）、`timeout`（時間切れ） |
| `mock_exam_pause` | 中断を実行したとき。`pause_type`: `ungraded`（採点せず中断）、`graded`（途中採点して中断） |

共通パラメーターは`exam_id`、`exam_version`、`exam_mode`（`timed` / `untimed` / `section`）、`section_id`（大問別では`q1`等、通しでは`all`）。途中採点して中断すると、採点と中断を1回ずつ記録する。ダイアログを開いただけ・キャンセル・復習・解説閲覧では記録しない。サンプル履歴も除外する。

回答・得点・解答時間・個別の受験IDや保存データは送らない。ページURLからはクエリとハッシュを除く。Analyticsが遮断・失敗しても、受験・端末保存・Supabaseの採点単位別集計には影響しない。

GA4のイベント件数は上記イベント名で確認できる。モード・大問・採点区分でレポートを分ける場合は、GA4の「管理 → データの表示 → カスタム定義 → カスタムディメンションを作成」で、必要な上記パラメーターをイベントスコープで登録する。登録後のデータが対象となる。ブラウザテストはタグの初期化と送信キューへの発火を確認し、GA4管理画面の受信・集計結果は別途確認する。
