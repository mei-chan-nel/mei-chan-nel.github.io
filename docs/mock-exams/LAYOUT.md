公式PDFの章立て・空欄・解答群・プログラムの行番号を確認した。公式問題は複製せず、No.001の原稿の本文・図表・選択肢を使用する。Web取得ではPDFのスクリーンショットを安定して取り出せず、公式冊子とのピクセル単位の比較は未完了。

## 表示

PC: 白い用紙、明朝体、黒い矩形解答欄、独立した選択肢番号、原稿のページ区切りと図表・プログラムを保持。タイマー・解答状況は用紙外。原稿固有CSSはiframeで隔離。第1問のB5系設定をA4相当に補正する。

モバイル: 本文16px以上を基本に連続表示。冊子のページ境界・繰返しヘッダーを隠し、表とプログラムを必要な範囲だけ横スクロール。タップ入力のシートは画面下部で最大48dvh、4×4キーと現在の欄が見えるように配置。図の拡大は別ダイアログで表示。

印刷: A4、表紙なし、第1問から32ページ。右下に「情報Ⅰ StudyAtlas 実戦模試 No.001」。原稿の選択肢が印刷下端から欠落する問題を発見し修正した。ページごとに実際の高さを測って必要な場合だけフィット。第3問の解答群を印刷時の2列配置に戻したため、第3問は全ページ等倍で収まる。第2問Bの1ページは約97.9%、第4問の1ページは約91.7%にフィット。公式冊子との字級の精密な統一は引き続き調整対象。

## 確認済み

- 原稿と生成HTMLの本文文字列が空白正規化後に一致。
- 原稿と生成HTMLのimg/svg要素数が一致。
- PDF全67ページがA4。画面とPDFで参照する問題内容は同じ原稿。
- PDFから抽出したテキストに長い本文断片の欠落なし。モバイル専用の図の代替説明・SVGメタデータは印刷比較から除外。
- PC1440px、スマートフォン390pxの5区分でブラウザ表示を確認。後者で本文全体の横はみ出しなし。
- 特に第3問のプログラム、データ分析の散布図、スマホキーパッドをスクリーンショットで確認。

## 残す確認

- 公式PDFとの詳細な字級・行送り・余白・図表配置の比較。
- Safari/iOS実機のスクロール・PDF保存とソフトキーボード。
- Chromiumでは768×1024・1024×768・844×390の表示も追加確認済み。iPad実機は未確認。
- 解説の制作・検証情報を学習者向け解説から折りたたむ編集（現状は原稿を保持）。

追加検証: タブレット／横向きの3サイズで本文横はみ出しなし。PC受験画面のaxe WCAG2A/AA自動検査で違反0件（iframe内を含む全アクセシビリティの保証ではない）。PDFは必要な出典用フォント文字だけを埋め込み、問題約2.0MB・解説約3.0MBへ軽量化。
