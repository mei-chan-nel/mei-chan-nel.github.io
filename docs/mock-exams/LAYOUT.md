# 画面・PDFの表示方針

## 画面

- 本文はStudy Atlasと同じシステムフォント。原稿のCSSをiframeで隔離し、図表・プログラム・選択肢を保持する。
- 受験中はグローバルヘッダーを隠す。大問ナビと戻る操作を同じ高さに置き、右メニューは紙面上端からスクロール追従する。850px以下では受験中の上部問題番号ナビを常に非表示にする。復習・解説の戻る操作は表示する。
- 解答欄には記号と回答を併記。ポップアップは×・外側クリックで閉じる。数字／文字のキーは欄の近くに表示し、「確定」または外側クリック／タップで入力を保持して閉じる。右メニューは該当問題へのジャンプだけ。
- PCの解説は左右の問題・解説を採点単位ごとに整列。No.001は44単位を41箇所で対応させる。160px以上の余白は「位置を合わせるための余白です。」だけを表示する。
- 狭い画面は大問名5ボタンで解説を選ぶ。設問ごとの問題表示は必要な部分だけを表示し、共通資料は展開できる。元の解説位置へ戻る。
- スマホは本文16px以上を基本とし、長い表・プログラムだけを横スクロール。図は拡大できる。画面用HTMLから印刷用埋込フォントを外し、先読み・キャッシュする。

- 原稿の版番号・左右の柱・原稿内ページ番号は画面用HTMLから除く。親ページで縦スクロールし、iframe自体には縦スクロールを残さない。body内のページ余白を高さに含め、端数を切り上げて枠を追従させる。
- 完成プログラムの直後に、小さな「トレースStudioで動かす」リンクを置く。別タブで開き、解説の位置を保持する。

## PDF

A4、問題冊子は表紙なしで第1問から開始。右下に「情報Ⅰ StudyAtlas 実戦演習 No.001」等の出典、中央に通しページ番号。印刷の書体は画面とは独立させる。

大問見出しは「第n問」を14ptの太字、続く案内文を10.5ptの通常の太さに統一する。設問番号の「問n」は全大問で太字にし、続く問題文は通常の太さとする。`data-question-number`を番号部分だけに付け、画面・PDFで共通に扱う。第4問の設問番号は本文と同じ行頭に置く。本文・解答欄・設問別資料の対応属性を保持する。書式だけの変更では問題版を上げない。

No.001の現行版2は問題33ページ・解説34ページ。画面と同じ原稿・承認済み文言修正から生成する。問題の各ページを実測して必要時だけ縮小し、80%未満になると生成を失敗させる。本文の長い断片がPDFから欠けていないことを検査する。CFFの日本語フッター書体はglyph IDを保って部分埋込みし、本文抽出だけでなく描画も確認する。

## 確認範囲

PC・390pxのブラウザ操作、900pxの解説、問題／解説の整列と復帰をChromiumで確認。全PDFがA4で、本文・図の照合が通る。検証コマンドと結果は[README.md](README.md)、[REVIEW-2026-10-28.md](REVIEW-2026-10-28.md)。

Safari/iOS実機のスクロール・キーパッド・PDF保存は未確認。大学入試センターの公式冊子を複製せず、ユーザー原稿の問題を用いる。公式冊子との字級・行送りの精密な一致は保証しない。
