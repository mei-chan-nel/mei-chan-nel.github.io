# 画面用教材の編集ルール

- 画面のソフトウェアキーボードは0〜9・A〜Fを直接入力する。A〜Dをⓐ〜ⓓへ置き換えてマークする旨の紙向け注記は表示しない。
- 文字を入力する空欄の指示は「当てはまる文字を答えよ」とする。
- 元原稿はsource/に保存し、承認済みの文言変更をインポーターに適用する。画面・配布PDFを整合させる。
- 画面はStudy Atlasと同じシステムフォント。印刷用の書体は独立したprintスタイル。

- 解説は正答の導き方と誤答の理由を中心にする。作問方針、測定設計、開発用の検証報告、問題を離れた一般論を学習者向けの末尾へ付けない。必要な出典は残す。
- 設問別の問題表示では、その設問と理解に必要な共通の文章・図表・プログラムだけを指定する。

- 文字を直接答える欄では、解説・PDFにもⓒ等のマーク表現を残さず、実際に入力するC等で示す。
- 採点表の設問番号は問題本文の問番号と一致させる。a/bを別の問として増番しない。
- 正答・配点・設問番号の確認データをsource/qa.jsonへ残し、採点定義とは独立に原稿から照合する。
- 元原稿のファイル名・SHA-256を記録し、承認済み編集はアダプターに残す。再生成時に他の模試・旧版・catalog.jsonを上書きしない。

- 誤答理由は「誤読・混同した場合」だけで終えず、問題の条件や具体的な数値を示し、何を満たさないため不適・誤りなのかを明記する。
- 完成プログラムは既存のトレースStudio共有形式につなぐ。添字の開始、初期値、必要な外部入力と最終結果まで照合する。
