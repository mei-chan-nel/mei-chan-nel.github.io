# 統計・データ分析シリーズ 実装・検証報告

最新main `42411e1` から `feat/statistics-interactive-labs` に分岐して制作しました。mainには変更を加えていません。

## 実装

`/lab/statistics/`、指定9ラボ、`/lab/statistics/projects/` を新設。既存のHTML・ES Modules構成とStudy Atlasのシェル・色・ナビゲーションを使用しました。Interactive Lab、統計の講義ノート、データサイエンスの用語ページ、サイトマップから移動できます。

| ラボ | 主な体験 |
|---|---|
| 相関・回帰 | 点の移動・追加・削除、外れ値、手動最小二乗、残差の正方形、学習から外した実測点による予測検証 |
| ヒストグラム | 生データ編集、階級幅・開始位置、集団の分離／合成、度数・相対度数・累積、表と点の連動 |
| 代表値・ばらつき | 点と箱ひげ図、平均固定の再配分、偏差の倍率、分散n／n−1、計算過程 |
| 標本調査 | 可視母集団120人、無作為／偏りのある非復元抽出、反復分布、標準誤差・区間被覆 |
| クロス集計 | 人数編集、行／列／セル比率、分子・分母、属性別と全体、シンプソン逆転、構成調整 |
| 時系列 | トレンド・季節・乱数成分、移動平均、伸び率・前年同月比・指数化、4予測法と保留期間誤差 |
| 確率分布 | コインの相対度数経路、二項分布の形成と理論比較、正規分布の区間面積・標準化 |
| 仮説検定 | A/B差と人数、帰無分布、両側p値・棄却域、誤判定・検出力、実用的差 |
| ローレンツ | 所得編集／ドラッグ、総額固定・移転、累積表、面積とジニ、同じ平均・ジニの異なる分布 |

各ラボに3つ、計27の任意ミッションを用意しました。条件設定・自由実験・予想／発見の記録・自己振り返りを組み合わせています。比較条件の保持、初期化、自動保存、JSON保存・読込、横断課題への結果記録を共通化。乱数シミュレーションはシードで再現できます。

横断課題では独自の架空24人データを編集し、分布・代表値・相関へ引き継げます。結果を持ち寄り、問い・根拠・限界・結論をテキストとして書き出せます。個別ラボは課題を経由せず使えます。

## 制約

- 提供ZIPは転送ツールの32MiB上限を超え、展開・内容確認ができませんでした。参考にしたのは放送大学の公開Web教材です。文章・図・データは独自制作です。
- 保存はブラウザ内・同一オリジン内。別端末へはJSONを利用します。Sitesと本番サイトの保存領域は別です。
- 横断課題は2〜300行。ヒストグラムは2群表示で、3群以上は最初の群とその他にまとめ、元の群名を表示します。
- 標本推定の区間は既知の母標準偏差を使う教育用の正規近似です。偏りのある抽出や小標本への解釈上の制約を画面で明示しています。
- p値は有限反復のモンテカルロ近似、正規CDFは数値近似です。反復回数には画面上の上限があります。
- ChromiumのPC／モバイル幅・タッチエミュレーションを使用しました。実機の全ブラウザ組合せは未検証です。

参考：[放送大学「身近な統計」](https://www.ouj.ac.jp/mijika/mijika/)。保守・保存形式・計算定義は `lab/statistics/README.md` を参照してください。
