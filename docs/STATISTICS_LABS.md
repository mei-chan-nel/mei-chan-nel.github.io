# 統計ラボ 実装・検証報告

作業ブランチは `feat/statistics-interactive-labs`。mainにはマージしていません。

## 最新の画面と操作

- 統計トップは、既存Interactive Lab一覧の番号・本文・矢印を持つ共通カードを使用。データ持込の大きな案内枠を削除しました。
- 各ラボに先頭の「データ」タブを追加。使用中の値・項目名・件数を表で確認し、サンプルを使用、CSVでダウンロード、CSVでアップロードできます。CSVの内容・列の確認は同じタブ内で行い、貼り付けにも対応します。
- 実験上部のデータ案内枠・自分のデータを使うボタン・初期化を撤去。データの操作はタブ内へ集約しました。
- ミッションと文章記録を削除。比較に残す・比較を見る・記録保存・JSONファイル操作も撤去しました。
- 平均固定時の標準偏差、相関係数の変化、集団構成による逆転などを、現在の状態に応じた短い説明でグラフの近くに示します。既存のドラッグ・スライダー・試行追加・分母強調・残差・再分配などを直接触って学べます。
- サンプルは毎回新たに乱数生成。教材の意味が保たれるよう、二群の分布や逆転などの構造を保ちます。操作中のデータは固定し、条件の影響を比べられます。
- 確率ラボも実際の観測値をCSVで読み込めます。コインの0/1、1セットの成功回数、連続値を、そのまま保って理論と比較します。正規分布では実測の区間内割合と理論面積を区別して表示します。
- 横断課題は「データ」「分析方法を選ぶ」「特徴を見比べる」の構成。使用した同じ元データを自動集計し、文章の記入は要求しません。
- 説明は目的・基本操作・下部の項目別折りたたみを保持。固定高さや内容の内部スクロールは設けません。

## 検証

統計計算・CSV変換・例外条件・読込データの復元に加え、乱数サンプルの再現性と変化、100通りのクロス集計の逆転、ヒストグラムの移動後のCSV、確率の読込値の固定、異なる尺度の正規モデル・CSV項目名の保持を含む61テストが成功しました。

全11ページのPC・タブレット・スマートフォンで、データと分析の表示切替、横はみ出しと内部スクロールを確認。各ラボのCSVファイル実読込・書出、サンプル再生成、再訪時の復元、無効値の拒否、貼り付け、直接操作と説明の更新、横断データ連携をブラウザで確認しました。

ポータル128ページとサイトマップ、既存ラボ生成、広告配置対象110ページの整合も検証しました。

## 制約と参考

CSVはUTF-8で1MB以内、各ラボごとに行数や形式の上限があります。時系列は非負の48か月分、クロス集計は2集団×2方式です。確率の読込は1〜10,000行、他の一般数値データは2〜300行です。データの保持はブラウザ・オリジン内です。別端末へはCSVで渡します。Chromiumの画面サイズとタッチエミュレーションによる検証で、実機の全ブラウザは未検証です。

提供された教材レビュー要約2点は参考として扱い、各章の追加候補を必須仕様として実装することはしていません。公開の放送大学「身近な統計」も参照し、文章・図・題材・データは独自制作しました。元ZIP・展開教材・要約の添付ファイルはリポジトリへ含めません。
