# 統計ラボ 実装・検証報告

`feat/statistics-interactive-labs` で管理しています。mainにはマージしていません。

## 目的とデータの扱い

各ページの冒頭に「何を調べる場所か」を一文で明示。続けて、使用データの出所・名前・列名・単位・件数、行った集計や回帰等の処理を表示します。自分のデータと架空の教材サンプルを区別し、編集した行の数も表示します。

確率モデル以外の8ラボで、CSV／TSVファイルと表計算ソフトからの貼り付けに対応しました。列を選び、内容を確認してから分析します。実験JSONの保存・復元とは別の操作です。自分の元データに戻す操作、使用データと処理を含む分析記録も用意しました。形式と上限は `lab/statistics/README.md` に記載しています。

## 画面の整理（説明・リンクの再調整）

- 一覧はラボへのリンクであることが明確なカード。タイトル・問い・入力・得られる結果・「ラボを開く →」を表示し、カード全体をリンクにしています。通常のテキストリンクには下線、操作には実ボタンを使います。
- 既存のリレーショナルデータベース・進数変換等の導入と操作説明を参考に、各ラボ冒頭に目的と概念を説明。教材サンプルには具体的な題材、自分のデータにはそのデータで試す操作を表示します。
- 一画面への固定高さ、グラフ・操作欄・表・横断課題の内部スクロールを撤廃。ページ全体が内容に合わせて伸びます。表のセルは折り返し、グラフの文字と操作点は表示サイズでも読み取り・操作しやすいよう再配置します。
- グラフ／計算表は分析目的別のタブで切り替え、図の近くの読み取り・操作説明は常時表示します。補助的な設定は項目名を示して開閉します。
- 3つのミッションはページ内のカードへ移動。条件設定ボタンは「教材サンプルをセット」とし、読込データから切り替わることを明示しました。
- 学問的な解説はページ下部に配置し、定義・計算過程・読み取り・前提と限界を項目別に折りたたみます。従来の本文は削らず保持しています。
- 比較はページ内で同じ分析表示を開きます。サイト共通フッターも通常の構成へ戻しました。CSV読込と保存の補助フォームはダイアログです。
- 横断課題は「データ確認」「分析方法」「記録・結論」の3手順。読込列名に合った問いを示します。

## 今回の参考資料の扱い

ユーザー提供の2点のMarkdown要約を参考として確認しました。文書内のP0/P1/P2や追加候補は必須の作業指示と扱わず、依頼された説明・導線の改善に合う観点を採用しました。質的データの棒グラフと量的データのヒストグラムの違い、欠測と実測の0の区別、問いに合った手法選択、分析結果の限界を、独自の文章でトップと横断課題の下部解説に補いました。新しい機能を一括追加したものではありません。今回の内容は既存ページ内で目的がまとまるため、ページは増やしていません。

## 制約

数値データは1MB以内で、ラボごとの行数・形式に上限があります。時系列は非負の48か月分、クロス集計は2集団×2方式です。標本調査では読込全行を教材内の母集団とし、その外側の集団についての代表性は判断しません。

保存はブラウザ内・同一オリジン内です。別の端末へはファイルで渡します。区間推定・シミュレーションの前提と数値近似の制約は各ラボの解説に明記しています。ChromiumのPC／モバイル幅とタッチエミュレーションによる検証で、実機の全ブラウザ組合せは未検証です。

元ZIPそのものは転送上限で確認できていませんが、今回提供された教材レビュー要約2点を確認しました。公開教材の参考は[放送大学「身近な統計」の公開Web教材](https://www.ouj.ac.jp/mijika/mijika/)。文章・図・データは独自制作で、ZIPや展開教材を公開リポジトリに含めません。
