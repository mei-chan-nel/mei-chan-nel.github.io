# 統計ラボ 実装・検証報告

`feat/statistics-interactive-labs` で管理しています。mainにはマージしていません。

## 目的とデータの扱い

各ページの冒頭に「何を調べる場所か」を一文で明示。続けて、使用データの出所・名前・列名・単位・件数、行った集計や回帰等の処理を表示します。自分のデータと架空の教材サンプルを区別し、編集した行の数も表示します。

確率モデル以外の8ラボで、CSV／TSVファイルと表計算ソフトからの貼り付けに対応しました。列を選び、内容を確認してから分析します。実験JSONの保存・復元とは別の操作です。自分の元データに戻す操作、使用データと処理を含む分析記録も用意しました。形式と上限は `lab/statistics/README.md` に記載しています。

## 画面の整理

- 一覧は、各ラボの入力と結果を見比べるためのコンパクトなリンク一覧。
- PCの基本画面は、目的・使用データ・処理・グラフ・主要操作が1画面に収まる構成。
- グラフ／計算表はタブで切替。予測や標準化など、ラボ固有の表示と操作を保持。
- ミッション・解説・比較・記録／保存は必要なときに開く画面へ移動。
- 装飾バッジとイメージ図を削除。操作可能なものにボタン、タブ、リンクを使用。
- 描画領域に合わせてSVG座標を再配置し、文字や点の操作領域を縮小せずグラフを表示。
- サイト全体の案内はヘッダーと、フッターの開閉メニューに保持。統計の実験画面に広告枠は置かない。
- 横断課題は「データ確認」「分析方法」「記録・結論」の3画面。

## 検証

- 統計計算・CSV変換・単位／列の保持・不正データ・元データ復元・既存保存の移行を自動テスト。
- PCの1440×900・1366×768、スマートフォン390pxで11ページと表示切替を確認。PC基本画面の縦はみ出し、各幅の横はみ出しなし。
- 8ラボの持ち込みデータ、CSVファイルの実読込、貼り付け、再訪復元、不正入力時の保持、横断課題への引き継ぎを確認。
- ドラッグ、表示切替、比較、JSON往復、分析記録、レポート保存を確認。
- 全27ミッションの表示・条件設定／記録と、ラベルに記号を含むCSV、見出しなし入力、所得の単位、モバイル比較表示を確認。
- 描画領域を変更した後も、散布図・ドットプロットのドラッグ座標が正しく数値へ戻ることを確認。
- ポータル128ページとサイトマップ、既存ラボ生成、広告配置対象110ページの整合を検証。

## 制約

数値データは1MB以内で、ラボごとの行数・形式に上限があります。時系列は非負の48か月分、クロス集計は2集団×2方式です。標本調査では読込全行を教材内の母集団とし、その外側の集団についての代表性は判断しません。

保存はブラウザ内・同一オリジン内です。別の端末へはファイルで渡します。区間推定・シミュレーションの前提と数値近似の制約は各ラボの解説に明記しています。ChromiumのPC／モバイル幅とタッチエミュレーションによる検証で、実機の全ブラウザ組合せは未検証です。

提供ZIPは32MiB転送上限で確認できていません。参考は[放送大学「身近な統計」の公開Web教材](https://www.ouj.ac.jp/mijika/mijika/)。文章・図・データは独自制作で、ZIPや展開教材を公開リポジトリに含めません。
