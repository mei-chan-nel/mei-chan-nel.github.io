# 用語一覧の学習支援機能

`generate_term_guides.py` が用語のメタデータ、タグ順、学習アプリの公開問題データを読み、一覧・検索用本文・問題タグ対応表を生成します。記事本文は通常のHTMLが正本です。用語ページの追加・本文更新・問題タグ更新後に実行します。

```sh
python scripts/generate_term_guides.py --app-root ../info1-quiz-app
python scripts/generate_term_guides.py --app-root ../info1-quiz-app --check
```

生成対象は `assets/term-guides.js`、`terms/index.html`、`data/term-search.json`、`data/term-question-tags.json`、各用語ページ内の共有機能ブロック・読み込みタグです。機能ブロックの適用は何度実行しても同じ結果になります。note移行用の生成元も同じ処理を使います。新規ページには `study-atlas-term-tag` メタデータ、`term-heading` と `term-explanation` のIDを設定し、正本のタグ一覧にあるタグを使います。

検索データには記事の見出し・解説本文のみを収録します。共通ナビゲーション、広告、例題・選択肢は含めません。記事タイトルと一覧の用語名が異なる場合は両方をタイトル検索の対象にします。NFKC正規化と小文字化後の部分一致、空白区切りAND検索です。検索結果はタイトル完全一致、前方一致、部分一致、本文一致の順とし、複数語ではタイトルに一致する語数・一致度も比較します。同順位はおすすめスコア、または元のタグ順を使います。本文にも一致した記事には原文の短い抜粋を、改行・句点などから判断した文頭から、後ろを長めに表示します。一致語は太字で示し、用語リンク・抜粋リンクから本文内の一致箇所へ移動し強調表示します。

検索語の入力・変更と決定キーで表示対象を「用語一覧」、絞り込みを「すべて」に広げます。検索はこの最大範囲のみで行います。検索中に表示対象・絞り込みを変更すると検索欄を空にし、選んだ条件の通常一覧へ戻します。IME変換確定を除く決定キーでは検索欄をblurし、スマートフォンのキーボードを閉じられる状態にします。本文のジャンプ先は黄色の背景だけで示します。

本文JSONは初めて空白以外の入力があったときに非同期取得し、ページ内で保持します。フォーカス、一覧・既読・お気に入りの切り替えでは取得しません。取得中の入力を妨げず、完了時の最新入力で再描画します。失敗時は通常の一覧と再試行ボタンを表示します。おすすめ用の問題タグJSONは誤答履歴がある場合におすすめを表示するときだけ別途取得します。こちらの失敗時も同じ絞り込み条件の通常一覧へフォールバックします。

`term-state.js` の `CONFIG` に推薦係数と既読判定の10秒・到達率0.7（どちらか一方で既読）をまとめています。各問題は解答回数によらず一度だけ集計し、複数タグへ同じ評価を反映します。誤答経験なしの正答済み問題はCに1、誤答経験あり・最終誤答はWに1、誤答経験あり・最終正答はWに0.5を加算し、`S = W * (0.5 + 0.5 * W / (W + C))` を計算します。W=0はS=0です。正のスコアだけをおすすめに表示し、上限を設けません。既読・お気に入り・検索順位はスコアを変えません。

既存の `info1LearningRecord:v1` を読み取ります。旧 `info1QuizStats:v4` にも対応しますが、旧形式からの移行直後など最終正誤が未記録の場合は、誤答経験のある問題をW=1として扱います。次の解答で最終結果が保存されれば通常の1／0.5評価になります。学習アプリの履歴データを書き換えず、苦手重点出題にも変更を加えません。

ブラウザの保存キーは次のとおりです。

| キー | 内容 |
| --- | --- |
| `studyAtlasTerms:v1` | 用語タグごとの既読・お気に入り・前面表示時間・本文の最大到達率 |
| `studyAtlasTermPreferences:v1` | 表示対象と絞り込み条件。検索文字列は保存しません |

お気に入りと既読は独立しています。登録・解除では既読状態を変えず、未読のお気に入りも保存できます。既読は累計10秒または本文70％到達のどちらかで記録します。時間は表示中かつフォーカスがある間だけ加算し、本文の下端まで見えれば短い記事は到達率1になります。時間・到達率は再訪時に引き継ぎ、非表示中・別ウィンドウに移った間・BFCacheに退避中の時間は加算しません。保存は約1秒ごととページ離脱時に行います。一覧と個別ページの既読・未読ボタンで手動変更できます。未読に戻すと時間と到達率をリセットし、そのページを開いている間の自動既読を抑制します。次に解説ページを開くと自動判定を再開します。

同じブラウザの別タブはstorageイベント、戻る操作はpageshowで同期します。保存が利用できないときは画面内で状態を保持し、保存できない旨を表示します。JavaScriptを利用できないときも静的な全用語リンクを利用できます。学習履歴・検索語・既読・お気に入りをネットワークへ送る処理はありません。

## 検証

```sh
node --test scripts/term-learning.test.mjs
python -m unittest discover -s scripts -p term_generation_test.py
python scripts/validate_study_atlas.py --portal-root . --app-root ../info1-quiz-app
```

ブラウザ回帰確認はPlaywright、axe-core、Chromiumを使います。依存パッケージは任意の開発用ディレクトリへインストールできます。公開用ファイルには含めません。プレビューサーバーを起動した後、次を実行します。

```sh
python scripts/preview_site.py --host 127.0.0.1 --port 8773
# 別のターミナルで実行。各モジュールは通常のNode検索パス、または環境変数で指定します。
node --test scripts/term-browser-check.mjs
```

`PLAYWRIGHT_MODULE`、`AXE_MODULE`、`CHROMIUM_PATH`、`TERM_TEST_URL` で環境に合わせた配置・URLを指定できます。初回入力の取得回数、遅延・失敗・不正データ・再試行、8通りの表示条件、キーボード操作、別タブ共有、時間と到達率、短い記事、保存不可、JavaScript無効時の表示、スマートフォン幅での横はみ出しとWCAGの自動検査を確認します。タイマー検証にはPlaywrightの仮想時計を使います。
