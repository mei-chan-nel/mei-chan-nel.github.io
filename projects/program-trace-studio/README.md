# プログラムトレース Studio

既存の例題・動画問題のトレースから独立したTypeScriptプロジェクトです。静的ファイルだけで動き、外部の保存サービス・ランタイム依存ライブラリは使いません。

```powershell
npm.cmd ci --ignore-scripts
npm.cmd run check
npm.cmd test
```

ビルドは `../../program-trace/studio/` へブラウザ用のESモジュール、HTML、CSSを出力します。公開フォルダーの生成物は直接編集せず、ここで変更してビルドします。共通ヘッダー・フッターは `program-trace/index.html` から、トレースの基本デザインは `program-trace/styles.css` から取得します。

実行画面の全画面操作、代入の矢印、変数欄の表示位置の調整、PCのパネル操作とキー操作には、公開版トレースの `fullscreen.js`、`assignment-flow.js`、`variable-scroll.js`、`result-panels.js`、`step-keys.js` をそのままビルド時に取り込みます。問題データや元のインタープリターは読み込みません。これらの共通UIを改良した場合はStudioも再ビルドします。

## 構成

- `lexer.ts`, `expressions.ts`, `parser.ts`：表記・字下げを解析し、命令と式のデータに変換。
- `runtime.ts`, `worker.ts`：Worker内で1行ずつ実行。終了・入力待ち・エラー・世代違いのメッセージを区別。
- `builtins.ts`：組み込み関数のレジストリ。追加時は登録と使用例・テストを追加。
- `builder-model.ts`, `editor.ts`, `builder-moves.ts`：実行画面と同じ行表示。見出し・各行の「＋」で空白行を挿入し、行をタップして4分類から処理を設定。木構造から行番号と「｜」「⎿」を自動生成。フッター操作とドラッグによる移動・入れ子の深さ変更、取消を管理。まとまり・elseの対応を保ち、自己の子への移動や孤立した分岐を拒否。
- `command-editor.ts`, `target-editor.ts`：最初に変数・一次元配列・二次元配列を選び、その種類の既存名／新規名だけを表示。左辺を選ぶ段階のフッターボタンは「右辺を入力」、右辺を設定したら「この行に反映」。
- `builder-variables.ts`：宣言済みの名前と配列の形を抽出。配列のコピーや行参照、外部入力も候補に反映し、未宣言の参照や乱数の実行結果は候補生成に使わない。
- `expression-editor.ts`, `expression-input.ts`, `tap-controls.ts`：右辺・条件はキーボードで式を入力し、候補をカーソル位置に挿入。値の種類は引用符などから判定。配列は自動的に要素の編集欄を提供。変数への配列全体の代入を候補と検証の両方で防止。全角記号・引用符を整え、構文・配列の形・関数引数・既知の計算エラーを安全なパーサーで検証。画面上のパッドも入力補助として利用可能。
- `input-settings.ts`, `value-editor.ts`：行ごとの外部入力設定、初期値・配列の要素／行列編集。
- `runner-view.ts`, `runner-model.ts`, `app.ts`：既存と同じ左プログラム／右解説・変数・出力の画面と操作。Workerが返す代入元・代入先の情報を使って値と要素を強調し、対応する値を矢印で結ぶ。添字を計算する変数は代入元と区別。未実行の枝はそのステップだけ「スキップ」と表示。スマホの横向き全画面、解説・変数・出力の折りたたみ、長い配列の要素省略と全要素表示、代入先への自動スクロールを提供。
- `documents.ts`, `document-actions.ts`, `storage.ts`, `sharing.ts`, `share-packet.ts`：保存形式の検証、ローカル保存、v2の省略命令・設定差分・DEFLATE/非圧縮とBase64urlによるURL共有。v1のgzip JSONも読み込み可能。新規作成時は未保存の変更を確認し、保存成功後にのみ置き換え。ファイルに書出ではファイル名を指定。
- `public/`：HTMLテンプレートとStudioのデザイン。編集・実行で同じプログラム欄の幅を使い、編集時の操作は右側に集約。`file-spec.html.in` は右下の閉じた「ファイルの仕様」に組み込む日本語の読込仕様。
- `test/`：ブラウザ用生成物に対する実行・保存・共有・Worker・ページの契約テスト。ポータルの統合テストにも含みます。

## URLと保存形式

- `/program-trace/studio/`：編集画面。
- `/program-trace/studio/guide.html`：行の追加・設定・保存などの使い方。
- `/program-trace/studio/examples/fibonacci.studio.json`：最初の10項を再帰で求める読込用JSON。日本語のファイル仕様・使い方・AI向け仕様からダウンロードできます。ビルド元は `public/examples/`。
- `/program-trace/studio/ai-guide.md`, `ai-guide.json`：AI向けのファイル生成指示とJSON Schema。HTML headのリンクとコメントから発見できます。編集画面の「ファイルの仕様」を開くと、日本語の規則、自作関数・値なしの呼び出し・再帰のJSON例、完全な仕様へのリンクを読めます。例をテストで読み込み・実行し、ダウンロード版との一致を確認します。
- `/program-trace/studio/share.html#v2.d.<deflate-base64url>` または `#v2.j.<json-base64url>`：共有プログラムの実行画面。「プログラムを編集」で編集へ移れます。静的HTMLで `noindex, follow`、サイトマップに登録しません。受信後も自動実行しません。`#v1.<gzip-base64url>` も引き続き復元します。
- 完成したプログラムは従来の `{ version: 1, title, source, settings: { indexBase, inputs } }` を維持。ファイルには `format: "mei-program-studio"` を付けます。旧ファイル・旧共有URLも本文から行へ変換して編集できます。
- 空のプログラムや内側が空の分岐／繰り返しは、追加の `builder: { version: 1, nodes }` で作成途中の構造を保存します。本文との一致、命令・式・ID・深さ・サイズを検証します。実行前には各まとまりに実行できる処理が必要です。完成後はこのメタデータを省き、共有URLが不要に大きくならないようにします。
- AIには完成した `source` だけを生成させ、`builder` は作成させません。不正なファイルは置き換えの確認前に拒否します。変換できない旧下書きがあった場合は元のデータを保ち、書き出せる復旧ボタンを表示します。
- localStorageは `mei-program-studio:v1:draft` と `mei-program-studio:v1:saved` のみ使用。共有データは利用者が編集・保存するまで下書きを上書きしません。

URL生成の上限は100,000文字、展開後の共有データは180KB。本文は500行・UTF-8で50KB。上限超過や途中で切れたURLなどでは理由とファイルによる代替を表示します。圧縮APIのないブラウザでも非圧縮v2なら生成・復元できます。送信先によって長いURLの扱いが異なるため、2,000文字を超えると案内を表示します。[共有URLの固定ルール・互換性・計測方法](SHARING.md)も参照してください。

## 実行の仕様

行の設定から生成した本文や、読み込んだ本文をJavaScriptとして実行しません。代入、配列要素の代入、表示、外部入力、分岐、範囲ループ、条件ループ、自作関数の定義・呼び出し・戻り値・再帰を専用インタープリターで処理します。自作関数もJavaScriptとして実行しません。

配列は一次元・矩形の二次元まで。添字は全体で0始まりまたは1始まり。配列の代入はコピー、要素の追加は初期値の編集で行い、未代入・範囲外にはエラーを返します。外部入力の形式と範囲はUIとWorkerで検証します。

1行に複数の代入がある場合は同じステップ内で左から処理。繰り返しの見出し、条件の確認、選択された `そうでなければ` の行もステップに含めます。繰り返しの範囲は入るときに一度評価します。乱数も式を評価するときに一度だけ生成し、解説のために再評価しません。リセットで同じ乱数列を再現します。

初期状態は選択行なし。最後の実行結果は緑で表示し、追加の「次へ」で強調を消してボタンを無効にします。結果は保持します。実行中の状態を直接編集せず、初期値変更後は最初から実行します。

PCでは「解説」「変数の値」「出力」の見出しで折りたたみ、枠の下端をドラッグして高さを調整できます。下端にフォーカスした場合は上下矢印キーでも変更できます。高さと折りたたみ状態は実行・リセット時にも維持し、スマホの全画面から戻ったときも元のPCの配置を復元します。
Space・Enterで次のステップを実行し、長押しのキーリピートでも続けて実行します。入力欄・編集画面・ダイアログでは通常のキー操作を優先します。Workerの応答待ち・自動実行・完了後には余分なステップを予約しません。

長いプログラムをレイアウト計測のために先行実行しません。解析時に枠の高さを決め、表示が多い場合は現在参照・変更した要素を含む範囲と「すべて見る」のダイアログを使います。出力履歴は全件保持し、直近3件を表示します。Workerからは出力の追加分を送ります。

上限：10,000ステップ、128変数、配列1つ1,000セル／全体5,000セル、出力1,000件／200,000文字。Workerへの応答が5秒ない場合も停止し、編集へ戻れます。境界値は `errors.ts` で管理します。

共通アクセス解析には共有URLのフラグメントを送らない設定を使います。ブラウザ履歴や共有先ではURLに本文が含まれるため、秘密の情報を書く用途は想定しません。

## 実行を戻す・自作関数

「←前へ」で状態履歴を復元します。Workerの履歴は不変の状態を共有し、配列・出力・ループ・乱数・関数の保留中の式も保持します。完了表示を閉じた操作も戻せます。巻き戻し時だけ出力履歴を再送し、通常は追加分だけ送信します。

編集画面の「関数を定義する」でメインの下に関数ブロックを作り、名前・引数・内側の処理・「値を返す」を設定します。引数は個別の追加・削除欄で設定し、名前の重複・予約語・空欄を確定前に検証。定義行は編集・ドラッグ不可、ブロック右上から未参照の関数を削除し、編集の取り消しで復元できます。戻り値のある関数は右辺の候補、ない関数は「呼び出す」の候補に表示。戻り値の設定中は自身の再帰呼び出しも利用できます。ソースは `定義する 名前(引数)：` と `返す 式`。関数は実行前に登録し、式内／単独の呼び出しに対応。引数とローカル変数は呼び出しごとに独立し、配列はコピーします。入れ子の定義は不可、再帰は32呼び出しまで。式は中断・再開時も評価済みの値を保持し、乱数や複数代入を再実行しません。保存形式v1と共有v2を維持し、共有の命令番号9～11に定義・返す・呼び出しを追加しています。
