# Interactive Lab

情報Ⅰの概念を操作・実験・可視化で理解する教材の入口です。共通の入口と、個別の実験教材を管理します。

学習アプリと同じ6分野で整理します。

1. 社会・セキュリティ
2. デジタル表現
3. ネットワーク
4. データ活用・DB
5. アルゴリズム
6. 情報デザイン

動画解説ページと同じく、カテゴリの見出しの下に個別教材のカード一覧を置く構成です。完成した教材をカテゴリに登録し、一つずつ体験を設計・実装します。個別教材のURLは `/lab/<slug>/` に統一する方針を維持します。

## 構成

- `catalog.mjs`: 6分野の名称と説明、完成した教材の一覧。
- `tools/build-pages.mjs`: 入口 `index.html` の生成。個別ページは生成しません。
- `lab.css`: 入口のレイアウト。既存 `assets/site.css` の配色・ヘッダー・フッターを使用します。
- `navigation.mjs`: ナビゲーションの表示補助。解析・広告スクリプトは読み込みません。

```sh
node lab/tools/build-pages.mjs
node lab/tools/build-pages.mjs --check
python3 scripts/preview_site.py --host 127.0.0.1 --port 8773 --app-root /workspace/info1-quiz-app
```

配信した `/lab/` を開いて確認します。Labの表示にnpmインストールは不要です。

## 暗号通信シミュレーター

`/lab/crypto-communication/`。通信経路の中継機を操作するチャーリーとして、「状況・目的・行動・結果」を追うレトロゲーム風の実験です。経路を通るデータのコピー、復号、編集、再暗号化、すり替え、転送を試せます。3ラウンドと公開鍵の真正性確認の追加実験を収録します。導入と各段階の説明は「次へ」で進めます。通信が中継機で止まった場面では、操作を自由に試せます。全ラウンドへ自由に移動できます。ヒントは折りたたみで提示します。

- `model.mjs`：不透明な暗号文・署名による教育用モデル。秘密のペイロードはモデルの内部に保持し、画面には出しません。
- `app.mjs`：同じ通信図・会話枠を保つ画面と行動メニュー、持ち物・道具のダイアログ。
- `commands.css`：道具の「選択 → 確認 → 結果」。選択だけでは操作せず、確認画面の「決定」で実行します。キャンセル・Escで選択を保って戻れます。本文と署名は暗号化を決定するまで下書きで、「編集を戻す」で復号直後に戻せます。送信候補のセット後も通信画面へ自動で移らず、転送前は候補を1つ前や元のデータに戻せます。転送は届け先とデータを確認して決定します。
- `storyboard.mjs`：「次へ」で進める導入、各ラウンドの送信方式、到着・介入・受信の会話。Alice・Bob・Charlieの主語と操作対象を各文で明示し、会話のページを文の途中で区切りません。会話の再生自体は暗号モデルを変更しません。
- `characters.svg` / `story.css`：Alice・Bob・Charlieのドット絵、色付きの頭文字、話者・鍵・暗号文の位置を連動させる舞台。
- `presentation.mjs`：各通信段階の状況・目的・データの役割を説明する表示モデル。
- `display.mjs`：全画面表示・終了と、非対応端末での画面いっぱい表示。Escで戻れます。
- `screen-layout.mjs` / `viewport.css`：全画面専用の画面高に収まる配置。横幅・高さ・向きで構成を切り替え、状況・目的・行動・結果を同時表示します。説明はページ送り、道具は操作と結果の画面に分けます。通常画面へ戻っても実験状態を保持します。
- `style.css`：共通デザインに合わせたPC・モバイル用レイアウト。
- 設定は「Alice宅の外にある通信経路上の中継機をCharlieが操作できる状態」。相手の端末・秘密鍵を盗む操作や、経路を掌握する手法自体は扱いません。
- 共通鍵は通信開始ごとに更新。以前の共通鍵は比較実験のため手元に残します。
- 元の本文はチャーリーが復号するまで非表示。ボブが受理しただけでは表示しません。
- 署名検証は本文とアリスの信頼済み公開鍵に結び付きます。チャーリーは自分の秘密鍵だけを操作できます。
- 数学的計算、ビット単位の攻撃、長さの漏えい、再送攻撃は抽象化します。実用の暗号化ツールではありません。

```sh
node --test scripts/crypto-communication.test.mjs
node lab/tools/build-pages.mjs --check
```
