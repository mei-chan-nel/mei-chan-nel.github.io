# Interactive Lab

情報Ⅰの概念を操作・実験・可視化で理解する教材です。アプリの操作と、CPU・メモリの変化を観察する「OSの仕事」を追加しています。

学習アプリと同じ6分野で整理します。

1. 社会・セキュリティ
2. デジタル表現
3. ネットワーク
4. データ活用・DB
5. アルゴリズム
6. 情報デザイン

動画解説ページと同じく、カテゴリの見出しの下に個別教材のカード一覧を置く構成です。個別教材のURLは `/lab/<slug>/` に統一します。

## 教材

- [OSの仕事](./os-work/)（アルゴリズム）：1コアCPUの時間分割、プロセスの状態、メモリの確保・解放を共通の仮想時間で再現します。Webの「受付 → 通信待ち → 描画 → 完了」、音声バッファ、写真加工の進捗と作業用メモリを操作して確かめられます。一定速度で再生・一時停止でき、アプリの画面内でCPUの割り当て中・順番待ち・イベント待ちを確認できます。音楽はパブリックドメインの3曲から選択でき、再生・一時停止・音量調整・消音に対応します。通知アプリ・クラウド同期・セキュリティ対策は初期状態から起動済みで、終了できません。待機中もメモリを保持し、通知の到着・ファイルの変更・予約スキャンをきっかけにCPUの仕事を発生させます。実際の通信・ファイル同期・セキュリティ検査は行いません。

通知とクラウド側の変更は、再現して比べられるように事前に用意した不規則な到着列で発生します。写真加工の完了・保存も同期のきっかけになり、変更がなければファイル全体を繰り返し同期しません。セキュリティ対策は予約クイックスキャンの例で、ファイルを開く際などのリアルタイム保護は対象外です。実際の通知にはOSの配信サービスや短時間のバックグラウンド処理も使われますが、この教材は比較のため各機能を1つの常駐プロセスにまとめています。1 tickは実際の1秒ではなく、観察のため引き延ばした仮想時間です。教材の折りたたみにはMicrosoftのWNS・OneDrive・Defenderの公式資料を案内しています。

CPUの実行待ちは、メモリを保持したまま処理の順番を待つ状態です。メモリ総量は1024 MBで、必要な空きが足りない起動・写真加工は「メモリ待ち」として保留され、空きができると自動で進みます。一時停止中はOSの再生後に進みます。初期状態ではOSと常駐アプリが448 MBを使用します。Web・音楽・写真も起動すると1008 MBになり、写真加工の作業用200 MBは確保待ちになります。Webを終了すれば空き216 MBになり、加工が自動で始まります。また、写真・音楽と加工用メモリで1008 MBを使用している間は、Webの起動が保留され、加工完了後に自動起動します。

「全画面」は画像圧縮・色の見え方Labと同じく、対応環境ではFullscreen APIを使い、埋め込み環境などでは画面いっぱいのページ内表示に切り替えます。同じ操作部とアプリを使い、再生・起動・表示・入力状態を引き継ぎます。1〜3の領域を画面内に配置し、狭い画面では内容を枠内でスクロールできます。終了ボタン・Escによる通常表示への復帰、元のスクロール位置とキーボードフォーカスの復帰に対応します。

音声バッファが空になると一時的に音が途切れ、CPUで補充されると加工の完了を待たず自動で復帰します。実音声は枯渇中に消音し、補充時に音切れ直前の実際の再生位置から続けます。通常再生中に仮想時間へ巻き戻す補正は行いません。枯渇ごとにブラウザの再生要求を中断・再発行しません。音源読み込みの表示領域と、全画面時のCPU欄・実行待ち欄は高さを固定します。

実音声の再生中断は、Promise内で即座に再試行せず、次のシミュレーション更新と500ms以上の待機を挟んで最大3回まで再試行します。その後は「音声を再開」の操作を待ちます。再生位置の補正は読み込み完了イベントから再要求せず、進行中のseekを待って1回だけ処理します。通常の時刻ずれを繰り返し補正する処理は行わず、停止済み音源へのpauseも重複させません。再生時間表示も実音声の位置を使います。

ユーザーが「起動」を押したアプリは、その場で表示中になります。メモリ待ちからの自動起動では、その後ユーザーが選んだ表示を変えません。音楽の再生・一時停止ボタンは曲名の右側に置きます。

基本操作は [使い方ページ](../study-guide.html#lab) にまとめています。

## 構成

- `catalog.mjs`: 6分野の名称と説明、完成した教材の一覧。
- `tools/build-pages.mjs`: 入口 `index.html` の生成。個別ページは生成しません。
- `lab.css`: 入口のレイアウト。既存 `assets/site.css` の配色・ヘッダー・フッターを使用します。
- `navigation.mjs`: ナビゲーションの表示補助。解析・広告スクリプトは読み込みません。
- `os-work/`: OSの仕事の画面と、ブラウザ内で完結するシミュレーション。

```sh
node lab/tools/build-pages.mjs
node lab/tools/build-pages.mjs --check
node lab/os-work/simulation.test.mjs
node lab/os-work/audio-controller.test.mjs
node lab/os-work/fullscreen.test.mjs
python3 scripts/preview_site.py --host 127.0.0.1 --port 8773 --app-root /workspace/info1-quiz-app
```

配信した `/lab/` を開いて確認します。Labの表示にnpmインストールは不要です。
