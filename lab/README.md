# Interactive Lab

情報Ⅰの概念を操作・実験・可視化で理解する教材の入口です。共通の入口と、個別の実験教材を管理します。

学習アプリと同じ6分野で整理します。

1. 社会・セキュリティ
2. デジタル表現
3. ネットワーク
4. データ活用・DB
5. アルゴリズム
6. 情報デザイン

動画解説ページと同じく、カテゴリの見出しの下に個別教材のカード一覧を置く構成です。完成した教材をカテゴリに登録し、一つずつ体験を設計・実装します。個別教材のURLは `/lab/<slug>/` に統一する方針を維持します。

## 構成

- `catalog.mjs`: 6分野の名称と説明、完成した教材の一覧。
- `tools/build-pages.mjs`: 入口 `index.html` の生成。個別ページは生成しません。
- `lab.css`: 入口のレイアウト。既存 `assets/site.css` の配色・ヘッダー・フッターを使用します。
- `navigation.mjs`: ナビゲーションの表示補助。解析・広告スクリプトは読み込みません。

```sh
node lab/tools/build-pages.mjs
node lab/tools/build-pages.mjs --check
python3 scripts/preview_site.py --host 127.0.0.1 --port 8773 --app-root /workspace/info1-quiz-app
```

配信した `/lab/` を開いて確認します。Labの表示にnpmインストールは不要です。

## 暗号通信シミュレーター

`/lab/crypto-communication/`。通信経路の中継機を操作するCharlieとして、鍵と暗号文の役割を学ぶレトロゲーム風の実験です。中継機を通るデータは自動で記録され、各場面では1〜2個の行動から選びます。3ラウンドと公開鍵確認の追加実験を収録します。

- `model.mjs`：不透明な暗号文・署名による教育用モデル。秘密のペイロードは内部に保持します。
- `quest.mjs`：場面ごとの判断、明示的な鍵選択と決定、正誤表示、誤答地点からの再挑戦と実際の通信による結果確認。本文を読んだ後に、改ざんをBobが検出できるか予想します。
- `app.mjs` / `unified.css`：通信図と、ナレーション・行動選択・結果を一つにしたパネルを保ち、学習アプリと同じ緑・赤で正誤を表示。鍵選択には「そのまま送る」も含みます。「一つ前へ」は会話だけでなく、復号・転送・ラウンド変更の実験状態も戻します。
- `storyboard.mjs`：短い三人称のナレーション。第3ラウンドでは検証用公開鍵の持ち主が未確認のため、すり替えが成立します。追加実験はCAへの申請・本人確認・証明書の発行と返却・相手への提示・ブラウザでの検証を順に表示します。CA公開鍵を通信経路から受け取る設定にはしません。
- `characters.svg` / `packets.svg` / `authority.svg` / `story.css`：ドット絵の3人と、鍵・封筒・暗号化した鍵・署名の形でデータを区別する通信図。
- `explanations.mjs`：鍵の役割、攻撃の手順、機密性・完全性・認証の違いを説明。補足説明は全文を表示し、枠内でスクロールできます。
- `display.mjs` / `viewport.css` / `screen-layout.mjs`：全画面表示と端末に合わせた配置。通常表示に戻っても実験状態を保持します。
- 通信図はデータの移動用の上段とキャラクター用の下段に分けます。正誤は解説カードの色で示し、「次へ」と「一つ前へ」をパネル内の共通位置に保ちます。
- `style.css`：既存Labの共通デザインに合わせた基本レイアウト。
- 設定は「Alice宅の外にある通信経路上の中継機をCharlieが操作できる状態」。CharlieはAliceやBobの秘密鍵を盗めません。
- 共通鍵は通信開始ごとに更新。鍵の選択肢には今回の共通鍵だけを表示します。
- 元の本文と書き換えの選択肢は、Charlieが本文の復号に成功するまで非表示です。
- 公開鍵暗号は共通鍵の配送に使い、本文は共通鍵で暗号化します。第3ラウンドでは検証用公開鍵がすり替わり、Charlie自身の署名で改ざんが受理されます。追加実験では、ブラウザに事前登録されたCA公開鍵を信頼の起点に、証明書のCA署名と相手名を検証します。偽のBobの証明書も、本物のCharlie名義の証明書も、Bobの証明書としては拒否します。
- 数学的計算、ビット単位の攻撃、長さの漏えい、再送攻撃、証明書チェーン・期限・失効は抽象化します。実用の暗号化ツールではありません。

```sh
node --test scripts/crypto-communication.test.mjs
node lab/tools/build-pages.mjs --check
```
