# Interactive Lab

情報Ⅰの概念を操作・実験・可視化で理解する教材の入口です。共通の入口と、個別の実験教材を管理します。

学習アプリと同じ6分野で整理します。

1. 社会・セキュリティ
2. デジタル表現
3. ネットワーク
4. データ活用・DB
5. アルゴリズム
6. 情報デザイン

動画解説ページと同じく、カテゴリの見出しの下に個別教材のカード一覧を置く構成です。完成した教材をカテゴリに登録し、一つずつ体験を設計・実装します。個別教材のURLは `/lab/<slug>/` に統一する方針を維持します。

## 構成

- `catalog.mjs`: 6分野の名称と説明、完成した教材の一覧。
- `tools/build-pages.mjs`: 入口 `index.html` の生成。個別ページは生成しません。
- `lab.css`: 入口のレイアウト。既存 `assets/site.css` の配色・ヘッダー・フッターを使用します。
- `navigation.mjs`: ナビゲーションの表示補助。解析・広告スクリプトは読み込みません。

```sh
node lab/tools/build-pages.mjs
node lab/tools/build-pages.mjs --check
python3 scripts/preview_site.py --host 127.0.0.1 --port 8773 --app-root /workspace/info1-quiz-app
```

配信した `/lab/` を開いて確認します。Labの表示にnpmインストールは不要です。

## 暗号通信シミュレーター

`/lab/crypto-communication/`。通信経路の中継機を操作するCharlieとして、鍵と暗号文の役割を学ぶレトロゲーム風の実験です。中継機を通るデータは自動で記録され、各場面では1〜2個の行動から選びます。3ラウンドと公開鍵確認の追加実験を収録します。

- `model.mjs`：不透明な暗号文・署名による教育用モデル。秘密のペイロードは内部に保持します。
- `quest.mjs`：場面ごとの選択肢、自動記録、選択・決定・取り消し。復号・共通鍵の包み直し・本文の再暗号化では、学習者が所持する鍵から使う鍵を明示的に選びます。正しい鍵の自動選択は行いません。間違った鍵を選んでも、通信を進めずに別の鍵で試せます。本文の転送は復号後に選びます。共通鍵を持たず復号に失敗した場合は、鍵の配送から再挑戦できます。元の本文を読んでからCharlieが反対の内容への書き換えを思いつき、転送前は元に戻せます。
- `app.mjs` / `quest.css`：通信図・会話枠・行動メニューを保つ画面。操作対象はその場面のデータに絞り、使う鍵は行動欄内のカードで選びます。小さい画面では鍵をページ送りで表示します。鍵を選んだ後も「戻る」で選び直せます。本文と入手した共通鍵、暗号化に使った鍵を表示します。
- `storyboard.mjs`：「次へ」で進める短い三人称のナレーション。Alice・Bob・Charlieの行動と対象を明示します。会話の再生は暗号モデルを変更しません。
- `characters.svg` / `story.css`：ドット絵の3人、色付きの頭文字、場面に連動する舞台。
- `display.mjs` / `viewport.css` / `screen-layout.mjs`：全画面表示と端末に合わせた配置、ページ送りの補足説明。通常表示に戻っても実験状態を保持します。
- `style.css`：既存Labの共通デザインに合わせた基本レイアウト。
- 設定は「Alice宅の外にある通信経路上の中継機をCharlieが操作できる状態」。CharlieはAliceやBobの秘密鍵を盗めません。
- 共通鍵は通信開始ごとに更新。以前の共通鍵は、前の攻撃が通じないことを比べるために残します。
- 元の本文と書き換えの選択肢は、Charlieが本文の復号に成功するまで非表示です。
- 公開鍵暗号は共通鍵の配送に使い、本文は共通鍵で暗号化します。第3ラウンドの署名は本文とAliceの信頼済み検証用公開鍵に結び付きます。
- 数学的計算、ビット単位の攻撃、長さの漏えい、再送攻撃は抽象化します。実用の暗号化ツールではありません。

```sh
node --test scripts/crypto-communication.test.mjs
node lab/tools/build-pages.mjs --check
```
