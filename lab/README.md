# Interactive Lab

情報Ⅰの概念を操作・実験・可視化で理解する教材の入口です。カテゴリの見出しの下に完成した教材のカードを置きます。個別教材のURLは `/lab/<slug>/` に統一します。

学習アプリと同じ6分野で整理します。

1. 社会・セキュリティ
2. デジタル表現
3. ネットワーク
4. データ活用・DB
5. アルゴリズム
6. 情報デザイン

現在は「デジタル表現」カテゴリに進数変換ラボを収録しています。

## 構成

- `catalog.mjs`: 6分野の名称と説明、完成した教材の一覧。
- `tools/build-pages.mjs`: 入口 `index.html` の生成。個別ページは生成しません。
- `lab.css`: 入口のレイアウト。既存 `assets/site.css` の配色・ヘッダー・フッターを使用します。
- `navigation.mjs`: ナビゲーションの表示補助。解析・広告スクリプトは読み込みません。
- `radix-conversion/`: 進数変換ラボ。デジタル表現カテゴリから入ります。

## 進数変換ラボ

2・10・16進数の相互変換に対応し、整数・小数・負の数を扱います。入力は有限の数値（合計64桁まで）。16進数の小文字、先頭の符号、小数点から始まる入力も使用できます。負の数は絶対値を変換して符号を戻す方式です。

- 10進数 → 2・16進数: 整数の割り算と小数の掛け算を分離。余りを下から、小数の整数部分を上から読む流れを示します。
- 2・16進数 → 10進数: 各桁を正・負の指数で分解し、桁の値を足します。
- 2進数 ↔ 16進数: 小数点の左右を別々に区切り、4ビット ↔ 10進数の値 ↔ 16進数1桁の対応を示します。
- 途中計算はすべて表示します。変換方向別の例題ボタンで、複数回の計算、A〜Cの読み替え、端の桁合わせ、循環を確認できます。結果は途中計算の後に「変換前＝変換後」で表示します。

`conversion.mjs` はBigIntによる分数で計算し、浮動小数点の丸め誤差を避けます。小数部分の同じ余りを検出し、循環部分の最初と最後の桁にドットを付けて表示します（1桁の周期ではドット1つ）。内部の数値表現は括弧記法です。表示上限は16〜256桁。上限に達した結果は省略を明示し、有限小数の途中表示と周期を表示しきれない循環小数を区別します。循環する数の入力は扱いません。`app.mjs` が学習用の途中計算と表示操作を担当します。

## 生成・確認

```sh
node lab/tools/build-pages.mjs
node lab/tools/build-pages.mjs --check
node --test scripts/radix-conversion.test.mjs
python3 scripts/preview_site.py --host 127.0.0.1 --port 8773 --app-root ../info1-quiz-app
```

配信した `/lab/` または `/lab/radix-conversion/` を開いて確認します。Labの表示にnpmインストールは不要です。進数変換のテストは既存の統合検証でも自動検出されます。
