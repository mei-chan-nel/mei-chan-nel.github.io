# リレーショナルデータベース

`/lab/relational-database/`。高校「情報Ⅰ」向けに、表の定義と関係、GUIによる定義 → 結合 → 射影 → 選択を体験する教材です。実行時の依存パッケージやサーバー側のDBはありません。

- 「1. 定義」で表・列・行を作成します。セルを直接入力し、別のセルへ移動するかEnterで保存します。Tabで次のセルへ進み、Escapeで保存前の値へ戻せます。文字／数値、任意の必須入力、主キーなし／単一／複合主キーに対応します。主キーは空欄と組合せの重複を拒否し、不正な編集は保存しません。行の削除は控えめな「×」から確認して行えます。
- 「結合」の追加は、カードを追加 → 結合を追加 → 列を対応づける案内で進めます。関係図は画面の横幅全体を使い、初期配置と「カードを整列」でカードを分散します。
- 関係図のカードは、元のテーブルを参照するテーブルオカレンスです。同じ表を複数配置でき、名前・位置を個別に設定できます。移動・拡大縮小・全体表示はマウス／タッチ／矢印キーに対応します。列を2つ順に選択するか、ダイアログから関係を設定します。
- 関係は同じ型の列による等値結合です。複数の対応列はANDで照合します。現在のデータから1対1／1対多／多対多を線上に表示します。
- 結合一覧の「＋ 結合を追加」の下で「基準となるテーブル」を選びます。基準の行を残す左外部結合でつながる表を組み立て、対応しない部分は空欄にします。基準を変えると結果が即座に変わります。空欄同士は結合しません。自己結合は同じ表の別カードで表し、輪になる接続と暗黙の直積は扱いません。
- 基準の変更は「結合」だけで行います。列の並べ替えは「射影」だけで行い、列の表示チェックはテーブルごとの枠にまとめ、結果表の見出しのつまみをドラッグして列順を変えます。別の表の列も自由に移動でき、非表示の列の順序も保持します。マウス・タッチ・矢印キーに対応し、列順を変えると表の右上に現れる「元の並びに戻す」で初期の順番へ戻せます。
- 射影は列の表示／非表示です。初期設定では重複行を残し、任意で表示列の値による重複除去を有効にできます。
- 選択は表示／非表示どちらの列も検索できます。等値、不等値、文字検索、大小比較、空欄、AND／ORに対応します。検索・整列後にも重複除去を適用するので、先に重複した行のどちらが残るかによって検索結果が変わりません。未結合の列の条件は適用せず、その件数を表示します。
- 「選択」では、結果表の各列の↑・↓ボタンで行を昇順・降順に整列できます。別の列で続けて整列すると、その列が同じ値の行では直前の順序を保ちます。整列するたびにその列を最優先とし、以前の整列を同値の比較に使います。「元の並びに戻す」で整列履歴を解除します。整列後に列を非表示にしても、その整列は維持します。数値は数値の大きさ、文字は日本語と文字中の数字を考慮して並べます。空欄は昇順・降順とも最後に置き、全整列条件が同じ行は元の順番を保ちます。初期状態は整列なしで、結合・射影の結果には整列を適用しません。
- プリセットは「学生・部員・部活」の1つです。学生24人・部員36件・部活7つの架空データで、学生は姓と名を持ちます。S02・S19・S22は未所属で、学生を基準に結合すると部活欄が空欄の行として残ります。C07「文芸部」は部員が0人で、部活を基準にすると学生欄が空欄の行として残ります。部員表の学生ID・部活IDを複合主キーにしています。射影は学生ID・氏名・部員の部活ID・部活名・顧問を初期表示し、選択には「部活名＝将棋部」を設定しています。39行から6行への絞り込みや、兼部による名前の重複を体験できます。「読み込み」からプリセットまたはJSONファイルを選びます。
- 元に戻す／やり直す（50操作）、ブラウザ内の自動保存、JSONファイルの保存・読込、新規作成に対応します。基準・列順・非表示・検索条件・整列も保存します。置換・削除は確認し、不正なファイルで現在の作業を上書きしません。旧版の未編集サンプルは新しい氏名・表名と未所属の生徒を含むデータへ更新し、独自に編集したデータは維持します。入力を外部送信する処理はありません。

関係は結合の設定であり、参照整合性を強制する外部キー制約ではありません。DBMS全体の再現、SQL、スクリプト、厳密な集合としての関係代数は対象外です。1セルの文字は200字、名称は40字、テーブル8個、各12列・100行、カード12枚、関係16個、検索条件10個、結合結果2,000行までです。結果の上限を超える場合は途中の結果を表示せず、設定の見直しを案内します。JSON読込は4MiBまでです。

## 保守・検証

- `model.mjs`：制約検証、プリセット、保存形式の移行、結合、列順、射影・選択。
- `app.mjs`／`database.css`：セル編集、関係図、レイアウト、保存・読込。
- `../tools/templates/relational-database.html`：HTML本体。`index.html` は共通シェルと合わせた生成物です。
- `../../scripts/relational-database.test.mjs`：データモデルの検証。
- `../tools/test-database.mjs`：PC・390px・320pxの実操作とアクセシビリティ検証。

```sh
node lab/tools/build-pages.mjs
node lab/tools/build-pages.mjs --check
node --test scripts/relational-database.test.mjs
python scripts/preview_site.py --host 127.0.0.1 --port 8773
LAB_PLAYWRIGHT_MODULE=/workspace/.lab-test-tools/node_modules/playwright \
LAB_AXE_MODULE=/workspace/.lab-test-tools/node_modules/axe-core/axe.min.js \
node lab/tools/test-database.mjs
```

ブラウザ検証はセルの直接編集とフォーカス、基準の変更と未対応行の保持、テーブルごとの列選択・見出しのドラッグと列順の画面間維持、連続した行の整列と同値の順序保持、値を使わない条件の入力欄非表示、射影・非表示列検索、複合主キーと数値のエラー、任意の主キー、列削除、自己結合、輪・型の拒否、カード移動、元に戻す、実際のJSON書出・読込・不正ファイル時の保持、再読み込み、新規作成を含みます。axe-coreは各画面とダイアログで自動検出できるWCAG A/AA項目を確認します。

`lab/tools/build-preview.mjs` で生成した単体HTMLのパスを `LAB_DATABASE_PREVIEW` に指定すると、外部リソースなしでの結合・射影・非表示列検索・セル編集・JSON書出も3サイズで検証します。320pxではブラウザ保存を使用できない状態にし、編集を続けてファイルに書き出せることを確認します。単体HTMLはブラウザのローカル配信で検証します。
