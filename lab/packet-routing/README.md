# パケット通信とルーティング

入口は `/lab/packet-routing/`。HTML/CSS/ES modulesのみで動き、依存パッケージ・外部API・サーバー側処理は不要です。Lab一覧のネットワーク分野から開けます。

## 操作

20台のルータ、6つのLAN、8台のPCを配置済みです。R13は故障、R7—R8は切断済みで、初期テーブルはそれらを検知・学習済みです。

送信元・宛先・メッセージを指定すると12文字ずつに分割して送ります。「連続送信」は2.8実験秒間隔。「経路上の回線を切断」は転送中の回線、または送信元側の経路を選び、消失と復旧の比較を始めやすくします。

図の機器・回線、または「選択対象」の一覧で対象を選び、故障・切断・復旧・削除を操作します。ルータを選ぶと自分のルーティングテーブル、PCを選ぶと自動設定されたIPアドレスを表示します。機器はドラッグ・矢印キーで移動でき、余白のドラッグ・ホイール・拡大縮小ボタン・ピンチで図を操作できます。回線接続は機器を2台選び、機器追加は図の余白を選びます。Escで選択モードに戻れます。

再生・一時停止・速さ変更・次のイベントまでのステップ実行を用意しています。パケットを選ぶと実際の通過経路・各判断のテーブル版・消失原因を表示し、「図で追う」でカメラが追従します。結果は20メッセージ、追跡用は最近の200完了パケットと通信中の全パケット、履歴は600件まで保持します。到達・消失カウンターは実験全体を数えます。

## モデル

`simulator.mjs`はDOMに依存しない決定的な離散イベントモデルです。`app.mjs`がrequestAnimationFrameで実験時間を進め、SVGの位置を補間します。一時停止中も編集でき、ステップ実行は次のイベント時刻まで進みます。同時刻のイベントはまとめて処理します。

単一エリアのOSPFを参考にしたリンクステート方式で、各ルータに独立したLSDB、広告のシーケンス番号、SPFによるテーブルを持たせます。検知に2.4秒、隣へのLSA伝達に0.75秒、SPFに0.4秒を設定しています。端点が新しい自分の接続情報を広告し、受信側は新しい版だけを採用して再転送します。復旧・新規接続時には隣同士が持つ情報を交換します。ルータの再起動ではそのルータのDBとテーブルを消去して学習し直します。

各ルータは自分のDBの双方向隣接関係だけを使い、コストの合計が最小の経路を計算します。実際の転送はそのルータのテーブルを参照し、送信時点で使えない回線に対して別経路を先読みしません。転送中の回線切断・機器故障ではそのパケットを即時に消失させます。検知前の古いテーブルによる消失、一時的な経路の循環、TTL（32回）による破棄を再現します。パケットの通過経路・判断は個別に保存し、メッセージは全片が到達した場合だけ組み立てます。

図の破線は「現在の各ルータのテーブルをたどった予測」。追跡時の実線はパケットの実際の通過経路と移動中の回線です。LSAはオレンジの点、データは青い点で表します。

学習用の簡略化として、LANは1台のルータに接続し、PCは1つのLANに接続します。IPは10.0.<LAN番号>.0/24の範囲で自動設定します。回線コストは1〜9、機器数は80まで。OSPFのエリア分割、DR/BDR、認証、実際のパケット形式、定期HelloやLSAの経年失効、帯域制限、混雑、TCP、再送は扱いません。検知はトポロジー変化からの遅延イベントで代用しています。削除・到達不能になったルータの古いLSAはDBに残りますが、双方向接続がなくなるためSPFで経路には使えません。独立したテーブルが収束する過程を観察するためのモデルで、実機のOSPF実装ではありません。

## 確認

```sh
node --test scripts/packet-routing.test.mjs
node lab/tools/build-pages.mjs --check
python3 scripts/preview_site.py --host 127.0.0.1 --port 8773
```

ブラウザで `http://127.0.0.1:8773/lab/packet-routing/` を開きます。サイトの共通CSS・Lab用ナビゲーションを使い、広告・解析コードは読み込みません。

モデルの14テストでは、転送中の消失、検知前の古いテーブル、ルータごとの更新時刻、分断・復旧、ルータ再起動、ネットワーク追加・削除、コスト変更、TTL、メッセージ再構成、保存数の上限を確認します。複数障害の反復テストでは、収束後の各ルータのテーブルを独立した物理グラフの最短距離計算と照合します。

Chromiumで送信・連続送信・故障・迂回・復旧・編集・追跡・再生停止・ステップ・ドラッグ・キーボード操作を実際に確認しました。1440px・390px・320pxの表示で横方向のはみ出しがなく、初期画面と情報更新中の画面はaxe-coreのWCAG 2 A/AA・2.1 AA自動チェックで指摘なし。実機Safari・Firefoxでの確認は未実施です。
