CPUと記憶装置

RAMを書き換える。実行する。キャッシュの働きを比べる。

自分のプログラムで、確かめよう

  1. RAMの種類と値・番地を直接変更します。数値欄に直接入力できます。
  2. 「次へ」で命令の取得・CPUへの取り込み・データ参照・計算を1動作ずつ確認。「自動実行」で最後まで進めます。「全画面」でCPU → キャッシュ → RAMを広く表示できます。
  3. 結果を保存し、キャッシュのON/OFFや容量を変えて再実行します。設定やRAMの編集時には、CPUとキャッシュが初期化されます。

加算・減算は指定番地の数値を使います。「値の設定」だけは数値をそのまま使います。計算中の値は1つです。

この実験のしくみ・時間の数え方

命令と数値は同じRAM（0〜31番地）に置きます。命令取得とデータ読み書きは1つのキャッシュを共有し、2番地単位のブロックをどの枠にも保持できます。最近使われていないブロックから置き換えます（LRU）。書込ミスでもブロックを取得し（ライトアロケート）、RAMにもその都度書き込みます（ライトスルー）。書き込みによって命令が数値に変わる場合もあります。

ヒット＝キャッシュ時間。読出ミス＝キャッシュ時間＋RAM転送時間。書込ヒット＝キャッシュ時間＋RAM転送時間。書込ミス＝キャッシュ時間＋RAM転送時間×2（ブロック取得と書込）。OFF時は1参照につきRAM転送時間。ブロック取得は2番地まとめて1転送と数えます。合計＝命令数×CPU処理時間＋全アクセスの待ち時間。表示は動作ごとに分けますが、CPU処理時間は命令完了時に1回だけ計上します。読み出しは、ヒット時はキャッシュ → CPU、ミス時はRAM → キャッシュ → CPU。RAMからの取得を2回数えているわけではありません。実機では、必要な値をブロック取得中に先にCPUへ返す場合もあります。書き込みは同じCPUの値をキャッシュとRAMへ反映するライトスルーです。実機のコントローラ・書込バッファ・並行処理は省き、教材では順番に表示して時間を加算します。表示の速さは仮想時間に影響しません。

値は安全な整数の範囲で扱います。自動実行は10,000命令ごとに一時停止。一括比較は10,000命令以内で終了するプログラムが対象です。RAM・設定の変更後はキャッシュを空にし、計算中の値を0に戻します。保存済みの比較記録は保持します。
