# 統計的な判断と仮説検定

Nightingale & Farid (2022)実験1の参加者315人・各128枚の顔判定を使い、割合の母平均を検定する。データ→仮説検定を行う→判断の誤り。原データ/出典/加工方法はshared/datasets/README.mdとページ下部。

## 仮説検定を行う：8段階

1. 1人ごとの正答率とヒストグラム（人数の分布）。階級幅・棒のクリック/キーボード選択。
2. 2択なら1/2=50%という基準の根拠、帰無/対立仮説。基準0〜1の内点、両側/右片側/左片側、基準を設定。自由記述欄は設けない。
3. 結果を見る前に有意水準と1標本t検定の方法・前提を決める。
4. ヒストグラムの棒の選択を外し、標本平均と帰無仮説の平均に直接ラベル。平均との差→二乗→全員の合計→n−1で割る→平方根で標準偏差を導出。
5. 平均の揺れを推定するSE=s/√nと、t=(平均−基準)/SEを計算。橙の今回の差を緑のSEの等間隔で区切り、何個分かをつなげる。
6. 帰無仮説を仮定し、同じ調査で今回以上にずれる確率を考えてから計算する。「次へ」で数値を出し、この確率をp値と名付ける。
7. p≤αなら棄却という、先に決めたルールで判断。
8. 差の方向/大きさ/実用上の意味/対象の範囲を解釈。信頼区間は端点、区間の意味、今回の平均、帰無仮説の平均とその内外を直接表示。

最初はヒストグラムを中心に表示し、表と計算例は補足で確認する。各段階に行うこと・計算・要点と「前へ」「次へ」。手順一覧はボタンで各段階へ直接移動でき、キーボード操作にも対応する。p値と判断は該当段階まで表示しない。仮説・方向・αを後から変更すると、その設定の段階へ戻る。公開済み研究で学ぶ教材であり事前登録の再現ではない。結果を見た後の条件変更は別の比較と明記。空の数値などの無効な入力では進行しない。

## 判断の誤り：3段階

真の状態×判断の表で2つの誤り→基準どおりでも誤って棄却する第1種→対立仮説側の差を見逃す第2種。複雑な2曲線の図を外し、状況の流れと確率の帯で示す。計画人数・真の平均・α・σの操作と検出力は、最終段階の「詳しく」にまとめる。旧errorStep3/4は2へ移行する。

計画では独立な正規分布の参加者割合を近似モデルとし、母標準偏差をデータから仮置きするか、別に設定する。n30〜1000、仮定する真の平均、αを変更可能。帰無仮説側で決めた同じt棄却域をt/非心t分布へ当てはめる。片側で真の平均が帰無仮説側なら、その棄却率を検出力や見逃し率と呼ばない。割合の範囲制約・選び方の偏り・画像の共有を厳密に再現したモデルではない。表示する基準は50%のように末尾の不要な小数を除き、平均/SD/SE/tは基本2桁へ丸める。確率は判断に必要な小さい値を保持し、計算は丸めない。

## データ・計算・互換

1行が1人分の参加者番号/判定枚数/正答数。2〜10000人、1人の判定数1〜10000、正答数0〜判定数の整数。番号は重複不可。以前保存した割合の名前は保全する。各人を等しい重みで平均し、判定数が異なる場合に全回答の合計比率へ勝手に置き換えない。全員同じ値ならt検定は計算不能として説明する。計画に正のσを別指定することは可能。

mean-model.mjsは両側と左右片側のp値・棄却域・CI・非心t計画。両側H₀:μ=μ₀、右片側H₀:μ≤μ₀、左片側H₀:μ≥μ₀。片側は境界で計算し、信頼区間は片側上限または下限を示す。初期設定（50%・両側）で平均48.152281746%、SD9.493165356ポイント、p=0.00062717598、95%区間47.099881264〜49.204682228%。1人の128回答を128人とは数えない。

Student分布は正則化不完全ベータ関数、非心tの密度/検出力は正規分布とカイ二乗の混合積分。SciPyで各方向と基準を独立検算。charts.mjsは個人ヒストグラムと検定の帰無分布を別の図として描く。∞のCI端は座標へ入れず矢印で表す。model.mjsの旧二項モデルは再現用に保持。

保存キーv3を維持。guide.mjsのnormalizeGuideで既存のユーザー参加者データへ設定だけを補い、元データを置き換えない。旧v1/v2のユーザーデータはCSVで取り出せる。CSV/表で観測データが変わると両方の手順を最初に戻す。このページだけ外側のタブ間「次へ」を隠し、内側の手順と混同させない。全画面では補足説明を右ナビへまとめ、上の手順と下の前後移動を固定する。主要図は画面高に合わせ、内容が収まる場合はスクロールせず表示する。狭い画面や補足を開いた場合は内容領域のみスクロールできる。右ナビの幅変更/折畳み・共通配色・非表示スクロールバーは維持。
