# 統計的な判断と仮説検定

Nightingale & Farid (2022)実験1の参加者315人・各128枚の顔判定を使い、割合の母平均を検定する。データ→仮説検定を行う→判断の誤り。原データ/出典/加工方法はshared/datasets/README.mdとページ下部。

## 仮説検定を行う：8段階

1. 1人ごとの正答率とヒストグラム（人数の分布）。階級幅・棒のクリック/キーボード選択。
2. 2択なら1/2=50%という基準の根拠、帰無/対立仮説。基準0〜1の内点、両側/右片側/左片側、任意の基準の理由を設定。
3. 結果を見る前に有意水準と1標本t検定の方法・前提を決める。
4. 標本平均と、人ごとの散らばりである標本標準偏差sを計算。
5. 平均の揺れを推定するSE=s/√nと、t=(平均−基準)/SEを計算。
6. 帰無仮説のもとでのt分布、選んだ方向の面積であるp値。
7. p≤αなら棄却という、先に決めたルールで判断。
8. 差の方向/大きさ/実用上の意味/対象の範囲を解釈。補足として方向とαに対応する信頼区間。

各段階に行うこと・計算・要点と「前へ」「次へ」。p値と判断は該当段階まで表示しない。仮説・方向・αを後から変更すると、その設定の段階へ戻る。公開済み研究で学ぶ教材であり事前登録の再現ではない。結果を見た後の条件変更は別の比較と明記。空の数値などの無効な入力では進行しない。

## 判断の誤り：5段階

計画→帰無仮説が正しい世界での第1種の誤り→対立仮説側での第2種の誤りと検出力→真の状態×判断の表→人数/有意水準の比較。

計画では独立な正規分布の参加者割合を近似モデルとし、母標準偏差をデータから仮置きするか、別に設定する。n30〜1000、仮定する真の平均、αを変更可能。帰無仮説側で決めた同じt棄却域をt/非心t分布へ当てはめる。片側で真の平均が帰無仮説側なら、その棄却率を検出力や見逃し率と呼ばない。割合の範囲制約・選び方の偏り・画像の共有を厳密に再現したモデルではない。

## データ・計算・互換

1行が1人分の参加者番号/判定枚数/正答数。2〜10000人、1人の判定数1〜10000、正答数0〜判定数の整数。番号は重複不可。持込データでは割合の名前（正答率/成功率など）も変えられる。各人を等しい重みで平均し、判定数が異なる場合に全回答の合計比率へ勝手に置き換えない。全員同じ値ならt検定は計算不能として説明する。計画に正のσを別指定することは可能。

mean-model.mjsは両側と左右片側のp値・棄却域・CI・非心t計画。両側H₀:μ=μ₀、右片側H₀:μ≤μ₀、左片側H₀:μ≥μ₀。片側は境界で計算し、信頼区間は片側上限または下限を示す。初期設定（50%・両側）で平均48.152281746%、SD9.493165356ポイント、p=0.00062717598、95%区間47.099881264〜49.204682228%。1人の128回答を128人とは数えない。

Student分布は正則化不完全ベータ関数、非心tの密度/検出力は正規分布とカイ二乗の混合積分。SciPyで各方向と基準を独立検算。charts.mjsは個人ヒストグラムと検定の帰無分布を別の図として描く。∞のCI端は座標へ入れず矢印で表す。model.mjsの旧二項モデルは再現用に保持。

保存キーv3を維持。guide.mjsのnormalizeGuideで既存のユーザー参加者データへ設定だけを補い、元データを置き換えない。旧v1/v2のユーザーデータはCSVで取り出せる。CSV/表で観測データが変わると両方の手順を最初に戻す。このページだけ外側のタブ間「次へ」を隠し、内側の手順と混同させない。全画面の右ナビ・幅変更/折畳み・共通配色・非表示スクロールバーは維持。
