# 統計的な判断と仮説検定

Nightingale & Farid (2022)実験1の315人・各128枚の回答を使用。1行が1人分の参加者番号/判定枚数/正答数。観測単位は参加者で、40,320回答を独立した40,320人とは数えない。データと出典はページ下部とshared/datasets/README.md。

## 仮説検定を行う：8段階

1. ヒストグラムで個人の正答率の分布を読む。階級幅は1〜10の整数を数値入力で設定し、上下操作は1ずつ。棒の人数を確認できる。100を割り切れない幅では同じ幅のまま最後の階級を100の先まで取る。
2. 0〜1の小数で帰無仮説の平均μ₀を設定し（上下操作は0.01、直接入力は任意の小数）、両側/右/左片側から仮説を組み立てる。μ₀=0.5は50%。結果を見る前に基準と向きを決める。
3. 有意水準と方法を決める。今回は母標準偏差を標本から推定する大標本の正規近似。厳密な既知σのZ検定ではない。この教材は30人以上を扱うが、30人なら必ず近似が十分とはしない。
4. 標本平均と散らばり。平均との差→二乗合計→n−1で割る（不偏分散）→平方根（標準偏差）。図は静的で、標本平均と帰無仮説の平均を両方ラベル。
5. 標準誤差=標準偏差÷√人数は標本平均のばらつきの推定。Z=(標本平均−帰無仮説の平均)÷標準誤差は、その差が標準誤差の何個分か。SEの略記を使わず、意味を数式の近くに明記する。
6. 正規分布表を読む。両側α=.05なら各端.025、表の0〜zの面積.4750。行1.9と列.06からz≈1.96を読む。表を読む図は右半分だけに色付けし、0から境目までと端の面積を色付きラベルで載せる。片側や他のαも表・面積・境目が連動する。4桁表の間にある位置を説明し、細かい桁は正規分布の式から求めて判定に使う。
7. Zと棄却域を比べる。両側なら|Z|≥境目、右ならZ≥右の境目、左ならZ≤左の境目で棄却。今回のZは横軸近くの下向き矢印で示す。境界に近い場合は表示桁を増やす。p値の計算や信頼区間の再掲は行わない。
8. 帰無/対立仮説、有意水準と人数、標本平均/標準誤差/Z、棄却域、判断と解釈を1画面で俯瞰する。元のデータでは平均正答率が当てずっぽうの基準を下回る、と主語を明示する。

各段階へは上の標準button一覧で直接移動できる。前へ/次へもある。最初へ戻るボタンや最終段階の繰り返しボタンは設けない。仮説・向き・αを変更すると設定段階へ戻る。自由記述欄はなく、数値の無効入力では先へ進めない。表示は必要な桁へ丸め、検定は丸める前の値で計算する。

## 判断の誤り：3段階

状態×判断の表→第1種→第2種。本文と右ナビは計算と結果の説明に絞り、重複した但し書きや一般的な注意事項を置かない。数式・単位・表の読み方は「詳しく」で確認できる。第2種の誤りの確率は、真の平均などの別の仮定が必要なため今回の観測だけでは分からないと説明する。別の計画の6.89%や計画パラメータをこの流れへ混ぜない。2つの誤りを足して結論の誤り率にしない。

## 計算と保存互換

normal-model.mjsはWelford法による参加者平均・不偏分散、標準誤差、正規近似のZ、方向に対応する棄却域、正規分布表のデータを返す。正規上側確率には正則化不完全ガンマ関数の級数/連分数、境目には二分法を使う。SciPyのnormと独立照合する。原315人で平均0.48152281746、s≈0.09493165356、標準誤差≈0.00534879273、Z≈−3.454458507、両側5%の境目≈±1.959963985。

2〜10000人の入力/保存は維持し、30人未満やばらつきゼロでは正規近似による判断を止める。元データ・平均・ばらつきは引き続き読める。旧mean-model.mjsのt/非心tと旧model.mjsの二項モデルは照合用として保持する。現在の画面はnormal-model.mjsを使う。元論文の再計算したtのp値と、現在のZ近似の判断を同じ方法と偽らない。

保存キーv3と参加者データを維持。旧5段階の過誤の最後2段階は現在の最後へ移す。以前の確率表示フラグ・計画フィールドは互換用として保持するが、画面では使わない。既知の原研究への出典が保存されている場合は、その解釈欄だけを現在の方法の説明へ更新する。ユーザーの観測値・ベースライン・原論文のリンクは置き換えない。旧v1/v2も削除せずCSV取り出しを維持する。

全画面では右ナビへ短い要点と折りたたみの補足を移す。図は本文に残し、手順と前後操作を固定。画面高に合わせ、必要なら本文だけスクロールする。共通配色・右ナビの幅変更/折畳み・非表示スクロールバーを維持。正規分布表の行列と数値は教材側で計算し、表示形式の参考は本文下部へリンクする。
