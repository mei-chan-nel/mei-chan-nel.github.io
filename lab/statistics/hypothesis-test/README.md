# 統計的な判断と仮説検定

Nightingale & Farid (2022) の実験1を使い、参加者の平均正答率を当てずっぽうの50%と比べる。データ→50%と比べる→判断の誤り。

315人が各128枚（本物64・AI生成64）を判定。平均48.1523%、標本標準偏差9.4932ポイント。著者の回答表から各人の正答数だけを集計する。正答19,415/40,320判断。空欄は判定していない画像で、誤答に置換しない。出典と加工方法はshared/datasets/README.mdとページ下部。

mean-model.mjs が参加者ごとの正答率を標本単位に、t=(平均−0.5)/(s/√n)、自由度n−1の両側p値と信頼区間を計算。初期p=0.00062717598、95%区間47.0999〜49.2047%。1人の128回答を独立な128人として数えない。正答率は離散値なので、参加者間の独立性と多数の参加者に対するt近似を使い、画像群を越える一般化とは区別する。

データ入力は参加者番号・判定枚数・正答数の3列、2〜10,000人。番号の重複、範囲外や非整数の個数を拒否。観測値はデータタブだけで編集し、分析では有意水準だけを比較する。全員同じ正答率なら分散推定ができないため、検定と区間を未定義として説明する。

「判断の誤り」は別の調査計画。30〜1,000人、仮定する本当の平均と有意水準を操作する。個々の参加者の正答率を独立な正規分布で近似し、標準偏差は今回の値を仮の母標準偏差として固定。帰無仮説側で決めたt棄却点を非心t分布にも使い、検出力と見逃し率を計算する。0〜100%の範囲を再現する厳密な正答モデルではない。乱数は使わない。

Student分布は正則化不完全ベータ関数、非心tの密度/検出力は標準正規分布とカイ二乗の混合積分を用いる。SciPyの独立計算で照合。model.mjsは旧版の二項計算を再現するために保持するが現在のUIには使わない。

保存キーはstudy-atlas-statistics-hypothesis-test-v3。旧v1の2群、v2の個数集計は削除せず、ユーザーデータがあればデータ画面からCSVで取り出せる。実験の意味が異なるので自動変換はしない。
