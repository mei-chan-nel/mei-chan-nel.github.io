# 統計的な判断と仮説検定

独立した1つの割合が事前の基準と違うかを調べる。データ→基準の割合と比べる→判断の誤り。

初期値はMendel (1866)の種子の形の実測集計：丸い種子5,474個、しわ1,850個、総数7,324個。基準75%（3:1）。集計を個票へ展開しない。出典はshared/datasets/README.mdとページ下部。

帰無仮説p=p₀、対立仮説p≠p₀、X~Bin(n,p₀)。統計量|X−np₀|を使い、観測値以上のずれを含む全ての個数の確率を合計する。乱数・正規近似は使わない。この両側定義は確率順序型のbinom.testとは異なることがあるので、定義を明示する。

データ入力は対象名・総数n・該当数kの1行。観測値はデータタブだけで変更する。分析タブはp₀とαを変えるがn,kを変えない。「判断の誤り」では別の調査計画nと本当の割合p₁を設定し、p₀だけで決めた同じ棄却域へ両分布を当てはめる。誤判定率・検出力は理論値。

保存キーはstudy-atlas-statistics-hypothesis-test-v2。旧v1の2群データは触らず、ユーザーの読込データがあればデータ画面からCSVで取り出せる。自動で片方の群へ読み替えない。

計算はmodel.mjs。対数PMFを最頻値から両方向へ再帰して正規化し、n≤10,000で安定化。図は最大90区間にまとめるが、p値は全ての整数で計算し、棄却域の境界は整数の半分で正確に描く。表示範囲外も計算に含む。
