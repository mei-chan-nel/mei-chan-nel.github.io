# 確率と確率分布：1つの実験を4つの見方で読む

学習目標は、設定した確率と実験で得た割合・分布を区別し、回数の確率を和や面積として読めること。

## 固定した順路

1. 実験の準備：表の確率p、1セットの投数n、セット数を設定して生成する。記録の1行は1セット。結果は編集しない。
2. 相対度数：全セットの0/1を投げた順につなぐ。各時点の累積相対度数とpを比べる。
3. 二項分布：同じセットを表の回数Kで集計。実験の相対度数と二項分布の確率を比べる。
4. 正規分布：同じKの範囲について、平均np・標準偏差√(np(1−p))の正規近似と比べる。
5. 標準化：同じ正規近似の区間をzへ変換し、面積が変わらないことを確かめる。

## 数値の契約

- `experiment.mjs`が1つの乱数列からセット内の0/1を生成する。二項分布用に別のデータは生成しない。
- `experimentSummary`は同じ記録から累積経路、セットごとの成功回数、度数を求める。
- `startExperiment`だけが新しい観測を追加する。条件変更では新しい実験番号を付ける。過去のセット配列は変更しない。
- グラフ上の操作は表示範囲や注目するKの選択のみ。p、n、セット数、μ、σをグラフ上で変更しない。
- 整数Kの範囲a〜bに対応する正規近似は、a−0.5〜b＋0.5の連続補正を使う。これは近似であり、二項分布の確率と同一とは限らない。
- npとn(1−p)がともに5以上を近似の目安とする。条件を満たさない場合は差と限界を明示する。
- p＝0または1ではσ＝0。確定した回数と二項分布は扱えるが、正規曲線と標準化は表示せず理由を示す。
- 正規曲線はμ±4σを表示する。面積の数値計算は表示外の裾も含む。
- n＝1〜200、セット数＝1〜1,000、総投数＝20,000以下。大きな累積経路は描画だけ間引く。計算とCSVは全観測を使う。

## 履歴と旧データ

新しい実験は既存の履歴へ追加し、履歴から前の実験を読み返せる。ブラウザー保存からも同じセット配列を復元する。以前アップロードした0/1・成功回数・測定値は別の旧データとして保持し、実験の準備からCSVで取り出せる。通常の順路にはデータ型の選択・自由編集・CSVアップロードを置かない。

旧`model.mjs`の関数は旧保存形式・他の読込処理との互換性のため維持する。新しいページは`experiment.mjs`を中心に動作する。
