# 月次データの出典と抽出

- 原統計：総務省統計局「家計調査 家計収支編 二人以上の世帯」、表10「品目分類（平成27年改定）（総数：金額）」、品目356「アイスクリーム・シャーベット」、事項コード10800150。
- 範囲：全国、二人以上の世帯（2000年〜）、1世帯当たり1か月間の支出金額、円。2009年1月〜2018年12月の120か月。
- e-Stat：[家計調査データベース](https://www.e-stat.go.jp/stat-search/database?layout=datalist&toukei=00200561&tstat=000000330001)。
- 数値を読み取った公開保存版：[e-Stat出力CSV](https://github.com/hkawash/sis-intro/blob/b5bb7d5580c253155bd351de489181e21cdc30b6/data/FEH_00200561_190526191958.csv)。同リポジトリのREADMEにe-Statでの抽出手順が記載されている。
- CSV保存版コミット：b5bb7d5580c253155bd351de489181e21cdc30b6。取得・確認日：2026-10-24。
- 元CSV SHA-256：0c3252ca7dd4e7c8ec324722161fa821c46e126081154c8a8e1517cdf9d662b9。
- 操作：CP932で読み、上記期間の年月と円の列を抜き出し、昇順に並べた。元データの値を修正・補間・生成していない。
- 検証：同リポジトリの別ファイル sweets-temp.csv の2010〜2018年の日当たり金額を各月の日数で戻した108点と全点一致。日本アイスクリーム協会の「家計調査実績」にある2017年9,047円、2018年9,670円の年計とも一致。2016年の月別合計8,907円は公表年計8,908円と1円の差があるが、円単位の月別公表値をそのまま使用する。
- 照合：[日本アイスクリーム協会 家計調査実績](https://www.icecream.or.jp/iceworld/data/expenditures.html)。季節性は[総務省 家計ミニトピックス2020年7月](https://www.stat.go.jp/data/kakei/tsushin/pdf/2020_07.pdf)でも示されている。

支出金額は購入数量ではなく名目金額。物価や世帯構成・調査方法の影響も含む。季節調整値は本教材の簡易的な加法モデルによる計算値であり、公表された公式の季節調整値ではない。
