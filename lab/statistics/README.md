# 統計・データ分析 Interactive Lab

既存のHTML／ES ModulesとStudy Atlas共通シェルで動く、依存ライブラリ不要のブラウザ教材です。

## 体験と画面

統計トップは、既存Interactive Labと同じ `archive-field-card` と `archive-course-card` を使用します。

各ラボは必ず「データ」タブから開きます。現在使用する値の表とその編集、サンプルの生成、CSVの入出力をまとめ、「次へ」から分析・読み取り・計算へ順に進めます。タブを直接選ぶこともできます。各タブには目的と操作案内を示し、推定・検定などは発展と明示します。元データは画面幅にかかわらず全件表示を基本とし、必要なら100行・300行へ切り替えられます。通常表示では図表と操作欄をページ全体でスクロールします。CSV読込は同じタブ内で内容と使用する列を確認して適用します。グラフや指標の操作に応じて、現在の値を使った短い読み取りの説明が変化します。定義・計算・前提・限界の解説はページ下部で項目別に開閉します。

全8ラボと横断課題は同じデータタブを使います。上部のサンプル・CSVダウンロード・アップロードは右寄せで、同じ外観です。表のセルを直接編集し、行を追加・削除できます。「変更を反映」、入力欄でEnter、または分析タブへ進む操作で検証して反映します。編集途中の値はページ送りや画面幅の変更で消えません。「編集を取り消す」で直前の有効なデータへ戻れます。未反映の変更は再読み込みで復元しません。スマートフォンは1行を項目名付きの入力欄として表示し、横スクロールなしで編集できます。

表編集にもCSVと同じ数値・形式の検証を使います。クロス集計は4行、A/Bは2行、時系列は48か月という分析上の形式を保持します。編集途中には行の追加・削除ができますが、形式に合わない状態では理由を表示し、分析を直前の有効なデータのままにします。編集を反映したデータは自分のデータとして保存し、再訪時に復元します。CSV出力・横断課題からの受け渡しにも編集後の値を使います。

ミッション、文章記録、比較保存、JSON保存のUIはありません。横断課題も手法の選択と自動集計した特徴の見比べを中心にし、文章の提出や記録は求めません。

単独ラボのサンプルはページを開くたび、「サンプルを使用」を押すたびに新しい乱数で生成します。操作中は値を保ち、条件を1つずつ変えられます。外れ値の影響、二群の山、シンプソンの逆転などが観察できる構造を保つ生成方法です。読み込んだ自分のデータはブラウザ内に保持し、再訪時には復元します。横断課題の共通データはラボ間を往復しても同じ値を保持し、「サンプルを使用」で更新します。

## CSV形式

UTF-8のCSV／TSVは1MB以内。引用符・BOM・改行を含むラベルに対応し、空欄・不正値を勝手に0へ変換したり削除したりしません。数値の絶対値は1,000,000以内です。表示時に小数を丸めても、CSVは元の数値精度で書き出します。

| ラボ | 形式 |
|---|---|
| 相関・回帰 | 対応する数値2列、2〜300行 |
| ヒストグラム | 数値1列＋集団列（任意、2群まで）、2〜300行。集団B移動後の表示値をCSVに書き出す |
| 代表値 | 数値1列、2〜300行 |
| 標本調査 | 数値1列＋集団列（任意、2群まで）、2〜300行。読込全行を母集団とする |
| クロス集計 | 集団・方式・成功数・不成功数の4列。2集団×2方式の4行 |
| 時系列 | 非負の数値48か月分。月ラベルは任意。日付は連続したYYYY-MM、または相対月番号 |
| 仮説検定 | 群・対象数・成功数の3列2行。各群の対象数10〜1,000人 |
| ローレンツ | 非負の所得1列、2〜300行。元の単位を維持 |
| 確率 | 1〜10,000行。コインは0/1、二項分布は0〜nの成功回数、正規分布の比較は数値の測定値 |

確率ラボの読込観測値は固定し、モデル条件を変えても再生成しません。試行の追加はサンプルに対して行います。正規モデルの初期の平均・分母nの標準偏差には読込データの値を用い、標準偏差0の表示用初期値は1とします。データが正規分布であることを保証するものではありません。

## 主な構成

- `build.mjs`：トップ・8ラボ・横断課題の11ページ生成。
- `<slug>/lab.mjs`：ラボ固有の計算・操作・可視化・下部解説。
- `app.mjs`／`workbench.mjs`：表示切替、既存DOMのイベントを保った配置、データタブとの切替。
- `learning.mjs`：各タブの順路・目的・操作案内・基本／発展の区分、前後への移動。
- `correlation/lab.mjs`：散布図の直接操作、予測点と軸上の座標、追加・Deleteキー削除、図上の直線調整。右の操作欄を使わず、ヘッダは相関係数と直線の方程式だけを表示。残差表示は初期値オン。余白を押すと選択を解除し、未選択の状態も復元可能。
- `data-tab.mjs`／`data-editor.mjs`：共通の表編集・行追加削除、CSV入出力、貼り付け、列選択と確認。
- `shared/table-data.mjs`：表の標準列とCSV変換の対応付け、セル・分析形式の検証。
- `shared/samples.mjs`：ラボごとの題材を保つ、再現可能な乱数サンプル生成。
- `shared/insights.mjs`：現在のデータ・条件から、変化の意味を短く説明。
- `shared/data-model.mjs`／`shared/csv.mjs`：入出力の変換と検証。
- `shared/chart-layout.mjs`：図の座標を表示領域へ配置し、文字や取っ手の大きさを保つ。
- `shared/explanation.mjs`：学問的な解説を項目別のネイティブ折りたたみへ変換。
- `shared/data.mjs`／`projects.mjs`：共通データを「データ」「分析方法」「特徴の見比べ」で利用。

## データの保持と連携

`study-atlas-statistics-<slug>-v1` にデータと状態を保持します。再訪時に復元するのは利用者の読込データで、教材サンプルは再生成します。従来の自分のデータは形式検証のうえで引き継ぎ、使わなくなった文章記録や比較情報を画面へ出しません。

横断データは `study-atlas-statistics-dataset-v1` に2〜300行の `{id,x,y,group}` と列名・出所を保持し、`?dataset=project&field=y`（またはx）で分布・代表値へ、`?dataset=project`で相関へ渡します。ラボ内の変更は共通元データを変更しません。元データの特徴は横断課題で自動集計し、操作後の各ラボの結果とは区別します。データを外部サーバーへ送信しません。

## 再生成・検証

```sh
node lab/statistics/build.mjs
node lab/tools/build-pages.mjs --check
node --test scripts/statistics.test.mjs
python3 scripts/validate_portal.py --app-root ../info1-quiz-app
python3 scripts/validate_manual_ads.py
```

四分位数は奇数個なら中央値を除く上下半分の中央値。統合した分布ラボの箱ひげ図は1.5IQR方式で外れ値候補を表示します。分散はn／n−1を切替可能。相関・回帰は「データ」「散布図・直線」の2タブです。予測点を直接動かし、縦横の点線と軸上の値を確かめられます。残差・図の取っ手による直線調整・選択点を回帰から外す検証は、グラフ下の折りたたみで試せます。標本調査は有限母集団の非復元抽出で、既知の母標準偏差を使う教育用の正規近似区間です。偏った抽出の区間を信頼区間として解釈しません。p値は両側のモンテカルロ法で `(極端な結果数+1)/(反復数+1)`。ジニ係数は有限人数の補正なしで、全所得0では未定義です。タブ別の内容点検は `docs/STATISTICS_CONTENT_REVIEW.md` に記載しています。

題材・データ・文章・SVGは独自制作です。提供されたZIPや展開教材はリポジトリへ含めません。

全ラボと横断課題は共通のデータ表から開始します。データの入力は表での編集とCSVアップロードにまとめ、貼り付け用の独立ボタンは置きません。最後のタブには前のタブへ戻るボタンだけを表示します。ページ内の実験・解説へのショートカットリンクと参考資料の紹介は表示しません。

## ブラウザ内の全画面表示

8ラボと横断分析課題で「全画面」を利用できます。ブラウザのネイティブ全画面APIは使用せず、同じ操作中のDOMをdialogへ移します。終了ボタン・Escで元の表示とスクロール位置へ戻り、データ・表の下書き・設定を保持します。データタブは全画面でも全員分の行を表示し、画面全体の縦スクロールで確認・編集します。表示件数は全画面でも変更できます。分析の長い表や操作は「前の表示」「次の表示」で切り替えます。

ヒストグラムの順序は「データ→度数分布表→分布と箱ひげ図→代表値計算」です。右側の操作欄はなく、色分けは見出しのスイッチ、階級幅と縦軸の種類は表・グラフより上の同じ高さの操作欄にまとめます。最初の下端は、階級幅の整数倍から最小値を含むよう自動で決めます。色分けは同じ階級内で積み上げ、相対度数の分母は常に全件数です。累積相対度数は表で扱います。集団の値の一括変更はデータタブで表を編集し、図の集計条件とは区別します。従来のB移動量を持つ保存データは、表示されていた値を一度だけ元の観測値へ反映して移行します。

全画面の度数分布表は、見出し・階級幅の操作欄を常に表示し、残りの高さを表へ配分します。表示行数を自動調整し、ページ送りでは表の行だけを切り替えます。階級幅を変えたときは最初の行から表示します。

## 共通の分析レイアウト

標本調査・クロス集計・時系列・確率・仮説検定・ローレンツは、図表を全幅で表示します。タブで使う主な条件と実行ボタンは図表の上へまとめ、詳細設定と操作・読み取りのヒントは下部の折りたたみに置きます。図の選択や数値入力、乱数による再現、データタブとの共有は同じ状態を使います。

この6ラボの全画面は上部の終了ボタンとタブを固定し、図表・設定・長い計算表を画面全体の縦スクロールで確認します。分析の途中をページ分割で隠しません。散布図とヒストグラムの調整済み表示、全ラボのデータタブの共通操作は維持します。

## 分布・代表値ラボの統合

「データの分布」に統合し、タブは「データ → 度数分布表 → 分布と箱ひげ図 → 代表値計算」です。群別箱ひげ図をヒストグラムと元の値の間に置き、四分位数は中央値を除く上下半分方式、ひげは1.5IQR内の実測端点、範囲外は別の記号で示します。サンプル60件にはA・Bの両方で外れ値が現れます。Aは丸・無地・実線、Bはひし形・斜線・破線を使います。

代表値計算は同じデータの全体または各群から平均・中央値と四分位数・分散と標準偏差を計算し、数値の内訳を示します。発展の一元配置分散分析では群間・群内・全体平方和、自由度、平均平方、F値と上側確率を計算します。独立性・正規性・等分散性の前提を明示し、群不足・自由度0・群内平方和0のときはF検定の結論を出しません。

旧summaryモジュールは計算の互換性のため残しますが、一覧や横断課題では独立したラボとして出しません。旧URLは統合先へ案内し、保存済みの自分のデータがある場合は明示的な引き継ぎ・CSV保存を提供します。旧保存データを自動削除しません。
