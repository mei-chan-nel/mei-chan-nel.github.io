# 統計・データ分析 Interactive Lab

既存のHTML／ES ModulesとStudy Atlasのシェルを使う、依存ライブラリ不要のブラウザ教材です。

## 画面の構成

各ページで、目的と概念、使用するデータの出所・名前・列・件数、行った処理、具体的に試すことを説明します。高さを画面に固定せず、操作欄・図・表は内容に合わせて伸びます。グラフ／計算表は分析目的別のタブで切り替え、ミッションと項目別に折りたためる学問的な解説をページ下部に置きます。比較もページ内に開き、保存とCSV読込は補助ダイアログです。スマートフォンでは縦に配置します。

一覧は入力データと得られる結果を併記したリンクです。装飾のバッジ・イラストは置かず、操作可能なものをボタン・タブ・リンクとして表示します。統計の実験ページには広告枠を置きません。サイト全体のナビゲーションはヘッダーとフッターの「サイト案内」に残しています。

## 自分のデータを使う

確率モデルを除く8ラボで、UTF-8のCSV／TSVファイル選択と、表計算ソフトのセルの貼り付けに対応します。ファイルは1MB以内。項目名の有無、数値列、集団列を確認してから読み込みます。空欄や不正な数値を黙って除外しません。

| ラボ | 形式 |
|---|---|
| 相関・回帰 | 対応する数値2列、2〜300行 |
| ヒストグラム | 数値1列＋集団列（任意、2群まで）、2〜300行 |
| 代表値 | 数値1列、2〜300行 |
| 標本調査 | 数値1列＋集団列（任意）、2〜300行。読込全行を母集団とする |
| クロス集計 | 集団・方式・成功数・不成功数の4列。2集団×2方式の4行 |
| 時系列 | 非負の数値48か月分。月ラベルは任意。日付は連続したYYYY-MM、または相対月番号 |
| 仮説検定 | 群・対象数・成功数の3列2行。各群の対象数10〜1,000人 |
| ローレンツ | 非負の所得1列、2〜300行。元の単位を維持 |
| 確率 | ファイルの読込ではなく、確率・回数等を設定して実験する |

数値の絶対値の上限は1,000,000です。読み込んだ列名・単位・件数と出所を表示し、編集した行の数を元データと照合します。「読み込み直後に戻す」で自分の元データに戻せます。使用データ・処理・変更行数は分析記録にも残します。読み込んだデータを架空データと表示しません。

## 構成

- `shared/explanation.mjs`：解説本文を削らず、見出し単位のネイティブ折りたたみに変換。
- `<slug>/lab.mjs`：ラボ固有の計算・操作・図・ミッション・解説。
- `experience.mjs`：ページの目的と入出力。
- `build.mjs`：一覧・9ラボ・横断課題の11ページを生成。
- `workbench.mjs`：ラボの生きたDOMとイベントを保持し、表示と操作を再配置。
- `app.mjs`：出所と処理の表示、共通の保存・比較・ミッション・分析記録。
- `data-editor.mjs`：ファイル選択・貼り付け・列選択・データプレビュー。
- `shared/csv.mjs`：引用符、改行、BOM、CSV／TSVの読込と書出。
- `shared/data-model.mjs`：各ラボのデータ形式への変換・出所・元データへの復元。
- `shared/chart-layout.mjs`：PCの描画領域にSVGの座標を再配置。文字や点の当たり判定を縮小しない。
- `shared/math.mjs`：記述統計・回帰・階級集計・再現可能乱数・確率分布・ローレンツ曲線。
- `shared/validation.mjs`：保存JSONの型・件数・定義域・元データの検証。
- `shared/data.mjs`／`projects.mjs`：横断データと、データ確認・分析選択・記録／結論の3画面。

## 保存とデータ連携

各ラボは `study-atlas-statistics-<slug>-v1` に状態・比較条件・ミッション記録を保存します。JSONは実験状態を再開するための形式で、数値データのCSV読込とは区別します。ブラウザ保存が使用できなくても操作とJSON書出は利用できます。

横断課題は `study-atlas-statistics-dataset-v1` に2〜300行の `{id,x,y,group}` と列名・出所を保存し、`?dataset=project&field=y`（またはx）で分布・代表値へ、`?dataset=project`で相関へ渡します。ラボ内の変更は共通元データを変更しません。3群以上を渡したヒストグラムは最初の群とその他にまとめ、その対応を注記します。

分析記録は `study-atlas-statistics-results-v1`。使用データ・処理・結果・ミッションの記録を持ち寄り、問い・根拠・限界・結論をテキストで保存します。保存は同一ブラウザ・オリジン内です。データを外部サーバーへ送信しません。

## 再生成・検証

```sh
node lab/statistics/build.mjs
node lab/tools/build-pages.mjs --check
node --test scripts/statistics.test.mjs
python3 scripts/validate_portal.py --app-root ../info1-quiz-app
python3 scripts/validate_manual_ads.py
```

四分位数は奇数個なら中央値を除く上下半分の中央値。箱ひげ図は1.5IQR方式。分散はn／n−1を切替可能。標本調査は有限母集団の非復元抽出で、既知の母標準偏差を使う教育用の正規近似区間です。偏った抽出の区間を信頼区間として解釈しません。p値は両側のモンテカルロ法で `(極端な結果数+1)/(反復数+1)`。ジニ係数は有限人数の補正なしで、全所得0では未定義です。

参考は放送大学「身近な統計」の公開Web教材。題材・データ・文章・SVGは独自制作です。提供ZIPは32MiBの転送上限で確認できておらず、ZIPや展開教材は含めません。
