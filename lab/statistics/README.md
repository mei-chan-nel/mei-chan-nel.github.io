# 統計・データ分析 Interactive Lab

Study Atlasの静的HTML／ES Modulesで動くブラウザ教材です。現役8ラボと横断分析課題に、共通のデータ入出力・検証・モバイル表示を適用しています。グラフは独自SVG、統計計算は既存の各モデルを使います。Excelの入出力だけ、同梱のExcelJS 4.4.0（MIT）を必要時にWorker内で読み込みます。

## 対象と入力仕様

|ラボ|入力|件数・条件|
|---|---|---|
|グラフの選び方と読み取り|日付、日降水量、日平均気温、日照時間|2〜90行、日付は古い順・重複なし|
|欠損値とデータの扱い|日付または観測名、降水量|2〜90行、降水量の空欄／NAを許可|
|データの分布|数値、任意の集団列|2〜300行、集団は2種類まで|
|クロス集計|分類1、分類2、結果|2〜10,000行、各列2種類のカテゴリ|
|散布図と相関・回帰|対応する数値2列|2〜300行|
|時系列データの分析|年月、非負の数値|24〜300行、連続した月、古い順|
|標本調査と推定|数値1列|2〜300行、全行を母集団とする|
|統計的な判断と仮説検定|一意の参加者番号、試行数、正答数|2〜10,000人、整数、0≦正答数≦試行数≦10,000|
|横断分析課題|対応する数値2列、任意の集団列|2〜300行、集団は2種類まで|

列ごとの数値範囲・日付形式は `data/schema.mjs` とダイアログの入力条件を参照してください。仮説検定の正規近似には30人以上などの条件があり、満たさない場合は警告と計算不可の説明を表示します。欠損を許容するのは欠損値ラボだけです。

標準データは既存の実データです。新規データを乱数で作り直しません。欠損値ラボは気象庁の日降水量30件のうち6件を学習用に隠した固定例です。元の観測と補完を比較できます。標本調査の抽出では従来どおり乱数を使います。気象データの詳細は [foundations/README.md](foundations/README.md)、全体の変更・検証結果は [最終整備レポート](../../docs/STATISTICS_FINAL_UPGRADE.md) を参照してください。

## 共通のデータタブ

データは読み取り専用です。20件以下は全件、超過時は先頭10件と末尾10件を表示します。分布・クロス集計はカテゴリの組合せを広く見せる代表プレビューで、元の行番号と表示パターン数を添えます。入力データの順序を変える処理ではありません。計算・グラフ・全件ダウンロードには省略した行も含めます。

「全件データダウンロード」は現在使用する全件をCSVへ出力します。「自分のデータで試す」はCSV／Excelのひな形、ファイル選択、エラー・警告の確認、適用を共通ダイアログにまとめます。不正なファイルは既存データを変更しません。「標準データに戻す」で元に戻せます。相関の点の移動など、独立した分析実験の操作は維持しています。

## CSV・Excel形式

CSVはUTF-8 BOM付き、カンマ区切り、CRLFです。引用符・改行を含む文字列に対応します。Excelは `.xlsx`、両形式とも5MB以内です。`.xls` やShift-JISのCSVは変換方法を案内します。

ひな形の「データ」シート／CSVは共通の構造です。

1. `#StudyAtlas,1`
2. `#表題,ここに表題を入力`
3. `#文字列保護,apostrophe-v1`
4. `#列名,表示用の列名...`
5. `#型,列ごとの入力条件...`
6. 分析上の役割を表す列名
7. 以降に観測データ

「#表題」と「#列名」は編集できます。6行目の列名はひな形のまま残します。表題はデータタブ、分析対象名、図のタイトルに反映し、列名は対応する軸・凡例へ引き継ぎます。気象ラボの単位など、学習上の意味が固定された見出しは保持します。表題を省略した場合は「自分のデータ」です。

メタデータなしの通常のヘッダー付きCSV／Excelも受け付けます。必要な列名または既知の別名を使ってください。追加の列は警告し、分析に使用する列だけを取り込みます。全件ダウンロードも取り込んだ使用列が対象です。CSV自体には型情報の標準がないため、`#型`に入力条件を記録します。

Excelは「データ」シート、なければ最初のシートを読みます。他のシートは使用しない旨を警告します（ひな形の「入力方法」は除く）。Excelの日付セルをISO形式へ変換し、月の列では各月1日を年月へ変換します。数式は評価せず、値として貼り付けるよう具体的なセル位置を案内します。

## 検証・プライバシー

共通検証は列の存在・型・範囲・日付・重複・件数・欠損を確認し、個別検証はカテゴリ数、月の連続性、試行数との整合などを確認します。行・列と修正方法をまとめて表示し、エラーがあれば適用を止めます。警告だけなら内容を確認したうえで適用できます。エラーが多い場合は100件ずつ追加表示します。

読み込んだ内容はFile API、ブラウザ内のWorker、既存のlocalStorageだけで扱います。API・外部サービス・アクセス解析・エラーログへ送信しません。サーバーへのアップロード処理はありません。Excelライブラリも同じサイトに同梱しています。ZIPの展開量・件数、処理時間に上限を設け、CSVに出力する数式風の文字列には可逆的な保護を付けます。

## 表示・読み込み

`build.mjs` がタイトル・タブ・操作ボタン・説明・表示領域を静的HTMLへ出力します。依存のない `boot.mjs` が描画機会を設け、その後に必要モジュールと実データを読み込み、集計・描画へ進みます。生成した依存一覧で読み込みを並列化します。Excelと読み込みダイアログは操作時に読み込み、分析グラフは選択したタブで描画します。失敗時は画面とラボ選択を残し、再読み込みを案内します。

320・375・414pxとPC、通常・全画面で共通の操作を使います。狭い画面のタブは横スクロール、長い表は表の中だけ横スクロールします。円は縦横同率で描き、対の図は縦配置にします。全画面のナビと本文は独立して操作でき、Escapeでダイアログから元の画面へ戻れます。

## 主なファイルと再検証

- `data/schema.mjs`：スキーマ、個別条件、代表プレビュー
- `data/{view,dialog,files,codec}.mjs`：共通表示、CSV入出力、検証の案内
- `data/excel-worker.js`、`vendor/`：ブラウザ内Excel処理、ライセンス
- `data-tab.mjs`、`foundations/app.mjs`：既存の計算状態との接続
- `boot.mjs`、`build.mjs`：段階的表示と依存一覧の生成
- `data/data.css`、`shared/chart-layout.mjs`：共通のレスポンシブ表示
- 各ラボの `model.mjs`／`lab.mjs`：既存の統計計算・学習操作

```sh
node lab/statistics/build.mjs
node --test scripts/statistics.test.mjs scripts/statistics-data.test.mjs
```

旧summaryは分布ラボへの案内と明示的な保存データ移行、probabilityは一覧への転送、lorenzは新ラボへの案内を維持します。過去の保存データを勝手に削除しません。
