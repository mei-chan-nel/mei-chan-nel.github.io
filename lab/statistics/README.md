# 統計・データ分析 Interactive Lab

依存ライブラリ不要のブラウザ教材です。既存のHTML／ES ModulesとStudy Atlasのヘッダー・フッター・配色を使います。

- `index.html`：分野トップ。9ラボと横断分析課題への入口。
- `<slug>/lab.mjs`：そのラボ固有の操作・グラフ・説明・3ミッション。ページは各々独立して利用できます。
- `shared/math.mjs`：記述統計、最小二乗、階級集計、再現可能乱数、確率分布、ローレンツ曲線。
- `shared/ui.mjs`：SVG座標・入力・表・ドラッグ。ドラッグとスライダーは再描画中もdocumentのポインター追跡を保ちます。
- `shared/data.mjs`：横断課題の架空データと検証済み保存形式。
- `shared/validation.mjs`：実験JSONの型・件数・定義域、比較データ・記録の検証。
- `app.mjs`：初期化・自動保存・JSON読込／書出・条件比較・ミッション記録・分析課題への記録。
- `projects.mjs`：共通データ編集、目的別ラボへの移動、記録の集約、分析レポート書出。
- `catalog.mjs`／`build.mjs`：一覧と11ページを生成。`lab/catalog.mjs`には統計分野入口を登録。

## 再生成・検証

```sh
node lab/statistics/build.mjs
node lab/tools/build-pages.mjs
node --test scripts/statistics.test.mjs
python3 scripts/update_sitemap.py --app-root ../info1-quiz-app
python3 scripts/validate_portal.py --app-root ../info1-quiz-app
python3 scripts/validate_manual_ads.py
```

共通シェルは任意の階層に対応します。既存の1階層ラボの出力は変わりません。HTML内の本文はラボ固有モジュールで生成し、トップ・個別ページ・パンくず・メタデータは静的HTMLで持ちます。

## 保存とデータ連携

`study-atlas-statistics-<slug>-v1`に各実験と比較条件・ミッション記録を自動保存します。操作時のみ保存し、空の初回表示では既存保存を上書きしません。保存できないブラウザでも実験とJSON書き出しが利用できます。データを外部サーバーへ送信しません。

横断課題は`study-atlas-statistics-dataset-v1`に2〜300行の`{id,x,y,group}`を保存し、`?dataset=project&field=y`（または`x`）でヒストグラム・代表値へ、`?dataset=project`で相関へ渡します。読込時にそのデータから新しく実験を開始し、ラボ内編集は共通元データを変更しません。ヒストグラムは最初の集団をA、その他の集団をBとして表示し、変換元の集団名を注記します。2群より多い場合は複数の集団をBにまとめた表示になります。

`study-atlas-statistics-results-v1`に分析時点の統計量とミッション記録を残します。横断課題ではこれを一覧し、問い・根拠・限界・結論をテキストに書き出せます。保存は同じブラウザ・同じオリジン内です。別端末へはJSONファイルを利用してください。

## 計算の定義

四分位数は奇数個の場合に中央値を除いた上下半分の中央値。箱ひげ図は1.5IQR方式で、教科書の最小最大方式との差を明記しています。分散の分母はnとn−1を切替。相関と回帰は分散ゼロ時に未定義を表示します。

標本調査は120人の有限母集団・非復元抽出。既知の母標準偏差と有限母集団補正を使う正規近似区間を、仕組みの観察用に表示します。偏った抽出ではこの区間を信頼区間として解釈しません。検定は両側のモンテカルロ法でp=(極端な結果数+1)/(反復数+1)。離散的な同順位を含む判定に合わせて棄却域を表示します。

ジニ係数は有限人数の補正なし。全所得0・負の所得では累積所得比率を定義しません。所得は非負に限定。正規CDFは数値近似です。

## 参考資料
