# グラフの読み取り・欠損値：共通データ

気象庁「過去の気象データ検索」、東京（地点47662）、2025年6月1日〜7月31日。

- [2025年6月](https://www.data.jma.go.jp/stats/etrn/view/daily_s1.php?prec_no=44&block_no=47662&year=2025&month=6&day=&view=)
- [2025年7月](https://www.data.jma.go.jp/stats/etrn/view/daily_s1.php?prec_no=44&block_no=47662&year=2025&month=7&day=&view=)
- [値欄の記号](https://www.data.jma.go.jp/stats/data/mdrr/man/remark.html)

2026-10-25に原表を確認。列は日付、日降水量（mm）、日平均気温（℃）、日照時間（h）。原表の記号付きCSVを同梱。数値の推定や丸め直しは行わない。降水量の`--`は現象なしとして0に変換、`0.0`は公表値0.0として集計する。0.0は降水があったが0.5mm未満であり、現象なしとは異なる。グラフの「降水量1mm以上の日」はこの記号差に依存しない定義。日最高気温などの準正常値がある列は今回使わない。

グラフラボは61日、欠損値ラボは6月の30日を使う。欠損値ラボの空欄は実測値を**教材上で隠したもの**。気象庁で欠測していたとは表示しない。隠す前の値を固定して、同数の欠損でも無作為・大雨の日・降水量の少ない日で結果が変わることを比較する。直接入力・CSVでは空欄とNAをnull、0と`--`を数値0として扱う。値を編集すると実測の基準値との対応を解除する。

- 6月：降水量合計100.0mm、30日。7月：合計74.5mm、31日。
- 分散は記述統計として件数nで割る。平均補完では有効値だけの平均は保存されるが、分散は有効件数/全件数の比だけ小さくなる。
- グラフの切替は、棒・折れ線では日別値、散布図では同じ日の2量、ヒストグラムでは階級ごとの日数、円では閾値で分けた日数の構成比を描く。各変換と分母を画面に明記。

新2ページは`foundations/app.mjs`で日付とnullable数値を扱い、既存の数値のみを受け付ける他ラボの入力規則を変更しない。全画面と右ナビは既存の共通部品を使用。旧ローレンツページは新ラボへの案内に変更し、ブラウザー内の保存済み所得データを削除しない。
