# グラフの読み取り・欠損値：共通データ

気象庁「過去の気象データ検索」、東京（地点47662）、2025年6月1日〜7月31日。

- [2025年6月](https://www.data.jma.go.jp/stats/etrn/view/daily_s1.php?prec_no=44&block_no=47662&year=2025&month=6&day=&view=)
- [2025年7月](https://www.data.jma.go.jp/stats/etrn/view/daily_s1.php?prec_no=44&block_no=47662&year=2025&month=7&day=&view=)
- [値欄の記号](https://www.data.jma.go.jp/stats/data/mdrr/man/remark.html)

2026-10-25に原表を確認。列は日付、日降水量（mm）、日平均気温（℃）、日照時間（h）。原表の記号付きCSVを同梱。数値の推定や丸め直しは行わない。降水量の`--`は現象なしとして0に変換、`0.0`は公表値0.0として集計する。0.0は降水があったが0.5mm未満であり、現象なしとは異なる。グラフの「降水量1mm以上の日」はこの記号差に依存しない定義。日最高気温などの準正常値がある列は今回使わない。

グラフラボは61日、欠損値ラボは6月の30日を使う。欠損値ラボの空欄は実測値を**教材上で隠したもの**。気象庁で欠測していたとは表示しない。隠す前の値を固定して、同数の欠損でも無作為・大雨の日・降水量の少ない日で結果が変わることを比較する。直接入力・CSVでは空欄とNAをnull、0と`--`を数値0として扱う。値を編集すると実測の基準値との対応を解除する。

- 6月：降水量合計100.0mm、30日。7月：合計74.5mm、31日。
- 分散は記述統計として件数nで割る。平均補完では有効値だけの平均は保存されるが、分散は有効件数/全件数の比だけ小さくなる。
- グラフの切替は、棒・折れ線では日別値、散布図では同じ日の2量、ヒストグラムでは階級ごとの日数、円では閾値で分けた日数の構成比を描く。各変換と分母を画面に明記。

新2ページは`foundations/app.mjs`で日付とnullable数値を扱い、既存の数値のみを受け付ける他ラボの入力規則を変更しない。全画面と右ナビは既存の共通部品を使用。旧ローレンツページは新ラボへの案内に変更し、ブラウザー内の保存済み所得データを削除しない。

## グラフ選択の教材構成（2026-10-25）

タブはデータ→気温の変化→降水量の内訳→日照と気温。題材を開くと、その問いの推奨グラフを選ぶ。気温は折れ線、降水量の日数比較は棒、割合は円、日照と気温の関係は散布図。別のグラフも全てクリックでき、描けるものは実際に描く。表す全体や対応する数値がそろわない場合は、選択した表示領域で理由を説明する。

降水量は1mm未満・1mm以上10mm未満・10mm以上で重複なく区分する。初期61日の内訳は48日・6日・7日。日照時間は区分に使わない。棒/折れ線/円で区分を比較し、同じ3区分の不等幅ヒストグラムも表示する。幅は1/9/25mm、縦軸は日数/幅（度数密度）。面積が日数を表す。上限のない10mm以上は、最大観測値31mmを含む35mmで表示上限を定め、補足欄に計算と上限の扱いを説明する。入力データ変更時は最大値を含む次の5mm刻みの値を使う。区分の順序を変える操作はグラフ下に配置する。

気温は折れ線/棒/ヒストグラム/気温帯別の日数の円で比較する。分布図が常に不適切なのではなく、今回は日付順の変化を読む問いであることを明示する。棒では変化が見えにくく、0℃から棒を伸ばす意味もないことを簡潔に説明する。軸の下限の実験は、量の比を比較できる正の降水量2日分を用いる。

日照と気温は散布図のほか、日付を横軸にした2系列の折れ線/棒を描く。既定は重ね表示で、上下2段にも切り替えられる。重ね表示は左が日照h、右が気温℃の別目盛り。日照は丸・実線/単色、気温は四角・破線/斜線模様で、色に依存せず区別する。目盛りが違うので交点や同じ高さを同じ量と読まない。各量を別々に集計した円2つ/ヒストグラム2つも表示し、分布は分かるが同じ日の対応は失うことを明示する。これらには日付の対応が必要な確認問題を表示しない。初期の橙の強調点を撤去し、明示的に選択した点のみを強調する。

全画面の主領域は見出し・操作・主グラフの3行。グラフがなく解説も空の選択でも右ナビを表示し、折りたたみと幅の設定を保つ。解説は右ナビ、読み取り問題/元データ/降水量軸の補足は下部開閉パネル。高さ520px以下は左領域をスクロール可にして図の最小180pxを確保する。同じタブのdetails開閉状態を保持。lessonVersion4へ移行し、旧版の観測値/出所は保持する。題材を開き直すとおすすめへ戻り、同じ題材での回答や全画面切替では試していた種類を保つ。

円と2系列の時系列SVGはdata-preserve-geometry、preserveAspectRatio="xMidYMid meet"を付ける。shared/chart-layout.mjsの非等方座標変換から除外し、SVG自身の等方拡大縮小で枠へ収める。横長/縦長の模擬サイズを実際のフィット関数へ渡し、扇形座標やviewBoxが変わらないことを検証する。
