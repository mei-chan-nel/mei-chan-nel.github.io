2026-10-25に原表を確認。列は日付、日降水量（mm）、日平均気温（℃）、日照時間（h）。原表の記号付きCSVを同梱。数値の推定や丸め直しは行わない。降水量の`--`は現象なしとして0に変換、`0.0`は公表値0.0として集計する。0.0は降水があったが0.5mm未満であり、現象なしとは異なる。グラフの「降水量1mm以上の日」はこの記号差に依存しない定義。日最高気温などの準正常値がある列は今回使わない。

グラフラボは61日、欠損値ラボは6月の30日を使う。欠損値ラボの空欄は実測値を**教材上で隠したもの**。気象庁で欠測していたとは表示しない。隠す前の値を固定して、同数の欠損でも無作為・大雨の日・降水量の少ない日で結果が変わることを比較する。直接入力・CSVでは空欄とNAをnull、0と`--`を数値0として扱う。値を編集すると実測の基準値との対応を解除する。

- 6月：降水量合計100.0mm、30日。7月：合計74.5mm、31日。
- 分散は記述統計として件数nで割る。平均補完では有効値だけの平均は保存されるが、分散は有効件数/全件数の比だけ小さくなる。
- グラフの切替は、棒・折れ線では日別値、散布図では同じ日の2量、ヒストグラムでは階級ごとの日数、円では閾値で分けた日数の構成比を描く。各変換と分母を画面に明記。

新2ページは`foundations/app.mjs`で日付とnullable数値を扱い、既存の数値のみを受け付ける他ラボの入力規則を変更しない。全画面と右ナビは既存の共通部品を使用。旧ローレンツページは新ラボへの案内に変更し、ブラウザー内の保存済み所得データを削除しない。

## グラフ選択の教材構成（2026-10-25改訂）

グラフのラボは期間・変数の自由選択を外し、具体的な問いと表現を対応付ける構成に改訂。3区分の日数の差→棒、気温の時間変化→折れ線、3区分の全体比→円、気温の分布→ヒストグラム、日照と気温の関係→散布図。区分は降水1mm以上、1mm未満かつ日照6h未満、1mm未満かつ日照6h以上で全日を重複なく分ける。問いの変更で対応するデータと推奨グラフを即時表示。別の表現の可否/読み取りやすさを具体的に説明し、読み取り問題と解答の根拠を計算する。

℃は間隔尺度なので気温を棒の長さの比や円の割合で表さない。気温は0起点に固定せず位置と差で読む折れ線に限定。軸の下限の実験は正の降水量2日分の棒で行い、実際の量の比と棒の長さの比を区別。旧v1保存データの観測値は保ち、旧期間/軸設定を新しいlessonVersion2の操作状態へ移行する。欠損ラボの内容/データは変更しない。

## 題材別タブと全画面配置（2026-10-25再整理）

グラフはデータ→気温の変化→雨と日照の内訳→日照と気温という題材別タブへ整理。目的ドロップダウンと重複する比較タブを撤去。気温は折れ線/棒/ヒストグラム、3区分は棒/折れ線/円、2量の関係は散布図/接続線を表示して、同じ観測値の何が読み取れないかを説明する。Celsiusの棒は表示するが、長さから温度の比は読めないことを明示。気温の円や、区分だけからの散布図など、必要なデータ構造がないものは選択不可とし理由を掲載。

全画面の主領域は見出し・操作・主グラフの3行。静的な解説は既存の右ナビへ、読み取り問題/元データ/降水量軸の補足は既存の下部開閉パネルへ移す。補足グラフは自動全画面サイズ計算から除外。高さ520px以下は左領域だけをスクロール可にし、グラフを最小180px確保する。通常表示は本文の自然な流れを維持。問題の回答や補足の数値変更後にも同じタブのdetails開閉状態を保持する。lessonVersion3へ操作状態を移行し、v1/v2の観測値/出所を保持。
