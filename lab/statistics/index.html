統計・データ分析

自分のデータを読み込み、分布・平均・相関などを可視化して確かめる。

自分のCSV・表データから始める分布・相関などのラボでもCSVの読込・貼り付けができます。サンプルならすぐに操作できます。

散布図と相関・回帰→

2つの数値の関係を調べ、回帰直線で予測する。

対応する2列の数値 → 散布図・相関係数・回帰直線

データの分布とヒストグラム→

データがどこに集まるかを、区切り方や集団を変えて調べる。

1列の数値＋集団（任意） → ヒストグラム・度数分布表

代表値とばらつき→

データの中心とばらつきを、平均・中央値・箱ひげ図で比べる。

1列の数値 → 代表値・標準偏差・箱ひげ図

標本調査と推定→

データの一部から全体を推定し、抽出方法と誤差の関係を調べる。

母集団の数値＋集団（任意） → 標本平均・推定値の分布・区間

クロス集計とデータの関係→

割合の分母を確かめ、集団を分けた場合と合計した場合を比べる。

2集団×2方式の成功・不成功数 → クロス集計表・割合の比較

時系列データの分析→

月別データの変化をならし、4つの予測方法を実測値で検証する。

48か月分の数値 → 移動平均・伸び率・予測誤差

確率と確率分布→

試行を繰り返し、実験結果が理論上の確率にどう近づくかを調べる。

確率・試行回数などのモデル条件 → 相対度数・確率分布・区間確率

統計的な判断と仮説検定→

AとBの成功率の差を、偶然のばらつきと比較して判断する。

A・Bそれぞれの対象数と成功数 → 帰無分布・p値・誤判定率

格差とローレンツ曲線→

所得を再分配し、分配の違いが格差の指標にどう表れるかを調べる。

1人ずつの所得（0以上） → ローレンツ曲線・ジニ係数

同じデータで、複数の分析を比べる→

分布・代表値・相関の結果を持ち寄り、根拠と限界をまとめる。

共通データ → 3つのラボ → 分析レポート

確率はモデル条件から行う実験です。各ラボの入力形式・計算の前提は、データ読込画面と解説で確認できます。
