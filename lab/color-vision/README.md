# 色覚シミュレーター

`/lab/color-vision/`。既存Interactive Labの書体・配色・ヘッダーに合わせた、依存パッケージ不要の静的教材です。`feat/color-vision-simulator`で制作し、公式サイトのmainは変更しません。

## 学習内容

題材は独自制作の架空の「青葉祭・当日案内ページ」1点。通常、P型、D型、T型の4列と、直前の状態／改善後の2段を比較します。初期状態では上下を同じ画像にし、未変更であることを明記しています。

| ステップ | 変更 | 学習上の注意 |
| --- | --- | --- |
| 0 初期状態 | 変更なし | 状態と凡例の色対応、赤緑の実線、地図の青緑、淡い文字を観察する。 |
| 1 配色 | 状態・グラフ・案内パネルを青／オレンジへ | P・D列の系列の区別が改善する一方、白文字と明るいオレンジのコントラストが低下する。 |
| 2 コントラスト | お知らせと案内パネルの背景／文字 | 読みやすさと、色だけの意味付けは別の問題であることを確認する。地図の白文字はまだ改善しない。 |
| 3 手掛かり | 状態名、記号、地図の模様とA/B/C、時刻表の会場名、グラフの線種・点・直接ラベル | 色以外で情報をたどれる。グラフのラベルを近い位置に追加してしまい、重なりが生じる。 |
| 4 整理 | グラフ凡例を分離、オレンジの線を濃く、会場記号を統一、地図名を白地の濃い文字に | 手掛かりを保ちながら重なりと文字の明暗差を改善する。実際の利用者による確認の必要性も示す。 |

全体と部分拡大を往復できます。倍率、ドラッグ、キーボードの矢印移動は全画像で同期します。画面幅によらず通常・P・D・T型の4列を表示します。説明は比較画像の下に置き、PCでは4項目を横並びにして比較画像の横幅を確保します。全体表示の変更枠は番号のみを表示し、説明のボタンと対応します。

## 色覚モデル

Brettel, Viénot & Mollon (1997), *Computerized simulation of color appearance for dichromats*, DOI: [10.1364/JOSAA.14.002647](https://doi.org/10.1364/JOSAA.14.002647)。P・D・T型すべてに2投影面を使います。完全な2色覚の近似であり、色弱の程度のスライダーや、シミュレーションでの適合判定は実装しません。

係数はNicolas Burrusの[libDaltonLens](https://github.com/DaltonLens/libDaltonLens/blob/master/libDaltonLens.c)（Public domain / Unlicense）。sRGB標準とSmith–Pokorny 1975 LMS、RGB白を中立軸とする係数を使用します。

1. ブラウザのsRGB Canvasに描画。自分の画像の透明部分は白に合成する。
2. sRGB伝達関数の逆変換で線形RGBへ変換する。
3. 分離面の内積を判定し、対応する投影行列を適用する。
4. 表示域へクリップしてsRGBへ戻し、8bitへ四捨五入する。

初期ページの赤／緑は、このモデルのP・D列で色差が小さくなります。変更後の青／オレンジは区別がつきやすくなりますが、色差の数値を知覚の閾値や合否として扱いません。T列では地図の青／緑が近づくため、地図のA/B/Cと模様にも意味があります。

飲食パネルの文字と背景のWCAG相対輝度比は `白 / #567658 = 5.09:1` → `白 / #e69f00 = 2.25:1` → `#203b40 / #fff3d6 = 10.81:1`。比率は**元のsRGB値**から計算し、シミュレーション画像の値では判定しません。小さな画面、視力、実際の利用者の見え方も含めて確認が必要です。

## 自分の画像

- PNG・JPEG・WebP、20 MiB以下、4,000万画素以下。
- 長辺1,600pxを上限に縦横比を保って縮小する。縮小した場合は元の寸法と処理寸法を表示する。
- ファイルはObject URL経由でデコードし、変換はWeb Workerで実行する。Worker非対応の場合は型ごとにイベントループを挟んでブラウザ内で変換する。
- サーバーへのアップロード、外部API、解析、永続保存は使わない。Object URLは読込後に破棄する。新しい入力が来た場合は古い結果を適用しない。
- 現状のみ4列で表示する。4種類をまとめたPNGと、通常／P／D／Tの個別PNGを書き出せる。表示位置に関係なく処理した画像全体を保存する。出力には手法と近似の注記を付ける。
- 削除またはリロードで画像を破棄する。学習モードとの切り替え中は、選択したステップと読込画像を保持する。

## 検証

```sh
node lab/color-vision/simulation.test.mjs
node lab/tools/build-pages.mjs --check
git diff --check
```

`reference-fixtures.json`は2026-10-15に取得した上記の公開C実装をコンパイルし、2色覚・severity 1.0で生成した102色×3型の参照値です。両投影面をカバーします。C実装の非線形sRGB符号化は切り捨て、JavaScriptは四捨五入のため、最大1階調の許容差で照合します。追加で全256段階の無彩色・sRGB往復、アルファ保持、既知のコントラスト比と教材の配色の関係を検証します。

ブラウザ検証では、5段階の前後連続性、8枚の同期、ハイライト、部位への拡大、4列の常時表示と説明欄の下配置、モード保持、ローカル画像読込・白背景合成・削除、5種類のPNG寸法、ダイアログ、320/390pxの横はみ出し、外部リクエストとJSエラーの不在を確認しています。axeによるWCAG A/AAの重大な違反も確認します。シミュレーション対象のページは学習用の問題を含むため、教材UIと区別します。
