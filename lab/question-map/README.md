# 問題マップ

情報デザインの教材。公開パスは `/lab/question-map/`。Labの共通シェルで生成し、共通のナビゲーション・配色・広告枠を使用します。HTMLの本文は `../tools/templates/question-map.html`、登録は `../catalog.mjs` が正本です。

## データ

実行時に `/info1-quiz-app/data/questions/` の4ファイルを `no-cache` で取得します。問題・選択肢・解説・タグ・出典は `completed_questions.json` のオブジェクトを直接参照し、地図用の本文・コピー・加工した問題データは生成しません。

- `map_points.json`：`points[questionId] = [x, y]`。PCA(50) → t-SNEの既存座標を使用。
- `map_terms.json`：`terms[term] = [questionId, …]`。自動抽出の候補から表示する語を選択。
- `map_metadata.json`：schema version、問題数、生成元のSHA-256、配置方法を確認。

全ID・問題数・有限座標・3ファイル間の生成元ハッシュを検査します。Web Cryptoが使えるHTTPSまたはlocalhostでは本文のSHA-256も照合します。生成元のWindows環境とGit配信の改行差を考慮し、LF・CRLFの両方を照合します。Web CryptoのないHTTP環境では構造・ID・世代整合性の検査を使用します。欠落・不一致・通信失敗時は理由と再読み込みボタンを表示します。

現在の原本は1,438問・1,438点・1,312語候補。実際の件数はJSONから取得します。候補には文章の断片が含まれるため、長さ・文字種・語尾を保守的に絞ります。本文のタグは低倍率で優先表示し、中倍率で候補語を加えます。語の厳密な形態素解析や意味保証は行いません。

## 表示と操作

Canvasに座標点・グリッド・地形を描き、読み上げや選択のできるDOMラベルとカードを重ねます。4単位の空間索引で表示範囲を検索し、表示するDOM数を制限します。正答率の地形は履歴更新時だけ低解像度の場を計算して再利用します。

初期の全体表示を1倍とし、拡大率約2.2・5・12・26倍でタグ、単語、問題文、選択肢、解説へ進みます。境界の8%の幅で切替の振動を防ぎ、ラベルにはフェードと既存候補の優先を使用します。表示範囲の地域ごとの出現数・特徴度からラベルを選び、現在の地理的アンカーを可能な限り維持します。文字幅を測り、ラベル同士・問題カード・操作ボタンの重なりを避けます。

ホイール・ドラッグ・慣性移動、1本指の移動・2本指のピンチ、＋／−・段階ボタン・全体表示、矢印・Home・Escapeに対応します。ラベルの上からもドラッグとピンチができます。キーボードでラベルを選択すると、その地域へ近づきます。動きを減らす設定ではアニメーションと慣性を省きます。

タグ・単語・問題文の検索、密集する点を押したときの近隣問題一覧、問題カード内の近隣一覧を用意しています。問題の全文を表示し、長い内容はカード内でスクロールします。カードのスクロールは地図の移動・拡大と独立します。学習アプリへのリンクは既存の `?challenge=<questionId>` に接続します。

## 解答履歴

`info1LearningRecord:v1` の `q[id][0]`（回答回数）と `[1]`（正答回数）を読み取り専用で参照します。現在形式がない場合は `info1QuizStats:v4` の旧履歴も読みます。履歴を書き込んだり移行したりせず、消去済みの現在形式を旧履歴で上書きしません。未知ID・不正値は無視します。

近隣の回答回数と正答回数にGaussianの重みを掛け、正答回数／回答回数を背景色にします。低正答率は赤〜黄、高正答率は緑〜青、回答がない領域は中立色。問題の点にも個別の正答率を反映し、カードには回答数と正答率を明記します。未挑戦を誤答として計算しません。`storage`、`pageshow`、ウィンドウへの復帰で更新し、他タブでの学習・履歴消去も反映します。

履歴は送信しません。共通のサイト解析・広告は既存Labと同じ構成です。座標の軸・遠い島同士の距離・島の面積を難易度や学習量として解釈しないこと、地形の色は近隣を混ぜた目安であることを画面に説明しています。

## 検証

```sh
node lab/tools/build-pages.mjs --check
node scripts/question-map.test.mjs
python scripts/preview_site.py --host 127.0.0.1 --port 8773 --app-root ../info1-quiz-app
```

プレビューサーバーを起動したまま、別のターミナルで実行します。

```sh
LAB_PLAYWRIGHT_MODULE=/workspace/.lab-test-tools/node_modules/playwright \
LAB_AXE_MODULE=/workspace/.lab-test-tools/node_modules/axe-core/axe.min.js \
node lab/tools/test-question-map.mjs
```

ユニット検証は実データ整合性、本文の改行差と変更の検出、空間索引、拡大中心の保持、段階の安定性、表示範囲に応じた用語変更、衝突回避、現行／旧履歴と消去、回答回数による地形の重み付けを確認します。ブラウザ検証は1280・390・320pxで5段階の表示・原文一致・横溢れ／文字衝突・検索・ホイール／キーボード・ピンチ／移動、履歴変更と消去、地形の表示切替、欠落データ、WCAGの自動検出可能な項目を確認します。ブラウザ検証の履歴はテスト専用コンテキストに注入し、外部の解析・広告リクエストは置き換えます。

配信時はポータルとアプリを同じオリジンに置きます。既存JSONを直接参照する構成を維持するため `catalog.mjs` の `standalone: false` で単体HTMLの書き出し対象から除外しています。
