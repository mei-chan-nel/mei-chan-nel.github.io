# PDFの複雑な図表領域の抽出レビュー

`pdf-regions.json` は4試験のレビュー済み領域表である。各試験のキーの下に **0始まりのPDFページ番号（文字列）** があり，領域にはPDFネイティブ座標 `[x0,y0,x1,y1]`，`kind`（figure/table/program），説明を記録した。全PDFの用紙は約 **515.91×728.5ポイント**。小さい解答欄の四角形だけを独立した図にしていない。

| 試験 | 領域数 |
|---|---:|
| 2025_main | 40 |
| 2025_supp | 49 |
| 2026_main | 58 |
| 2026_supp | 61 |
| 合計 | 208 |

図の凡例・軸名・拡大図・表題・配列名・添字・プログラムの行番号とインデントを含む。左右のパネル・連続する配列を一つの領域にまとめた箇所がある。解答欄が図表内にある場合はその位置を保ち，解答欄の後続オーバーレイができる領域としている。

## 手法

`pdf_regions.py` は `get_drawings()` と画像配置を近接クラスタ化し，近傍の短い文字行を含める下書き検出器を提供する。幅0または高さ0の線は，MuPDFで空矩形と見なされるため，クラスタ化前に0.2ポイントだけ厚みを与えている。16/34×16ポイント程度の解答欄の単独枠は除外する。下書きは，紙面の12ページ単位のコンタクトシートで目視確認し，最終JSONを別途調整した。

再確認用のシート生成：

```sh
python import-review/pdf_regions.py --regions import-review/pdf-regions.json --sheets /tmp/pdf-region-sheets
```

自動検出の新しい下書きを作る場合：

```sh
python import-review/pdf_regions.py --draft /tmp/pdf-regions-draft.json --sheets /tmp/pdf-region-drafts
```

レビュー済みJSONはこの下書きの再出力で上書きしないこと。自動検出だけでは，角丸プログラム枠の外側，離れた凡例，枠線に接していない軸名，外側の配列名を落とすことがある。また，文章だけの囲みを図と誤判定することがある。

## 本文として組み直す領域

Fittsの法則・担当者選択規則・プライバシーポリシー・関数の説明・推定規則・補正方法など，枠内が通常の文章だけのものは原則として図の領域に含めていない。下線だけの長い線も図として扱わない。文章として段落化し，条件や箇条書きの意味を保って表示する。2026追試の会議記録は階層構造が問われるため，記録そのもの（図2）は保持する。2026追試のDNA文字列の式は，式の順序・対応が重要なので小さなfigure領域として保持した。

## ページ境界・セクション開始

`pdf-section-starts.json` にセクションの先頭ページと実際の見出し上端を記録した。q2aの `top:120.5` は「A」とその導入文の開始位置であり，共通の「第2問（30点）」は同じページの `y:79` から始まる。q1の初ページでは上の試験科目表示を除外すると本文見出しは `y:159`。その他の大問見出しは原則 `y:79`，Bの開始は `y:80.5`。

**本文の下端を一律640ポイントで切らない。** 多くの正規の図題・プログラム図題が `y:640〜651` に置かれている。今回の領域は必要に応じて655まで延ばした。ページ番号・冊子番号のフッターは `y:660.5〜670.8` 付近なので，それとは区別できる。

## 限界と確認事項

- 領域は図の内容を改変せず，元ページからSVGまたは高解像度ラスタで切り出すためのもの。目視で読める実際の内容に合わせている。PDF内部では，クリッピングパスの外へ図形の座標が延びている場合がある（例：2025本試験の散布図）。元ページのクリッピングを維持して書き出す。
- 図を切り出す際は，字形のパス化・フォント埋め込みなどにより，独自フォントの数字や解答記号も元と同じ見た目にする必要がある。これらは本文用Unicode復号とは別である。
- 2026本試験の生年UIと2値マスク，2025追試の迷路表現の再掲など，本文と図が左右に並ぶ箇所では本文を巻き込まない狭いx範囲を設定した。
- 2026追試32ページの候補グラフは，「あ・い・う・え」の図外ラベルも含む。
- 最終的に，領域端をまたいで文字が切られていないことを全ページのテキスト行の矩形で検査した。大きな図形で領域外に残るものも点検し，本文の枠・下線・PDF内部のクリップ外座標であることを確認した。
- JSONの領域は問題本文を横断する注釈の最終配置まで決めるものではない。各領域をSVGとして表示した後，文章との重複や読順をプレビューで確認する必要がある。
