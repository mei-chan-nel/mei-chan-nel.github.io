主記憶装置・補助記憶装置

「主記憶装置・補助記憶装置」とは

コンピュータで使われる記憶装置は、役割によって大きく、主記憶装置と補助記憶装置に分けられます。

主記憶装置

主記憶装置は、CPUが処理するときに、実行中のプログラムや使用中のデータを一時的に置く装置です。メインメモリとも呼ばれ、一般的にはRAMが使われます。

CPUがプログラムを実行するときは、SSDなどに保存されているプログラムやデータを主記憶装置へ読み込んでから処理します。主記憶装置は高速に読み書きできるため、CPUは必要な命令やデータをすばやく利用できます。

ただし、一般的なRAMは揮発性メモリであり、コンピュータの電源を切ると記憶していた内容が失われます。

補助記憶装置

補助記憶装置は、プログラムや文書、画像などのデータを長期間保存するための装置です。ストレージとも呼ばれ、SSDやハードディスク、USBメモリなどが該当します。

補助記憶装置は、電源を切っても記憶している内容が失われない不揮発性の記憶装置です。一般に、主記憶装置よりも読み書きは遅いものの、より多くのデータを保存できます。

キャッシュメモリ（参考）

キャッシュメモリは、CPUと主記憶装置の間にある、主記憶装置よりもさらに高速な記憶装置です。多くの場合、CPUの内部やその近くに置かれています。

CPUの処理速度は非常に速いため、必要なデータを毎回主記憶装置から読み出していると、データが届くまでCPUが待つ時間が生じます。そこで、よく使われる命令やデータをキャッシュメモリに一時的に保存しておき、同じデータが必要になったときにすばやく取り出せるようにします。

キャッシュメモリは主記憶装置より高速ですが、容量は小さく、価格も高くなります。そのため、主記憶装置の代わりにすべてのプログラムやデータを保存するのではなく、近いうちに使われそうなデータの一部だけを保持します。

プログラムが実行される流れ

例えば、補助記憶装置に保存されている文書作成ソフトを起動すると、次のように処理されます。

  1. 補助記憶装置から、プログラムや必要なデータを主記憶装置へ読み込む。

  2. CPUが主記憶装置上の命令やデータを使って処理する。

  3. よく使われる命令やデータの一部が、キャッシュメモリに置かれる。

  4. 作成した文書を保存すると、主記憶装置上のデータが補助記憶装置へ書き込まれる。

このように、それぞれの記憶装置は次の役割を分担しています。

  • キャッシュメモリ：よく使う命令やデータを置き、CPUの待ち時間を減らす

  • 主記憶装置：実行中のプログラムや使用中のデータを一時的に置く

  • 補助記憶装置：プログラムやデータを電源を切った後も長期間保存する

主記憶装置は「現在の作業をする場所」、補助記憶装置は「データを保存しておく場所」、キャッシュメモリは「すぐ使うものを手元に置く場所」と考えると、違いを理解しやすくなります。

記憶装置 · EXAMPLEオリジナル問題

主記憶装置と補助記憶装置の説明として、最も適切なものはどれか。

  1. 0

    主記憶装置は実行中のプログラムやデータを一時的に置き、補助記憶装置はデータを長く保存するために使う。

  2. 1

    主記憶装置は紙へ印刷する装置で、補助記憶装置は画面へ表示する装置である。

  3. 2

    主記憶装置は電源を切っても必ず内容が残り、補助記憶装置は必ず内容が消える。

  4. 3

    主記憶装置と補助記憶装置は、名称が違うだけで役割も性質も同じである。

解答・解説を確認

正解0．主記憶装置は実行中のプログラムやデータを一時的に置き、補助記憶装置はデータを長く保存するために使う。

解説

主記憶装置はCPUが処理するプログラムやデータを一時的に置く。SSDやHDDなどの補助記憶装置は、電源を切った後もデータを保存するために使う。
