IPアドレス

「IPアドレス」とは

IPアドレス（Internet Protocol Address）とは、インターネット（TCP/IPを使ったネットワーク通信）で、通信相手となる機器のネットワークインタフェースを識別するための番号です。

インターネットでは、多数のコンピュータやスマートフォン、サーバなどが相互に通信しています。インターネットを流通するデータ（パケット）には「どこから、どこへ送るのか」を示す情報として、送信元IPアドレスと宛先IPアドレスが付けられます。

たとえば、Webサイトを閲覧するときは、WebサーバのIPアドレスを宛先として通信します。

このため、IPアドレスは、よく「インターネット上の住所」にたとえられます。

IPv4

現在利用されている代表的なIPアドレスの一つがIPv4（Internet Protocol Version 4）です。

IPv4アドレスは32ビットで構成されます。

32ビットを8ビットずつ四つに分け、それぞれを10進数に直して「.（ドット）」で区切って表すことが多くあります。

たとえば、

192.168.1.10

のように表記します。

8ビットで表せる値は、

00000000 ～ 11111111

であり、10進数では、

0 ～ 255

です。

したがって、IPv4アドレスの四つの数値は、それぞれ0～255の範囲でなければなりません。

たとえば、

203.18.200.45

はIPv4アドレスとして表記できますが、

203.18.300.45

は「300」が255を超えているため、IPv4アドレスの表記として正しくありません。

IPv4は32ビットなので、理論上の組合せは、

232＝約43億

通りです。

IPv6

インターネットに接続する機器が増加すると、32ビットのIPv4だけでは利用できるアドレス数が不足するようになりました。

そこで利用されているのがIPv6（Internet Protocol Version 6）です。

IPv6アドレスは128ビットで構成されます。

IPv4が32ビットであるのに対してIPv6は128ビットなので、表せるアドレスの組合せは大幅に増えます。

IPv6では、一般に16進数を「:（コロン）」で区切って表記します。

たとえば、

2001:0db8:0000:0000:0000:0000:0000:0001

のように表せます。0が連続する部分は1か所だけ::と省略でき、

2001:db8::1

とも表せます。

128ビットであるので、

2128 ＝ 約3.4×1038＝約340兆×1兆×1兆

通りを表すことができます。

グローバルIPアドレスとプライベートIPアドレス

IPv4では、少ないIPアドレスを有効に活用するために、インターネット上で利用するアドレスと、家庭や学校、会社などの内部ネットワークで利用するアドレスに分けられています。

インターネット上で通信相手を識別するために利用されるIPアドレスを、一般にグローバルIPアドレスといいます。グローバルIPアドレスはインターネット全体で重複してはならないアドレスです。

一方、家庭や学校、会社などのLAN内部で利用するために用意されたIPv4アドレスをプライベートIPアドレスといいます。

プライベートIPアドレスは、同じLANの中では重複してはなりませんが、別のLANでは同じ値を使ってもかまいません。

たとえば、

家庭AのPC：192.168.1.10
家庭BのPC：192.168.1.10

のように、別々の家庭で同じプライベートIPアドレスを使用することができます。

家庭内の端末がインターネットへ通信するときは、家庭のルータが内部の端末と外部との通信を対応付けて中継します。

このため、複数の家庭で同じプライベートIPアドレスが使われていても、それぞれインターネットへ接続することができます。

グローバルIPアドレスとプライベートIPアドレスの関係は、会社に荷物を届ける場合にたとえることができます。

たとえば、A株式会社の田中さんに荷物を届ける場合を考えます。

このとき、

  • A株式会社の住所がグローバルIPアドレス
  • 田中さんという名前がプライベートIPアドレス

に相当すると考えられます（A株式会社の中に田中さん、佐藤さんはそれぞれひとりだけとします）。

配達業者はA株式会社の住所まで荷物を運びます。会社まで届いた荷物はA株式会社の中で田中さんにまで送られます。

このようにすれば、A株式会社の佐藤さんに荷物を送る場合でも、A株式会社の住所さえあれば荷物を届けることができます。社員ひとりひとりが住所を持つ必要がなく、住所（グローバルIPアドレス）の数を節約できます。

また、B株式会社に別の「田中さん」がいたとしても、混乱なく荷物を運ぶことができます。つまり、異なるLANにおいて、プライベートIPアドレスが重複していても問題ありません。

家庭や会社のネットワークでは、ルータが外部との通信と内部の端末との対応を管理し、インターネットから戻ってきた通信を適切な端末へ届けます。

DHCP

PCやスマートフォンをネットワークへ接続するたびに、利用者がIPアドレスなどを手作業で設定するのは大変です。

そこで利用されるのがDHCP（Dynamic Host Configuration Protocol）です。

DHCPは、ネットワークに接続した端末に対して、

  • IPアドレス
  • その他のネットワーク設定情報

などを自動的に割り当てるための仕組みです。

たとえば、家庭のWi-Fiへスマートフォンを接続したとき、通常は利用者がIPアドレスを入力しなくても通信できます。これは、ルータなどで動作するDHCP機能によって、必要な設定情報が自動的に割り当てられているためです。

ドメイン名とDNS

コンピュータ同士が通信するときにはIPアドレスを利用しますが、

142.250.196.99

のような数字の並びを人間が覚えるのは難しいものです。

そこで、人間が扱いやすい名前としてドメイン名が利用されます。

たとえば、

mei-chan-nel.com

のような名前です。

しかし、実際にネットワーク通信を行うには通信先のIPアドレスが必要です。

そこで、ドメイン名などの名前とIPアドレスを対応付ける仕組みとしてDNS（Domain Name System）が利用されます。

たとえば、Webブラウザで

mei-chan-nel.com

を指定すると、DNSを利用して、その名前に対応するIPアドレスを調べます。この処理を名前解決といいます。

Webサイトを閲覧するときの大まかな流れは、

ドメイン名を指定
↓
DNSによってIPアドレスを調べる
↓
得られたIPアドレスを使ってWebサーバへ通信する

となります。

DNSは分散して管理されている

世界中のすべてのドメイン名とIPアドレスの対応を、1台のDNSサーバだけで管理しているわけではありません。

DNSは、多数のDNSサーバによって階層的・分散的に管理されています。

ドメイン名そのものも階層構造になっています。

たとえば、www.example.co.jpであれば、右側から、

jp
↓
co.jp
↓
example.co.jp

というような階層として考えることができます。

それぞれの範囲を担当するDNSサーバが情報を管理することで、インターネット上の膨大なドメイン名を管理しています。

ルータ

ルータ（router）は、異なるネットワーク同士を接続し、パケットを適切なネットワークへ中継する装置です。

たとえば、

家庭内LAN
↓
家庭のルータ
↓
インターネット
↓
別のルータ
↓
Webサーバ

というように、パケットは複数のネットワークを経由して宛先へ届けられます。

ルータがパケットを受信すると、主に

宛先IPアドレス

を確認します。

そして、自分が持っている経路表（ルーティングテーブル、転送表）と照合し、次にどのルータやネットワークへ送るかを決定します。

このように、パケットをどの経路へ転送するか判断することをルーティングといいます。

通常の宛先に基づくIP転送では、

宛先IPアドレス
＋
ルータの経路情報

を使って次の転送先を決定します。

IPアドレス · EXAMPLEITパスポートR2公開問題 問75（改題）

IPv4アドレスの表記例として、最も適当なものはどれか。

  1. 0

    00:11:aa:bb:cc:dd

  2. 1

    050-1234-5678

  3. 2

    10.123.45.67

  4. 3

    https://www.example.jp/

解答・解説を確認

正解2．10.123.45.67

解説

IPv4アドレスは、0から255までの十進数をドットで4つ並べて表します。10.123.45.67はその形式に合っています。
