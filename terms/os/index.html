TERM GUIDE · DIGITAL

OS

「OS」とは

OS（Operating System：オペレーティングシステム）は、コンピュータのハードウェアを管理し、アプリケーションが動作するための共通の環境を提供する基本ソフトウェアです。
Windows、macOS、Linux、Android、iOSなどが代表的なOSです。

コンピュータでは、Webブラウザ、文書作成ソフト、ゲームなど、さまざまなアプリケーションが動作します。しかし、それぞれのアプリケーションがCPUやメモリ、ディスク、プリンタなどを勝手に操作すると、複数のアプリケーションが同じ資源を取り合ったり、互いのデータを書き換えたりするおそれがあります。
そこで、アプリケーションとハードウェアの間にOSが入り、コンピュータ全体を管理します。

OSの主な役割

OSには、主に次のような役割があります。

CPUの管理
複数のアプリケーションが動いているとき、それぞれの処理にCPUを使う時間を割り当てます。CPUを短い時間ずつ切り替えて利用させることで、複数の処理を並行して進められます。

メモリの管理
各アプリケーションに必要な主記憶（メモリ）の領域を割り当てます。また、あるアプリケーションが別のアプリケーションのメモリを勝手に書き換えないように管理します。

ファイルや補助記憶装置の管理
SSDやHDDなどに保存されたデータを、ファイルやフォルダとして管理します。アプリケーションはOSの機能を利用して、ファイルの保存や読み込みを行います。

入出力装置の管理
キーボード、マウス、ディスプレイ、プリンタなどの周辺機器を管理します。個々の機器を制御するためには、デバイスドライバと呼ばれるソフトウェアが使われます。デバイスドライバは、OSからの要求を、それぞれの機器に適した命令へと橋渡しします。

このように、OSはCPU、メモリ、補助記憶装置、入出力装置などのコンピュータ資源（リソース）を管理し、必要なアプリケーションへ割り当てる役割を担っています。

基本ソフトウェアと応用ソフトウェア

ソフトウェアは、役割によって大きく基本ソフトウェアと応用ソフトウェア（アプリケーションソフトウェア）に分けることができます。
OSは基本ソフトウェアの代表例です。コンピュータのハードウェアを管理し、ほかのソフトウェアが動作するための基盤を提供します。
一方、文書作成、表計算、画像編集、Webページの閲覧など、利用者の具体的な目的のために使うソフトウェアを応用ソフトウェアといいます。

たとえばWebブラウザがファイルを保存するとき、ブラウザ自身がSSDを直接制御するのではなく、OSに「このデータを保存したい」と要求します。OSが実際のファイルや記憶装置を管理するため、アプリケーションはハードウェアの細かな仕組みをすべて知る必要がありません。

OSによって動作するアプリケーションが異なる

OSはアプリケーションに共通の実行環境を提供しますが、どのOSでもすべてのアプリケーションがそのまま動作するわけではありません。
アプリケーションは、Windows用、macOS用、Android用、iOS用など、それぞれのOSが提供する機能や仕組みに合わせて作られています。そのため、同じアプリケーションでもOSごとに別のバージョンが用意されることがあります。

また、安全性や安定性を保つため、アプリケーションがOSの内部やハードウェアを制限なく直接操作できるようにはなっていません。OSが間に入って利用できる資源や操作を管理することで、複数のアプリケーションを安全に動作させています。

OSの更新

OSには、機能の追加だけでなく、発見された不具合やセキュリティ上の問題を修正する更新も提供されます。そのため、OSを長期間更新せずに使用すると、既に知られている弱点が残ったままになることがあります。
パソコンだけでなくスマートフォンでもOSは重要な役割を担っており、適切に更新して利用することがセキュリティ対策の一つになります。

つまり、OSは単にコンピュータを起動するためのソフトウェアではなく、CPU・メモリ・ファイル・周辺機器などを一元的に管理し、アプリケーションとハードウェアの間を取り持つ、コンピュータ全体の土台となるソフトウェアです。

EXAMPLE

例題

OS · EXAMPLEITパスポートH22春期 問56（改題）

OSの役割として、最も適当なものはどれか。

  1. 0

    アプリケーションに対して、CPU、メモリ、補助記憶装置などの資源を割り当てる。

  2. 1

    OSが異なっても、すべてのアプリケーションが必ずそのまま動作するようにする。

  3. 2

    ファイル内の文字コードを常に自動変換し、利用者やアプリが違いを意識しないようにする。

  4. 3

    アプリケーションがOSの内部機能を制限なく直接操作できるようにする。

解答・解説を確認

正解0．アプリケーションに対して、CPU、メモリ、補助記憶装置などの資源を割り当てる。

解説

OSは、アプリケーションが使うCPUやメモリ、ファイルなどのコンピュータ資源を管理し、必要に応じて割り当てる。
