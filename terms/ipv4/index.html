TERM GUIDE · NETWORK

IPv4

「IPv4」とは

IPv4（Internet Protocol version 4）は、インターネットなどのネットワークで、通信する機器を識別するために使われるIP（Internet Protocol）の方式の一つです。

ネットワーク上でデータを送るときには、「どこからどこへ送るのか」を示す必要があります。その宛先や送信元を表すために使われる番号がIPアドレスです。

IPv4アドレスは32ビット

IPv4のIPアドレスは、32ビットの2進数で表されます。

例えば、次のような32ビットの値があるとします。

11000000 10101000 00000001 00001010

そのままでは人間には読みにくいため、IPv4では通常、32ビットを8ビットずつ四つに区切り、それぞれを10進数に直して「.（ドット）」でつなぎます。

上の例では、

  • 11000000 → 192

  • 10101000 → 168

  • 00000001 → 1

  • 00001010 → 10

なので、

192.168.1.10

と表します。

一つの区切りは0～255の範囲

8ビットでは、

00000000 ～ 11111111

までの値を表せます。

これは10進数では、

0～255

に当たります。

したがって、

203.18.200.45

はIPv4アドレスとして表記できますが、

203.18.300.45

のような表記はできません。300は8ビットで表せる0～255の範囲を超えているためです。

グローバルIPアドレスとプライベートIPアドレス

IPv4アドレスには、インターネット上で利用するグローバルIPアドレスと、家庭や学校、会社などの内部ネットワークで利用するプライベートIPアドレスがあります。

グローバルIPアドレスは、インターネット上で通信相手を区別できるように割り当てられます。インターネット全体で重複することのない番号です。

一方、プライベートIPアドレスは、それぞれの家庭や組織の内部だけで使われるため、同じネットワークの中では重複してはいけませんが、別々のネットワークで同じアドレスを使うことができます。例えば、家庭Aと家庭Bの両方で、

192.168.1.10

というアドレスを使っていてもかまいません。

家庭内の端末がインターネットへ接続するときには、一般にルータが家庭内部の通信とインターネット側の通信を対応付けて中継します。このとき、ルータは家庭内で使われているプライベートIPアドレスと、インターネット側で使われるグローバルIPアドレスとの間でアドレスを変換します。この仕組みをNAT（Network Address Translation）といいます。

そのため、家庭内で使われているプライベートIPアドレスを、そのままインターネット上の通信相手の宛先として利用するわけではありません。

IPv4ではアドレスが足りなくなった

IPv4は32ビットなので、理論上表せる組合せは

2³²通り

です。これは約43億通りです。

インターネットが普及し、コンピュータだけでなく、スマートフォンやさまざまな機器がネットワークに接続されるようになると、IPv4だけでは利用できるアドレスが不足することが問題となりました。

そこで使われるようになったのがIPv6（Internet Protocol version 6）です。

IPv6

IPv6は128ビットの長さを持ち、2¹²⁸通り、つまり、およそ 3.4 × 10³⁸＝約340澗（かん）通りを表します。
16進数を用いて192.168.1.102001:db8::1のように表現します。

IPアドレスに関する説明として、最も適切なものを選べ。

  1. 0

    IPv4アドレスは32ビットで構成され、通常は8ビットずつ四つに区切り、それぞれを10進数で表記する。

  2. 1

    IPv6アドレスは、IPv4アドレスを構成する各数値の範囲を広げ、全体を64ビットにしたものである。

  3. 2

    インターネット上の機器と直接通信するときは、通信相手のプライベートIPアドレスを宛先として指定する。

  4. 3

    IPアドレスは通信相手を識別するために用いられるが、同じネットワーク内では複数の機器に同じアドレスを設定できる。

解答・解説を確認

正解0．IPv4アドレスは32ビットで構成され、通常は8ビットずつ四つに区切り、それぞれを10進数で表記する。

解説

正答はIPv4の構成と表記の説明である。IPv4アドレスは32ビットで、通常は8ビットずつ四つに分ける。各部分を0～255の10進数に直し、192.0.2.1のようにドットで区切って表す。 IPv6は128ビットで、16進数を用いて表記する。IPアドレスはネットワーク上の通信相手を識別するための情報なので、同じ範囲で重複しないように設定する必要がある。
