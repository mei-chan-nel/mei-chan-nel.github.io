CPU

「CPU」とは

CPUは、コンピュータ上で動くプログラムの命令を実行する装置です。スマートフォンやパソコンでは、アプリを起動する、数値を計算する、画面表示のために各装置へ指示を出す、といった多くの処理にCPUが関わっています。

CPUはCentral Processing Unitの略で、日本語では中央処理装置と呼ばれます。コンピュータの働きは、入力装置・出力装置・記憶装置・演算装置・制御装置の「五大装置」に分けて考えることができます。このうちCPUは、主に演算装置と制御装置を担当します。

制御装置は命令を読み取り、その内容に従って各装置へ動作の指示を出します。演算装置は加減乗除などの計算だけでなく、大小の比較やAND・OR・NOTなどの論理演算も行います。

命令は「取り出す → 解読する → 実行する」

実行中のプログラムや処理に必要なデータは、主に主記憶装置に置かれます。CPUはそこから命令を順に取り出し、何をする命令なのかを解釈し、必要な演算や装置の制御を行います。

  1. 取り出す（fetch）：主記憶装置から次に実行する命令を取り出します。
  2. 解読する（decode）：取り出した命令が何を指示しているかを解釈します。
  3. 実行する（execute）：演算やデータの移動、各装置への指示などを行います。

CPU内部にはレジスタと呼ばれる非常に高速な記憶領域があり、処理中のデータや命令、処理位置などを一時的に保持します。

クロック周波数

CPUは、基準となる周期的な信号に合わせて動作します。この信号の1秒あたりの回数をクロック周波数といい、Hz（ヘルツ）で表します。

1.6 GHz ＝ 1.6 × 109 Hz ＝ 1秒間に16億回のクロック

単純化して、1命令の実行に平均4クロック必要だと仮定すれば、1秒あたりに実行できる命令数はおよそ次のように計算できます。

1.6 × 109 ÷ 4 ＝ 4.0 × 108 命令/秒

ただし、実際のCPUでは命令の種類やCPUの設計によって1命令に必要な時間が異なり、複数の命令を並行して処理する仕組みもあります。そのため、クロック周波数だけでCPU全体の性能が決まるわけではありません。

キャッシュメモリと主記憶装置

CPUは非常に高速ですが、主記憶装置から毎回データを読み出していると、その待ち時間が処理速度の低下につながります。そこでCPUの近くには、よく使うデータや命令を一時的に保存するキャッシュメモリが置かれています。

キャッシュメモリは主記憶装置より容量は小さいものの高速で、CPUと主記憶装置の速度差を埋める役割を持ちます。

レジスタ → キャッシュメモリ → 主記憶装置 → SSD・HDD

一般に右へ行くほど大容量になりますが、CPUからのアクセスには時間がかかります。SSDやHDDは補助記憶装置であり、電源を切ってもデータを保持できる点も重要です。

複数の処理を動かす仕組み

コンピュータでは複数のアプリや処理が同時に動いているように見えます。1つのCPUコアで複数の処理を扱う場合、OSは処理する対象を短い時間で切り替えます。切り替える際には、再開できるようにレジスタなどの状態を保存します。

また、複数のCPUコアを備えたCPUでは、条件が整えば複数の処理を実際に並行して進めることもできます。

つまり、CPUは主記憶装置から命令を取り出して解釈し、演算と各装置の制御を行う、コンピュータの処理の中心となる装置です。

例題

CPU · EXAMPLEオリジナル問題

CPUが主に行う処理として、最も適切なものはどれか。

  1. 0

    電源を切った後もデータを保存する。

  2. 1

    命令を解釈して各装置を制御し、演算を行う。

  3. 2

    コンピュータとプリンタを接続するための通信方式を定める。

  4. 3

    外部から情報を入力し、処理結果を外部へ出力する。

正答と解説を確認

正答1. 命令を解釈して各装置を制御し、演算を行う。

解説

コンピュータの五大装置は、入力装置、出力装置、記憶装置、演算装置、制御装置です。CPUは主記憶装置から命令を取り出して内容を解釈し、その命令に従って各装置の動作を制御します。また、数値の計算や比較などの演算も行うため、主に制御装置と演算装置の役割を担います。
