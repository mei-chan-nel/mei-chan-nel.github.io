TERM GUIDE · NETWORK

ルータ

「ルータ」とは

ルータ（router）とは、異なるネットワーク同士を接続し、データの宛先に応じて適切な方向へ転送するネットワーク機器です。

例えば、家庭や学校のLANからインターネット上のWebサイトにアクセスするとき、通信データはルータを経由して外部のネットワークへ送られます。

ルータは、データに付けられた宛先IPアドレスと、自身が持つ経路情報をもとに、次にどこへデータを送るかを判断します。

ルータの基本的な役割

ネットワークには、家庭や学校などの比較的狭い範囲で利用するLAN（Local Area Network）や、離れた場所のネットワークを結ぶWAN（Wide Area Network）などがあります。

インターネットは、世界中の多数のネットワークが相互に接続されたものです。ルータは、これらの異なるネットワークの間でデータを中継します。

例えば、家庭のパソコンからインターネット上のWebサーバへアクセスするとき、通信は次のように進みます。

  1. パソコンが、WebサーバのIPアドレスを宛先とするデータを送信します。
  2. 宛先が家庭内LANの外部にあるため、データを家庭のルータへ送ります。
  3. ルータが宛先IPアドレスを確認し、インターネット側へ転送します。
  4. インターネット上のルータが順次データを中継し、Webサーバのあるネットワークへ届けます。

ここで重要なのは、ルータが異なるネットワークの間をつなぐ役割を持つことです。

同じLAN内の機器同士の通信は、通常、スイッチングハブなどで中継できます。一方、別のネットワークへデータを送る場合には、ルータが必要になります。

ルーティングと経路制御表

ルータが、宛先に応じて通信経路を判断することをルーティング（経路制御）といいます。

ルータは、受け取ったデータをすべての接続先へ送るのではなく、経路制御表（ルーティングテーブル）を参照して転送先を決めます。

経路制御表には、どのネットワークに向かうデータを、どの方向へ転送すればよいかという情報が記録されています。

一般的なIP転送では、宛先IPアドレスと転送表の情報を照合して経路を選びます。複数の経路が該当する場合には、通常、宛先との一致部分が最も長い経路が優先されます。

また、インターネット上のすべてのルータが、送信元から最終目的地までの経路全体を一度に決めているわけではありません。

それぞれのルータが、次にどのルータやネットワークへ送るかを判断します。この次の転送先を「次ホップ」といいます。

各ルータがこの処理を繰り返すことで、データは最終的な宛先へ向かいます。

ルータ · EXAMPLE応用情報技術者H22春期午前 問37（改題）

ルータの基本的な働きとして最も適当なものはどれか。

  1. 0

    異なるネットワーク間で、IPアドレスなどをもとに通信を中継する。

  2. 1

    同じLAN内で、MACアドレスを基にフレームを中継する。

  3. 2

    ドメイン名に対応するIPアドレスを調べる。

  4. 3

    無線端末を有線LANへ接続する。

解答・解説を確認

正解0．異なるネットワーク間で、IPアドレスなどをもとに通信を中継する。

解説

ルータは、異なるネットワークを接続し、IPアドレスなどをもとに通信を中継する機器です。
