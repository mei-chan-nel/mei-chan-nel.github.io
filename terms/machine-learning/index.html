機械学習

「機械学習」とは

機械学習とは、コンピュータが多くのデータを調べ、そこに含まれる特徴やパターンを見つけて、予測や分類などに利用する技術です。AIを実現するための代表的な方法の一つです。

例えば、犬と猫の画像を見分ける機械学習では、コンピュータに犬と猫の画像を数多く与えます。コンピュータは、それらの画像から、耳の形、顔の輪郭、毛並みなど、分類に役立つ特徴を学習します。その後、初めて見る画像に対しても、学習した特徴をもとに犬か猫かを判断します。

このように、機械学習では、人間がすべての判断規則を細かくプログラムするのではなく、コンピュータがデータから判断の手掛かりを見つけます。ただし、コンピュータが人間のように内容を理解しているとは限りません。学習したデータに見られる傾向をもとに、可能性の高い答えを計算しています。

機械学習は、次のような場面で利用されています。

  • 写真に写っている人物や物体を判別する画像認識

  • 音声を文字に変換する音声認識

  • 過去の売上から将来の需要を予測するシステム

  • 利用履歴をもとに商品や動画を推薦するシステム

  • 迷惑メールや不正な取引を見つけるシステム

機械学習の結果は、学習に使ったデータの内容に大きく左右されます。データが少なかったり、特定の種類に偏っていたり、誤った情報が含まれていたりすると、適切な判断ができないことがあります。

例えば、特定の年代の人のデータばかりを使って学習すると、それ以外の年代について正しく予測できない可能性があります。また、過去の採用結果に偏りがあれば、そのデータを学習したAIも同じような偏りを受け継ぐことがあります。そのため、データの入手元や作成方法、種類のバランス、正解を示すラベルが適切かどうかを確認することが重要です。

さらに、採用や融資、医療など、人に大きな影響を与える場面では、AIの判断だけに任せるのではなく、人間が結果を確認したり、判断に疑問がある場合に訂正を求められる仕組みを設けたりする必要があります。

機械学習は、大量のデータから人間だけでは見つけにくい傾向を発見できる便利な技術です。一方で、その結果が常に正しいとは限りません。どのようなデータを使って学習したのか、結果に偏りがないかを確かめながら利用することが大切です。

例題

機械学習 · EXAMPLE基本情報技術者H30秋期午前 問3（改題）

AIにおける機械学習の説明として、最も適当なものはどれか。

  1. 0

    データからパターンや規則を見つけ、予測や判断に利用する技術

  2. 1

    コンピュータの部品を小さくして、消費電力を必ず0にする技術

  3. 2

    専門家が入力した知識だけを検索して、決まった文を表示する技術

  4. 3

    Webページの見た目を整えるためだけの技術

解答・解説を確認

正解0．データからパターンや規則を見つけ、予測や判断に利用する技術

解説

機械学習は、多くのデータからパターンや規則を見つけ、予測や分類などに利用するAIの技術である。
