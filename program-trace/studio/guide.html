プログラムトレース Studio

プログラムの作り方

Studioを開く →

各行の処理を選び、値や条件を設定してプログラムを組み立てます。字下げや「｜」「⎿」は自動で付きます。

処理を追加する

各行の右端の「＋」で、その行のすぐ下に空白行を追加します。プログラムの見出しの「＋」は、1行目の上に追加します。空白行をタップし、「変数・配列」「分岐」「繰り返し」「関数」から処理を選びます。「この行に反映」を押すと、実行画面と同じプログラムの表記になります。入力済みの行もタップして変更できます。「新規作成」で空白の1行から始めます。

値と計算を設定する

「変数・配列」では、最初に「作るもの」で変数・一次元配列・二次元配列を選びます。その種類で作成済みの名前が表示されます。新しい名前を作るときは、一番下の「新規」を選んで入力します。下の「右辺を入力」を押して、入れる値を設定します。

右辺はキーボードで直接入力できます。3やx + yは数値や計算式、"合計は"のように引用符で囲んだものは文字列です。候補の変数・計算記号・関数をタップすると、カーソルの位置に挿入します。画面上の数値・文字入力も補助として使えます。全角の数字・計算記号・引用符は確定時に整え、式の間違いは内容を残したまま修正を促します。

「関数」の「表示する()」では、表示する内容を上から順につなげます。"合計は"、変数goukei、"です。"を順に追加すると、実行時に「合計は7です。」のように表示されます。

条件分岐と繰り返し

「分岐」で「もし … ならば」を選び、変数や比較記号をタップして条件を作ります。反映すると内側に空白行ができるので、条件が成り立ったときの処理を設定します。その内側、または分岐の直後の空白行から「分岐」を選ぶと、対応する「そうでなくもし」「そうでなければ」を追加できます。字下げと「｜」「⎿」は自動で付きます。

「繰り返し」の「範囲を決めて繰り返す」では、変数と開始値・終了値・増減する値を指定します。各値を開いて、画面上のボタンで式を変更できます。終了値も含み、増減する値は1以上の整数です。「条件を満たす間繰り返す」では比較条件を指定します。内側には実行する処理を設定してください。さらに分岐や繰り返しを入れることもできます。

行を並べ替える

行をタップすると、下の操作欄に「1行上に」「1行下に」「ひとつ内側へ」「ひとつ外側へ」「削除」が表示されます。行番号をつかんでドラッグしても移動できます。PCではプログラムの文字の部分からもドラッグできます。横に動かすと入れ子の深さを選べ、左端へ動かすといちばん外側へ移します。移動先は線で表示されます。分岐・繰り返しの見出しを動かすと、内側の行も一緒に移ります。「そうでなくもし」「そうでなければ」は元の「もし」と一緒に移します。「元に戻す」「やり直す」で取り消し・復元ができます。

一次元・二次元配列

左辺で一次元・二次元配列を選ぶと、右辺は要素ごとの入力欄になります。値や式を直接入力し、「要素を追加する」や「×」で個数を変えられます。二次元では行と列を追加・削除できます。「式で入力する」では[3, 5, 9]のような配列や、別の配列を指定できます。既存の配列を左辺で選んだときは、配列全体かひとつの要素かを選べます。二次元の要素には行番号・列番号を指定します。変数の右辺にはData[0]のような要素を使い、配列全体を入れる候補は表示しません。

編集画面の右側にある「配列の番号」で、すべての配列を0始まり・1始まりのどちらにするか選びます。既存の要素番号は自動で書き換わらないので、指定した番号も合わせてください。配列は要素の変更より前に作り、各行の列数をそろえます。

外部入力と乱数

代入の右辺で「外部からの入力」を選び、形式・範囲などを設定します。数値・文字列・一次元配列・二次元配列に対応します。その行を実行すると入力ダイアログが開きます。

右辺の「乱数()」で範囲と整数／実数を指定できます。整数は範囲の両端を含み、実数は最大値を含みません。「式に入れる」で確定します。「最初から」では同じ乱数の流れを再現します。独自の関数の定義・再帰は扱いません。

1行ずつ実行する

右側の「実行画面へ」で実行画面に切り替わります。「次へ」で実行した行が緑になり、その結果が変数と出力に反映されます。「プログラムを編集」で編集画面へ戻れます。変数を使う前に値を設定してください。内側が空の分岐や繰り返しは、処理を追加してから実行します。

保存と共有

下書きはこのブラウザに自動保存します。「ブラウザ内に保存」で名前をつけて残し、「ブラウザ内から読込」で選べます。「ファイルに書出」ではファイル名を指定してJSONファイルを保存し、「ファイルから読込」で開けます。「新規作成」の前に未保存の変更がある場合は、保存するか選びます。保存の途中でキャンセルしても元のプログラムを保持します。ブラウザのデータを削除するとブラウザ内の保存は消えます。作成途中のプログラムも保存できます。

「URLで共有」はプログラムと設定をURLにまとめます。受け取った人が編集しても、あなたの保存には影響しません。長いURLがうまく送れない場合は書き出したファイルを共有できます。読み込んだプログラムは自動実行されません。

上限とエラー

500行・50KB、1回の実行は10,000ステップまでです。配列は1つあたり1,000要素（セル）・全体で5,000要素、出力は1,000回までです。範囲外の添字・未代入の変数・0での除算などは該当する行を示して停止します。設定を変更して実行し直せます。
