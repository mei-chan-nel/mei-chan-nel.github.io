  ファイルの仕様
  
    
    
    読み込めるファイル
    
    
    文字コードはUTF-8、拡張子は .studio.json です。ファイル全体を、次の形式のJSONオブジェクトにします。Markdownの囲みやJSONの外への説明は入れません。
    
    
    {
  "format": "mei-program-studio",
  "version": 1,
  "title": "2つの値の合計",
  "source": "x = 3\ny = 4\ngoukei = x + y\n表示する(\"合計は\", goukei, \"です。\")",
  "settings": {
    "indexBase": 0,
    "inputs": {}
  }
}
    
    
      
      
    • format と version は上の値に固定します。
      • 
      
    • title はプログラム名です。1～120文字にします。
      • 
      
    • source はプログラム本文の文字列です。改行は \n、本文中の " は \"、\ は \\ としてJSONに記入します。
      • 
      
    • settings.indexBase は、配列の番号を0から始める場合は 0、1から始める場合は 1 です。すべての配列に適用されます。
      • 
      
    • settings.inputs は外部入力の設定です。外部入力がない場合は {} にします。
      • 
    
    
    
    自分でファイルを作る場合は、完成した本文を記入します。builder は作成途中の行を保存するためにアプリが付ける情報なので、手動・AIで作るファイルには付けません。
    

    
    本文の書き方
    
    
    行番号は不要です。分岐や繰り返しの内側は、半角スペース2個で字下げします。さらに内側なら4個、6個と増やします。「そうでなくもし」「そうでなければ」は、対応する「もし」と同じ深さに置きます。
    
    
    x = 3
Data = [3, 5, 9]
Data[0] = x + 1
Table = [[1, 2], [3, 4]]
Table[0, 1] = 8
もし x < 10 ならば：
  表示する("10未満です。")
そうでなくもし x == 10 ならば：
  表示する("10です。")
そうでなければ：
  表示する("10より大きいです。")
i を 1 から 5 まで 1 ずつ増やしながら繰り返す：
  表示する(i)
x < 10 の間繰り返す：
  x = x + 1
    
    
    半角スペースの代わりに、深さごとの「｜」「⎿」でも記入できます。「⎿」はその深さの最後の行に使います。字下げ用のスペースと記号は混ぜません。「終了」「end」などの終端行は書きません。分岐・繰り返しの内側には、実行する処理を1行以上入れます。
    
    
      
      
    • 変数名は文字または _ で始め、続きには文字・数字・_ を使います。日本語も使えます。命令・関数と同じ名前、__proto__・constructor・prototype は使えません。
      • 
      
    • 数値、引用符で囲んだ文字列、真・偽、一次元・二次元配列を扱えます。変数・配列は、使う前に代入してください。
      • 
      
    • 計算記号は + - * / ÷ % ** です。/ は通常の割り算、÷ は商の小数部分を切り捨てて0に近い整数にします。% は余り、** は累乗です。
      • 
      
    • 比較は == != < <= > >=、論理演算は and or not です。計算順を明確にするには ( ) で囲みます。
      • 
      
    • 同じ行で x = 1, y = x + 1 のように複数代入すると、左から順に処理します。文字列と数値を表示するときは 表示する("値は", x) のように分けます。
      • 
      
    • 一次元配列は [3, 5, 9]、二次元配列は [[1, 2], [3, 4]] と書きます。二次元では全行の列数をそろえます。要素は Data[i]・Table[i, j] で指定し、存在する番号の範囲内で使います。
      • 
      
    • 範囲を決めた繰り返しは終了値を含みます。開始・終了・増減する値は整数にし、増減する値は1以上にします。減らす場合は「ずつ減らしながら繰り返す：」にします。
      • 
      
    • # 以降はコメントです。引用符の中の # は文字として扱います。独自の関数・再帰・返す・break・continue・三次元以上の配列は使えません。
      • 
    
    

    
    用意されている関数
    
    
    
      
    表示する("値は", x)
    引数を順につなげて表示します。間に空白は自動では入りません。1行の処理として使い、計算式の中には入れません。
    
      
    要素数(Data)
    一次元配列の要素数、二次元配列の行数を返します。二次元の列数は、0始まりなら 要素数(Table[0]) で取得できます。
    
      
    乱数()
    0以上1未満の実数です。
    
      
    乱数(1, 6, "整数")
    最小値以上、最大値以下の整数です。範囲の両端を整数にします。
    
      
    乱数(0, 10, "実数")
    最小値以上、最大値未満の実数です。最小値を最大値より小さくします。
    
    
    

    
    外部から入力する場合
    
    
    本文に age = 【外部からの入力】 と書き、settings.inputs.age に形式と範囲を設定します。外部入力は単独の変数への代入として1行に書きます。次は、そのまま読み込める例です。
    
    
    {
  "format": "mei-program-studio",
  "version": 1,
  "title": "年齢で分岐する",
  "source": "age = 【外部からの入力】\nもし age >= 18 ならば：\n  表示する(\"成人です。\")\nそうでなければ：\n  表示する(\"未成年です。\")",
  "settings": {
    "indexBase": 0,
    "inputs": {
      "age": {
        "kind": "number",
        "integer": true,
        "min": 0,
        "max": 120,
        "minLength": 1,
        "maxLength": 100,
        "elementKind": "number",
        "rows": 2,
        "columns": 3
      }
    }
  }
}
    
    
    各入力の設定には、使わない項目も含めて上の9項目をすべて記入します。
    
    
    
      
    kind
    数値は "number"、文字列は "text"、一次元配列は "array"、二次元配列は "matrix" です。
    
      
    integer、min、max
    数値や配列の数値要素の設定です。true なら整数のみ、false なら小数も使えます。範囲は両端を含み、最小値≤最大値にします。整数のみの場合は範囲も整数にします。不要な場合は true・-1000000・1000000 で構いません。
    
      
    minLength、maxLength
    一次元配列の要素数の下限・上限です。それぞれ1～1000で、下限≤上限にします。不要な場合は 1・100 にします。
    
      
    elementKind
    配列の要素を数値にする場合は "number"、文字列にする場合は "text" です。不要な場合は "number" にします。
    
      
    rows、columns
    二次元配列の行数・列数をそれぞれ1～30で指定します。不要な場合は 2・3 にします。文字列入力と配列の文字列要素は1つ1000文字までです。
    
    
    
    
    入力設定だけでは、配列が昇順かどうかなどは判定しません。探索などで順序に条件がある場合は、本文で確認するか並べ替えます。特定の要素番号を使う場合は、その番号まで含むよう要素数の下限を決めます。
    

    
    上限
    
    
    ファイルはUTF-8で300,000バイトまで、本文は500行・50,000バイトまでです。入れ子は32段まで、実行は10,000ステップまで、変数は128個までです。配列は1つ1,000要素・セルまで、全体で5,000まで。出力は1,000回・合計200,000文字までです。数値は有限の値で、整数は±9,007,199,254,740,991以内にします。
    
    
    読込時にはファイルと本文を検証します。読み込んだだけでは実行しません。詳しい表記・設定・上限は AI向けの完全な仕様、データの形式は JSON Schema で確認できます。
