プログラミング · 変数・配列 · QUESTION 002

これは英語、数学、国語の平均点を求めるプログラムである。
このプログラムの誤りを指摘し、正しくせよ。

（1）eigo = 50
（2）sugaku = 65
（3）kokugo = 56
（4）heikin = eigo + sugaku + kokugo /3
（5）表示する("平均点は",heikin,"です。")
答えと解説を見る

答え（4）heikin = (eigo + sugaku + kokugo) / 3

解説計算式では、かっこ、乗除算、加減算の順に処理します。
平均を求める式は、合計を先に計算してから人数で割る形にします。

プログラミング · 変数・配列 · QUESTION 004

次のプログラムの実行した際の表示結果を答えよ。

（1）x = 1
（2）y = 2
（3）x = y
（4）表示する("現在のxの値は", x, "です。")
（5）表示する("現在のyの値は", y, "です。")
答えと解説を見る

答え現在のxの値は2です。 現在のyの値は2です。

解説yの値をxへ代入しても、yの値は変わりません。
代入は値をコピーする操作で、二つの変数を自動的に結び付ける操作ではありません。

プログラミング · 変数・配列 · QUESTION 005

次のプログラムの実行した際の表示結果を答えよ。

（1）x = 1
（2）y = 2
（3）tmp = x
（4）x = y
（5）y = tmp
（6）表示する("現在のxの値は", x, "です。")
（7）表示する("現在のyの値は", y, "です。")
答えと解説を見る

答え現在のxの値は2です。 現在のyの値は1です。

解説二つの変数を交換するときは、一方の値を一時変数に退避します。
退避せずに上書きすると、最初の値を失ってしまいます。

プログラミング · 変数・配列 · QUESTION 008

次のプログラムの実行した際の表示結果を答えよ。

（1）x = 3

（4）y = x - y
（5）x = x - y
（6）表示する("現在のxの値は", x, "です。")

」「現在のyの値は3です。
」と表示されます。

プログラミング · 変数・配列 · QUESTION 020

2次元配列Kaiinは表の通りに名前、年齢、性別を格納している。
名前 年齢 性別
田中 25 男性
山田 30 女性
鈴木 23 女性
佐藤 44 男性
次のプログラムの実行した際の表示結果を答えよ。

（1）表示する(Kaiin[0, 0], "さんは", Kaiin[0, 1], "歳の", Kaiin[0, 2], "です。")
（2）表示する(Kaiin[1, 0], "さんは", Kaiin[1, 1], "歳の", Kaiin[1, 2], "です。")
（3）表示する(Kaiin[2, 0], "さんは", Kaiin[2, 1], "歳の", Kaiin[2, 2], "です。")

答え田中さんは25歳の男性です。 山田さんは30歳の女性です。 鈴木さんは23歳の女性です。

解説列0・1・2には順に名前・年齢・性別が入り、行0・1・2は田中・山田・鈴木のデータです。
したがって「田中さんは25歳の男性です。
」「山田さんは30歳の女性です。
」「鈴木さんは23歳の女性です。

プログラミング · 変数・配列 · QUESTION 021

映画館の座席が5行3列の2次元配列Seatsで管理されている。
座席は0が空席、1が予約済みを表す。
現在のSeatsの要素の値は以下の通りになっている。
なお、この配列の添字は1から始まる。
0 1 0
1 1 0
0 1 0
0 0 1
1 0 0
次のプログラムの実行した際の表示結果を答えよ。

（1）gyou = 3
（2）retu = 2
（3）表示する( gyou, "行", retu, "列目の座席の状態は", Seats[gyou, retu], "です。")
答えと解説を見る

答え3行2列目の座席の状態は1です。 （予約済みです）

解説この配列は添字が1から始まるため、gyou＝3、retu＝2をそのままSeats[3,2]として参照します。
3行2列目の値は1なので、「3行2列目の座席の状態は1です。
」と表示され、予約済みだと分かります。
